## 입출력 계약
- 입력: 04 (T001 적용본), RQ 브리프.
- 출력: 04 수정본, WORKING_NOTES.md, 보고서.
- 이동 문단은 `diff`로 원문 동일성을 증명한다(아래 검증).

## 구현 순서
1. 04 원본을 `git show HEAD:docs/journal_manuscript_v1/04_DISCUSSION.md > /tmp/04_before.md`로 보관.
2. WORKING_NOTES.md 생성(머리말 + A/B/C/D).
3. 04에서 M1–M3 제거, M2의 한 줄 추가, M5 재부여.
4. 검증, 보고서.

## 검증 명령
```bash
grep -c 'IEEE Transactions on Games seeks' docs/journal_manuscript_v1/04_DISCUSSION.md    # 0
grep -cE '^## 7\. Deferred|^## 8\. Closing' docs/journal_manuscript_v1/04_DISCUSSION.md    # 0
grep -cE '^## [1-6]\. ' docs/journal_manuscript_v1/04_DISCUSSION.md                        # 6
grep -c 'IEEE Transactions on Games seeks' docs/journal_manuscript_v1/WORKING_NOTES.md    # 1
grep -c 'low-dimensional probability adapter' docs/journal_manuscript_v1/WORKING_NOTES.md # ≥1
grep -c '안 C' docs/journal_manuscript_v1/WORKING_NOTES.md                                 # ≥1
grep -c 'What we do not claim' docs/journal_manuscript_v1/04_DISCUSSION.md                # 1 (Forbidden 절 유지)
# 원문 동일성: 이동한 §7 본문(제목 제외)이 WORKING_NOTES에 그대로 있는지
diff <(sed -n '/^## 7\. Deferred/,/^## 8\./p' /tmp/04_before.md | sed '1d;$d' | sed '/^$/d') \
     <(sed -n '/^## B\. Deferred/,/^## C\./p' docs/journal_manuscript_v1/WORKING_NOTES.md | sed '1d;$d' | sed '/^$/d')   # 출력 없음
git diff --name-only   # 04, WORKING_NOTES, 보고서 뿐
```

## 목표
KR/NA1 16.13의 T·S 행에서 동결 q vs PT_flex의 경기가중 ΔBrier에 대해 match-cluster bootstrap CI를 산출한다. 재학습·보정기 적합 없음.

## 실행
```bash
python scripts/e3_ext_paired_bootstrap.py --n-boot 10000 --seed 7 \
  --out-dir outputs/supplementary_e3_20260921 \
  --docs-md docs/SUPPLEMENTARY_E3_EXT_BOOTSTRAP_20260921.md \
  --docs-json docs/SUPPLEMENTARY_E3_EXT_BOOTSTRAP_20260921.json
```
- 주 네 domain×cohort: KR_16.13×{T,S}, NA1_16.13×{T,S}
- 95% percentile CI + Bonferroni 98.75% CI 병기
- 선택: 공통 경기 H=mean(d_mT−d_mS) (기전 주장 금지)
- 소규모 pilot은 점추정만(보조)

## 산출
- `outputs/supplementary_e3_20260921/rows_{cohort}_{set}.npz` (match,y,q,pt,…)

## 구현 명세

**C1. `rr20260920_q_build_newv_labels.py`**
- `cohort_keys(data_root, set_name, cohort="T")`: `cohort == "T"` → 기존 마스크 `(coh["cohort"] == 1)`; `cohort == "S"` → `(coh["cohort"] == 0) & (coh["fine"] == 1)`; 그 외 `SystemExit`. `valid_h90 == 1` 조건은 유지. `fine` 열이 npz에 없으면 `SystemExit("cohort file lacks 'fine'")` (계약 §2; 열 존재 근거: `e0ec3d0:scripts/cr20260915_cohorts.py` L441–444).
- CLI `--cohort {T,S}` 기본 `T`. `OUT`을 함수화: `T` → 기존 `outputs/q_newv_fit85_20260920/labels`, `S` → `outputs/q_newv_fit85_20260920_S/labels`. 메타 JSON에 `cohort` 필드와 마스크 규칙 문자열 기록.
- L204–205의 `_train_oof` 경로도 같은 함수를 쓰되, T008에서는 사용하지 않음(fold 재사용 경로가 별도).

**C2. `rr20260920_q_train_oof_mlp_folds.py`**
- `cohort_t_keys` → `cohort_keys(data_root, set_name, cohort)`로 일반화(C1과 동일 규칙; 중복 구현 대신 C1 모듈에서 import 가능하면 import).
- 새 CLI: `--cohort {T,S}`(기본 T), `--reuse-evaluators`(기본 False). `--reuse-evaluators`이면 fold k마다 `OOF_DIR/V_oof_fold{k}_mlp_expanded.joblib`(키 `mlp`, `calib`)와 `OOF_DIR/bundle_oof_fold{k}.joblib`(키 `bundle`)을 로드해 L243–246의 `predict_cal` 클로저를 재구성하고, L249–266 점수 블록을 `--cohort` 키 집합으로 실행한다. 적합·early-stop·g 재적합은 건너뛴다. 두 파일 중 하나라도 없으면 `SystemExit`로 멈추고 어떤 것이 없는지 출력(계약 §3 fallback은 T008에서 저자 확인 후).
- `LAB`/`OOF_DIR` 경로: `T`는 기존, `S`는 `outputs/q_newv_fit85_20260920_S/labels`(라벨) + **평가기는 항상 T의 `outputs/q_newv_fit85_20260920/oof_evaluators/`에서 읽음**(같은 V^(-k)).

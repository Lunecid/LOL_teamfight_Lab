## 6. 해석

- 정의를 TRAIN 패치 단독 추정치로 바꾸면 MAIN TEST에서 경기의 3.54 %가 바뀌고(노출 행 기준 제거 3,188/추가 2,013), 유효 T 행은 32,981 → 32,968(재구축 1,751)이다.
- 같은 동결 LightGBM의 T Brier는 옛 모집단 0.22839 → dev 모집단 0.22837(공통 행만 0.22820); 차이는 행 구성의 차이이지 모델 차이가 아니며 두 모집단 사이에 구간은 계산하지 않는다.
- 주 대비(dev 모집단, T, LightGBM): 재적합 − 동결 ΔBrier -0.00007 [-0.00023, +0.00010] → 구간이 0 포함. 재적합이 동결 모델과 구별되지 않으면 정의 변경은 학습된 q를 바꾸지 않는다.
- 판정 규칙: 짝지은 구간이 0을 포함하지 않으면 우세. 구간은 고정 모델의 평가 표본 불확실성만 반영하며, 정의 변경의 "순수 효과"라는 표현은 쓰지 않는다(모집단이 다르다).

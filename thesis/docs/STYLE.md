# 서술·표기 계약 (STYLE)

2026-09-21 개정. 이 문서는 학위논문이 "연구를 어떻게 진행했는가"의 보고서가 아니라 "어떤 문제를 정의했고 어떤 근거로 답했는가"의 논문이 되도록 문장·표·수치의 규칙을 고정한다. 검사 도구의 역할 분담은 §6.

## 1. 서술 순서 (Widom, "Tips for Writing Technical Papers")

- 서론은 다섯 질문에 순서대로 답한다: 무엇이 문제인가 / 왜 중요한가 / 왜 어려운가 / 기존 접근은 왜 충분하지 않은가 / 본 논문의 접근과 결과는 무엇이며 **구체적 한계**는 무엇인가. 이어서 기여 요약(절 번호 포함)과 논문의 구성.
- 각 장은 "이 장이 무엇을 확립하는가"로 열고 확립한 것으로 닫는다. 결과에 이르게 된 경위(설계가 어떻게 바뀌었나)는 본문이 아니라 부록의 기록이다.
- 결론은 두 문단 이내이며 초록·서론을 반복하지 않는다.
- 서론에는 실험 결과 수치를 넣지 않는다. 정의·측정·예측·검증의 수치는 그 내용을 다루는 **4–7장**에서 제시한다.

## 2. 이전 연구와의 관계

- 저자의 IEEE CoG 2026 논문은 관련 연구의 한 항목이다. 표기는 3인칭 "Baek과 Kwon \cite{baek2026killconditioned}". 그 정의·한계·본 논문의 처리는 **2장**에서 다루고, 방법·자료·상수의 출처를 밝히는 인용은 필요한 위치(예: 4장 상수 비교 기준)에 남긴다. 본문 전체를 그 연구의 확장 과정으로 구성하지 않는다.
- 서술 음성으로서의 "선행 연구에서 이어", "계승", "출발점", "확장한다", "저자의 / 저자가 참여한"은 쓰지 않는다. 연구 관리 용어("동반 저널 원고", "저널 원고", "J-RQ", "마감 잠금", "규모분리 계약", "I1–I4", 작업 번호)는 본문에서 방법론적 의미(데이터 역할, 분석 집단, 사전 설정, 탐색적 여부)로 바꾼다.
- CoG 2026의 한계는 **버전별로 귀속**한다: 출판 논문의 설계(손으로 정한 상수, 수작업 가중 교환가치 라벨, 표현×학습기 동시 변경) / 학회 파이프라인 코드의 두 사후 입력 / 학회 이후 분석의 철회된 규모 결론. 후속 수정을 출판 논문의 한계로 소급하지 않는다.
- 허수아비 금지(`docs/COG_SUCCESSION_LOCK_20260919.md` §1): "킬만 셌다", "임의·근거 없는 상수", "같은 입력 비교·패치 홀드아웃을 처음 했다". 라벨·코호트가 다르므로 두 연구의 AUC를 직접 비교하지 않는다.

## 3. 문장

- 한 문장 한 주장. 한 문단 한 메시지이며 첫 문장이 메시지를 말한다. 문장 사이의 관계(원인·대조·귀결·세분)를 드러낸다.
- "X이지만 Y는 아니다" 식 부정 병렬은 **정밀한 진술**로 바꾸되 불확실성을 보존한다. "추가 효용은 없다"(✗) → "추정치는 0 부근이었고 구간은 양·음의 값을 모두 포함했다"(✓). 절차의 부정("선정하지 않는다")은 절차의 긍정("모든 선정은 15.15에서 끝난다")으로.
- 군더더기("두 진술이 동시에 참이다", "그대로 밝힌다", "역사를 고쳐 쓰지 않는다")는 삭제한다.
- **조건의 위치**: 공통 한계와 반복되는 금지 해석은 8.2절(해석의 범위)에 모은다. 각 결과의 대상·비교·해석을 결정하는 조건은 그 결과의 첫 설명에 **한 번** 둔다(예: 정보군 비교 "모든 arm에 사전 승률 요약을 공통 제공하고 프레임·사건 특징을 직접 추가하는 효용을 비교하였다"; 라벨 이식 "예측값을 고정한 채 라벨만 바꾼 비교"; 외부 "구간 수준·다중비교·지역별").
- 보완 실험(15.16 노출 이후의 진단)의 표기는 분석 절 도입에 한 번, 독립적으로 읽힐 표에는 표주에 한 번. 문장마다 반복하지 않고 주장의 강도로 유지한다.
- 분석 대상은 긍정문으로 한정한다: "본 논문은 킬 기록을 기준으로 구성한 교전에 대해, 사전 관측 시점의 공개 상태로 교전 전후 추정 경기 승리확률의 변화 방향을 예측하는 문제를 다룬다." / "본 논문의 분석 대상은 킬 사건을 기준으로 식별한 교전이다."

## 4. 표와 그림

- 캡션은 대상을 이름 짓는 명사구(셀을 지정하는 괄호 하나까지, 수식 제외 45자 이내). 종결어미·마침표·세미콜론·가중·보정기·구간 상태·범례·읽는 법·출처·수식·상호참조는 캡션에 두지 않는다.
- 표 머리에 지표·단위·구간 수준을 적는다. 가중·보정기·분모·구간 수준처럼 표를 읽는 데 필요한 최소 조건은 `\tabnote{}` 한 줄에 둔다. 본문은 목적·핵심 결과·해석을 쓴다.
- 결과 표와 그 표를 처음 설명하는 문단은 같은 펼침면에 오도록 `\input`을 첫 `\ref` 문단 바로 뒤에 두고, 본문 float는 `[!t]`로 배치한 뒤 렌더로 확인한다.
- 통계량은 이름·분자·분모를 표 머리나 표주에서 알 수 있어야 한다. 분모가 다른 두 비율은 같은 열에 두지 않는다.

## 5. 용어·수치·인용

- 용어는 1.1의 용어표, `config/notation.tex`, 첫 등장의 `definition` 환경에서 한 번 정의하고 재정의하지 않는다. 고정 용어: 교전(단위) / 한타 T·소규모 교전 S(코호트) / 예측 시점 τ / 결과 시점 e_h / 교전 전 상태 / 승률 평가기 V̂ / 구간 변화 ΔV̂ / 전략적 가치 개선 SVI / 변화 방향 / 방향 예측기 q / 승률·시간 스플라인 기준선 PT_flex / 균형 구간 B40 / 적정 점수 / 점수 분해 CORP / 짝 경기 군집 부트스트랩 / 점수 전용 / 비교전 구간 / 탐색적 / 보완 실험(진단).
- 모든 수치는 매크로다: 주 결과는 `config/numbers.tex`(출처 `docs/NUMBERS.md`), 보완 실험은 생성물 `config/numbers_supp.tex`와 `tables/gen/*.tex`(출처·통계량·분자·분모 `docs/NUMBERS_SUPP.md`, 생성기 `tools/gen_supp.py`). 기존 연구의 상수는 `\cite`가 붙은 문장에서 cite-only 매크로로만.
- 반올림: Brier·AUC 소수 넷째, ΔBrier·구간 소수 다섯째(부호 포함), 비율 소수 셋째, 초 소수 첫째; 천 단위 `{,}`; 단위 앞 띄어쓰기.
- 인용 키는 `latex/bib/*.bib`에 있는 것만. 새 문헌은 DOI 확인 후 `thesis_extra.bib`에 VERIFIED 표기와 함께.
- 상태 어휘: `docs/STATUS.md`의 하위 분석 ID별 상태(FROZEN / DONE / PASS / PARTIAL / INCOMPLETE / NOT_RUN / BLOCKED / DEFERRED)에 맞춰 "실행하였다"는 DONE·PASS에만, "부분적으로"는 PARTIAL에만, "미실행·이연·차단"은 나머지에만 쓴다. 미정 사항은 `\pendingauthor{}`로 표시하고 STATUS.md §4에서 항목별로 추적한다.

## 6. 검사 도구의 역할

| 차단 (`tools/check_thesis.py`, exit 1) | 검토 위치 보고 (`tools/check_style.py`) | 사람이 판단 |
|---|---|---|
| 매크로·생성 표가 JSON 원장과 일치 (`check_numbers_supp.py`) | 부정·대조 표현의 빈도와 위치 | 그 수치가 문장의 주장을 지지하는가 |
| 부록 E 상태 표가 STATUS.md와 일치 (`gen_status_table.py --check`) | 계승·저널 결합·허수아비 어휘의 위치 | "실행"과 "검증"을 혼동했는가 |
| 미정의 인용·참조, 중복·끊어진·미참조 라벨 | 상태 어휘와 완료 동사가 같은 문장에 있는 곳 | 인용 출처가 해당 버전의 사실인가 |
| 헤드라인 매크로 값 불변, M-RQ 질문 본문 해시 | 캡션 길이·종결어미, 1장의 리터럴 숫자 | 효과 크기와 불확실성의 표현 |

빈도·어휘 검사는 임계값이 없다. 자동 검사를 논문 정확성의 보증으로 쓰지 않는다.

## 입력 특징 경로의 구분 (차단)

저장소에는 두 특징 경로가 있다. **StateV2**(원 362 → Expanded 361 → 수치 351; `state_value_v2.py`)는 승률 평가기 $\hat V$, SVI 라벨, 방향 예측기 $q$가 쓰는 표현이고, **탭·시퀀스 표현**(기본 1,015 × 통계 7 = 7,105; 저장소 `gameplay/`)은 교전 승자 라벨(`market_event`) 아래의 정의 민감도·누출 절제가 쓰는 표현이다. 한 표현의 성질을 다른 표현에 쓰지 않는다. 특히 45분 시각 정규화(`TIME_NORM_ABSOLUTE`)와 인과적 지도 앵커(`ANCHORS_CAUSAL`), 프레임 나이 특징(`TAB_FRAME_AGE_FEATURE`)은 탭 경로의 설정이므로 3.4절이 아니라 4.8절에 적는다. StateV2에는 좌표·앵커·거리·구역 열이 없고 `snapshot_age_s`는 기록만 되며 어느 모형의 입력도 아니다. 근거와 열 단위 전수는 [`FEATURE_CENSUS.md`](FEATURE_CENSUS.md)이며 `tools/gen_feature_census.py --check`가 드리프트를 막는다.

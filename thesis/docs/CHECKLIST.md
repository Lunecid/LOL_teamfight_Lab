# 제출 체크리스트 (부산대학교 학위논문 작성 지침 기준)

출처: 학생지원시스템 › 졸업 › 학위청구논문 › 논문 작성 지침, `forms/학위논문작성가이드(국문석사).hwp`.
전문대학원 고유 절차(심사 일정, 심사료, 제출 부수)는 데이터사이언스전문대학원 행정실(051-510-7187)에 확인한다.

## 구성·순서
- [ ] 표지 → 면지 → 속표지 및 인준지 → 차례 → 국문 초록 → 본문 → 참고문헌 → 부록 → 영문 초록
- [ ] 표지·면지·속표지 및 인준지는 **단면** 인쇄
- [ ] 국문·영문 초록 각 **2쪽 이내**

## 표지·인준지
- [ ] "석사학위논문" 표기, 제목, 성명, "부산대학교 데이터사이언스전문대학원", "데이터사이언스학과", 학위수여년월
- [ ] 인준지의 학위명(공학석사 / 이학석사 / 데이터사이언스학석사) 확정
- [ ] 인준지 연월일 = **최종 심사(인준) 연월일**
- [ ] 위원장·위원 성명, 날인(인) 자리
- [ ] 영문 제목: 관사·접속사·전치사 외 주요 단어 첫 글자 대문자

## 용지·인쇄·제본
- [ ] A4, 80 g 이상 백색 모조지
- [ ] 표지 회색 레자크지, 흑색 글씨, 무선철 제본
- [ ] 100 % 인쇄 후 여백(위 35 / 아래 25 / 왼쪽 30 / 오른쪽 25 mm) 자로 확인

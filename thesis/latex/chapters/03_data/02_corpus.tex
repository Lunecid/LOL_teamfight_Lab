\section{원천 코퍼스}
\label{sec:data-corpus}

원천 코퍼스는 한국(KR) 서버의 랭크 경기 \numMatchesTotal{} 건으로, Match-V5의 \texttt{gameVersion} 필드가 15.14, 15.15, 15.16으로 기록하는 세 패치에 걸쳐 있다. 이 필드는 공개 패치 번호 25.14--25.16에 대응한다. 패치별 경기 수는 \numMatchesTrain{} / \numMatchesVal{} / \numMatchesTest{} 건이며, 세 패치는 순서대로 학습, 보정·선정, 평가의 역할을 맡는다(제 \ref{sec:data-roles} 절). 표 \ref{tab:corpus-census}는 패치별로 검출된 교전, 결과 시점 규칙에서 유효한 교전, 그리고 규모 계급에 따른 한타 T와 그 밖의 교전 N의 행 수를 보인다. 검출과 결과 시점 규칙은 제 \ref{ch:engagement} 장에서 정의한다.

두 진술이 동시에 참이다. 연구 코퍼스는 \numMatchesTotal{} 경기이고, 주 예측 성능은 15.16의 홀드아웃 교전 표본에서만 평가된다. 같은 코퍼스가 같은 평가 표본은 아니다. 합동 T의 기술통계와 15.16의 $q$ 성능을 한 행의 ``증분 이득''처럼 나란히 쓰지 않으며, 학습 분할 안의 $q$ 성능을 합쳐 ``21만 경기 성능''으로 보고하지 않는다.

외부 코퍼스로 2026년 시즌의 API 패치 16.13 KR 경기 \numExtKRCollected{} 건, NA1 경기 \numExtNACollected{} 건, 16.15 KR 경기 \numExtKRbCollected{} 건, 16.14 KR 파일럿 \numExtPilotCollected{} 건을 별도로 수집하였다. 이들은 선정에 쓰이지 않고 점수 전용(score-only) 평가에만 쓰인다(제 \ref{sec:val-external} 절). 원시 경기 자료는 Riot API 이용약관에 따라 재배포하지 않으며, 논문은 파생 수량만 보고한다.

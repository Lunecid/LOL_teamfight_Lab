## 3. 사용자 확정 조건

1. 모집단은 기존 kill-conditioned localized engagement 정의를 유지한다. G≈13.7초, D≈4,264u, R=1,600u, B=15초 등 운영 설정과 적용 예외는 기존 정의 문서가 지배한다. 새 단순 조건으로 이를 대체하지 않는다.
2. 교전을 사후 식별하고 해당 시점의 정보만으로 q를 계산한다.
3. 시간순 패치 분할을 유지한다. 기존 15.14 학습/15.15 검증/15.16 시험을 역사적 기준으로 두고 새 평가를 구분한다.
4. 소규모 패치 설정 수정으로 동작하는 프레임워크를 목표로 한다. 모든 패치에 성능이 동일하다는 주장은 하지 않는다.
5. 관측 가능한 전반적 상태로 한타의 가치 개선을 예측한다. 순간 위치·스킬 정확도·개인의 실행 능력은 충분히 관측하지 못한다.
6. SHAP을 주 q의 e스포츠 설명에 사용한다.

## 4. 마지막 킬 이후 유예 구간을 데이터로 정하는 계획

### 측정값

L_i: 교전 i의 마지막 킬 시각. T_ij: 오브젝트 j의 획득 시각. 양의 지연 d_ij=T_ij-L_i를 측정한다.

- 바론, 원소용 종류/스택/영혼, 장로, 전령, 유충, 아타칸별로 보고한다.
- 첫 적격 오브젝트까지의 시간과 여러 오브젝트를 연속 획득하는 시간을 구분한다. 첫 획득 평균만으로 전체 이득의 종료를 정하지 않는다.
- 패치·경기 시간·기존 교전 규모·지역별 표본 수, 평균, 중앙값, 분위수, 누적 분포를 보고한다.
- 오브젝트가 없는 교전 비율을 반드시 함께 보고한다. 미획득을 0초로 넣지 않는다.
- 경기 종료, 다음 관련 교전, 분석 관찰 한도 때문에 더 관찰하지 못한 표본을 따로 기록한다. 관찰된 획득만 평균내면 긴 지연이 빠지는 선택 효과가 생길 수 있다.

### 사건 연결과 중복

시간적으로 뒤에 있다는 이유만으로 해당 교전의 이득으로 귀속하지 않는다. 기존 공간/사건 귀속 규칙을 출발점으로 유지하고 아래를 따로 기록한다.

- 오브젝트 위치, 획득팀, 기존 교전 영역과의 관계.
- 동일 사건이 여러 교전의 후속 구간에 포함되는지.
- 중간에 새 교전이 있었는지, 원거리 동시 사건인지.
- 마지막 킬과 같은 시각의 사건은 d=0으로 별도 표시.
- 용 획득과 영혼 지급이 같은 전환을 표현하는 경우 연계한다. 중복된 독립 보상으로 더하지 않는다.
- 유충 개별 획득과 묶음 획득, 전령 획득과 사용은 별도 사건이다. 사용이 기록되지 않으면 추정과 관측을 구분한다.

### 유예 h의 선택

획득 지연의 평균은 중요한 첫 통계이나 그 자체를 h로 확정하지 않는다. 꼬리가 긴 분포라면 평균이 대표적 종료 시점을 주지 못한다.

개발 패치에서 h별 적격 사건 포함률, 중복/새 교전 혼입, 표본 유지율, 가치 라벨 반전율을 함께 비교한다. 데이터 분포에서 후보 h를 정하고 인접 후보의 민감도를 평가한 뒤 동결한다. 시험 패치 AUC가 높은 h를 선택하지 않는다. 오브젝트별 지연 분포는 보여주되 첫 버전은 해석 가능한 단일 h를 우선 검토한다. 오브젝트별 h는 복잡성 대비 이점이 검증된 경우에만 추가한다.

주 경계 후보 e_i=L_i+h. 다음 교전이나 경기 종료가 e_i보다 앞설 때 조기종료·제외·중첩 분석 중 무엇을 적용할지 사전에 명시한다. 미래 오브젝트가 없다는 이유로 교전 표본 자체를 제거하지 않는다. 이 문서 작성 시점에는 전체 적격 사건 지연을 아직 측정하지 않았으며 평균이나 h 수치를 확정하지 않았다.

## 5. 패치 적응을 검증하는 방법

- 공통 모듈: 정의 산출, 시점 안전 특징, 독립 가치 모델, q 학습·평가, SHAP.
- 패치 설정: 사건 타입/이름, 오브젝트 존재 여부, 규칙·아이템 스키마, 입력 매핑. 없는 오브젝트와 누락된 관측값을 구분한다.
- 학습/검증 패치에서 정의·가치 모델·유예·튜닝을 결정하고 시험에서는 동결한다. 시험 패치를 포함한 기존 pooled 정의/가격 실험과 '전체 파이프라인의 시간 외삽'을 구분한다.
- 순수 전이: 이전 패치만으로 학습, 새 패치에서는 사전에 알려진 규칙 매핑만 변경. 점수와 수정 항목을 기록한다.
- 소량 적응: 새 패치의 별도 초기 자료로 보정/재학습한 경우, 이후 시간상 분리된 자료에서 평가한다. 순수 전이 결과와 별도 표로 보고한다.
- 최소 수정 가능성을 파일/설정 변경 목록과 재학습 비용으로 입증한다. 특정 모델이 모든 패치에서 그대로 최고 성능을 낸다는 주장과 구분한다.

## 6. 글로벌 상황 기반 예측의 한계를 실험으로 연결

순간 포지셔닝과 스킬 정확도가 관측되지 않는다는 것은 입력의 제한이다. 이를 모든 잔여 오차의 원인으로 단정하지 않는다. 라벨 불안정, 오래된 snapshot, 분포 이동, 모델 적합 부족도 경쟁 설명이다.

필요 결과: 30초 안의 실제 snapshot 갱신 횟수와 고유 프레임 수; 경기 시간/사전 골드/사전 p별 성능; evidence 복원 비교; 공정한 학습기 비교; 오류 유형과 사례; q의 SHAP. 미관측 개인 기량이나 실제 스킬 적중을 SHAP으로 설명한 것처럼 이름 붙이지 않는다.

## 0. 기준과 적용 범위

이 문서는 대화에서 합의한 **목적 → 개선 → 예측 → 검증**의 순서를 유지한다. 기준 자료는 CoG paper 308, I1–I4 설계도([EXPERIMENT_DESIGN_MAP_20260919.md](EXPERIMENT_DESIGN_MAP_20260919.md)), 2026-09-19의 SVI·코호트·재선정 문서다.

여기서 분기는 **연구 범위와 원고의 분기**다. GitHub 브랜치·커밋은 이 문서만으로 생성하지 않는다. 원 데이터·코드·모델·라벨은 공통 실행을 덮어쓰지 않는 한 변경하지 않는다. 학과의 양식·분량·제출 일정·지도교수 요구는 제공된 자료로 확인되지 않으므로 임의로 설정하지 않는다.

공통 실험은 **한 번** 수행하고 두 원고가 같은 evidence_id로 인용한다. 석사 전용 심화(M01/M02)는 별도 버전이며 저널 주 모델을 자동 교체하지 않는다.

## 1. 공통 목적

> 공개 텔레메트리로 관측되는 교전 전 정보를 이용해, 정의된 교전과 후속 구간에서 어느 팀의 전략적 가치가 개선되는지를 예측하고, 그 예측이 반영하는 정보와 해석의 한계를 이해한다.

목적 수준의 ‘전략적 이득’과 실제 측정량은 구분한다. 실제 주 목표는 고정된 경기 승률 추정모형의 전후 변화가 양수인지 나타내는 SVI다. 이진 SVI의 예측확률은 기대 승률 증가량이나 전술 선택의 효용이 아니다.

CoG가 이미 했던 일을 누락하지 않는다. CoG는 킬 수만을 예측한 논문이 아니며, 고정 계수의 교환 가치와 운영적 라벨이라는 한계를 명시했다. 같은 표형 입력의 MLP와 시간순 패치 분할도 이미 포함했다. 후속 연구의 개선은 이를 처음 도입했다는 주장이 아니라 정의 근거·평가 범위·정보 비교를 확장하는 것이다. [S1]

## 2. I1–I4 공통 개선 구조

| 단계 | 개선 목적 | 핵심 산출물 | 해석 제한 |
|---|---|---|---|
| I1 교전 단위 | 사례의 시간·공간·규모 기준과 관측 시점을 더 근거 있게 정한다. | 교전 식별자, T/N 범위, onset/cutoff, 구간·제외 사유 | T 선택이나 데이터 기반 상수 자체가 ‘진짜 한타’의 검증은 아니다. |
| I2 결과 가치 | 수동 교환 계수를 경기 승패와 연결된 상태 가치 평가로 확장한다. | 고정 V̂, endpoint, ΔV̂, SVI, 측정 진단 | V̂의 승패 성능이 SVI의 독립 정답성을 보증하지 않는다. |
| I3 사전 예측 | 정보집합의 효과와 학습기 효과를 구분한다. | 동일 입력 모델 비교, 정보집합 비교, 선정·동결 q | 모델 우열과 정보의 본질적 유무를 동일시하지 않는다. |
| I4 의미·범위 검증 | 사례·라벨의 민감성, 초기 우세 의존, 조건별 품질, 전이를 점검한다. | PT/B40 비교, V 검증, 물질적 결과·Quiet, 외부 평가 | 검증은 목적을 대체하지 않으며, 효과의 부재나 인과효과를 자동 증명하지 않는다. |

I1의 사례·시간 경계는 **X와 Y 모두**에 연결한다. I2는 I1이 정한 사례·구간에 V̂를 적용한다. I4는 q만이 아니라 I1과 I2도 평가한다. PT는 역할상 I4의 비교 기준이지만 실행상으로는 I3의 학습·보정·동결 절차에 함께 들어간다.

‘검증’이 도식의 뒤에 있다는 것은 결과를 본 뒤 검증 기준을 선택한다는 뜻이 아니다. 대상, 지표, 하위집단, 동결 규칙은 해당 실행의 평가 전에 정의한다. 과거 TEST 노출이 있으면 탐색적 후속 연구 이력을 유지한다.

## 3. 공통 표기와 과제 계약

- W: 실제 최종 경기 승패. V̂는 W를 예측하는 지원 모형이다.
- p_pre = V̂(S_pre): 교전 전 상태의 최종 블루 승리확률 추정치.
- ΔV̂ = V̂(S_end) − V̂(S_pre).
- Y_SVI = 1[ΔV̂ > 0]: 블루 방향의 모델 추정 전략적 가치 개선 여부.
- q(X_pre): 주 교전 집단에 조건부로 SVI가 양성일 확률을 예측하는 모형.
- b(p): p_pre만으로 SVI 발생확률을 추정하는 기준모형. p_pre 자체와 사건이 다르다.
- PT: 사전 승률과 경기 시간을 사용하는 강화 기준모형.
- B40: 0.40 ≤ p_pre ≤ 0.60, B45: 0.45 ≤ p_pre ≤ 0.55. 둘은 연구 목적이나 정답 난이도 정의가 아니라 검증 집단이다.

일반적인 한타 승리, 최종 경기 승리, ΔV̂의 크기, SVI 발생확률, 초점 교전의 인과효과를 서로 바꾸어 쓰지 않는다. ΔV̂=0과 결측의 처리는 실행 계약을 확인하여 동일하게 적용한다. 임의의 중립대·중앙값 상대 라벨로 주 목표를 바꾸지 않는다. [S2]

## 4. 공통 자료·평가 범위

| 항목 | 공통 설정 |
|---|---|
| 주 원천 코퍼스 | 210,000경기, KR 15.14–15.16 |
| 역할 | 15.14 학습, 15.15 보정·선택, 15.16 평가 |
| 주 교전 | T; N은 보조·부록. N은 Quiet가 아니다. |
| 입력 | 현재 동일-정보 비교의 352개 사전 수치특징 계약 |
| 주 목표·시간 규칙 | 고정 V̂의 SVI, h90 주 규칙; h60/h120은 민감도 |
| 주 비교 | 동일한 15.16 평가 행에서 q와 PT의 ΔBrier; AUC·log loss·보정 동반 |
| 핵심 하위집단 | 전체 T와 B40; B45·시간대는 명시한 보조 분석 |
| 외부 | 등록된 KR/NA1 16.x를 분리 보고; 주 전이는 재학습 없이 적용 |

계약서의 원천 코퍼스 전체 기술통계와 홀드아웃 예측 성능을 분리한다. pooled T의 p_pre 통계와 TEST q 성능을 같은 행의 직접 비교처럼 사용하지 않는다. TRAIN in-sample q 성능을 합쳐 ‘210k 성능’으로 보고하지 않는다. [S3]

추가 실행의 시간·분리 검사도 공통으로 둔다. 예측 입력에는 실제 endpoint·미래 구간 길이·사후 참여자 수·최종 승패를 넣지 않는다. TRAIN 라벨 생성에 쓰는 V̂가 해당 경기의 최종 승패를 학습에 사용하지 않도록 경기 단위 교차적합 계약을 확인하고, 그 사례의 p_pre와 양 끝점에는 같은 제외-fold 모형을 사용한다. 학습 라벨용 모형과 평가 역할용 최종 모형의 연결은 manifest로 기록한다. 이는 입력의 시간적 이용 가능성과 자기 경기의 최종 결과 이용을 점검하는 규칙이며, 독립적 라벨 타당성이나 인과 식별을 보증하지 않는다.

학습기 선정은 Q_SELECT에서 수행한다. 현재 대화의 실행 상태인 LGBM 동결을 주 계보에 기록한다. 다른 후보의 새 재선정 실행이 존재하면, 해당 manifest를 확인한 뒤 새 버전으로 등록한다. 석사 분기에서 새 후보를 평가했다는 이유로 저널의 이미 고정된 주 모델을 자동 교체하지 않는다. 후보 목록·파일 경로는 실행 완료의 증거가 아니다. [S4]

## 5. 두 분기의 역할

| 구분 | 저널 분기 | 석사학위논문 분기 |
|---|---|---|
| 중심 | 개선된 교전·결과 정의 아래의 예측 문제와 그 근거 | 비동기 공개자료에서 과제를 구성·예측·검증하는 전체 연구 과정 |
| 범위 | 핵심 논지를 지지하는 결과에 집중 | I1–I4의 설계 이유, 대안 비교, 구현·측정·추론 연결을 상세히 전개 |
| RQ | J1 측정, J2 예측, J3 의미·범위 | M1 사례, M2 가치, M3 정보·학습기, M4 검증 |
| 공유 | 동일한 주 데이터·라벨·모델·평가 증거 | 동일한 주 데이터·라벨·모델·평가 증거 |
| 추가 깊이 | 필요한 대표 표·민감도 | 사전 정보군의 단계적 구성 분석, 실패·불확실성 및 설계 이력 |
| 종료 기준 | 정한 주장을 증거에 맞는 범위로 답하고 제한을 보고 | 전체 설계에 대한 이유·근거·재현 가능한 평가를 연결해 설명 |

학위논문은 저널보다 모델을 많이 돌리거나 동일한 문장을 늘리는 버전이 아니다. 저널도 학위논문의 모든 장과 실험이 끝날 때까지 무조건 대기하지 않는다. 공통 핵심에 영향을 주지 않는 학위논문 전용 분석은 독립적으로 진행한다.

## 6. 버전 관리·공유 규칙

공통 실험은 한 번 실행하고 하나의 evidence_id를 부여한다. 두 원고는 그 evidence_id를 다른 상세 수준으로 인용한다. ‘같은 데이터를 썼다’가 아니라 동일한 사례 키·label_version·input_version·모델·가중치·평가 역할을 확인한다.

공통 ledger 최소 필드:

`evidence_id, source_commit, corpus_version, detector_version, label_version, input_version, split_role, cohort, model_manifest, weighting_rule, primary_metric, comparison, status, evaluation_exposure, source_path, journal_use, thesis_use`

- 상태: planned / reported / reproduced / accepted / superseded. reported를 reproduced로 오인하지 않는다.
- 공통 라벨·분할·제외 규칙이 바뀌면 두 원고에 동시에 변경 이력을 남긴다.
- 석사 전용 변형은 별도 input_version/experiment_id로 저장하고 기존 frozen 산출물을 덮어쓰지 않는다.
- CoG에서 이미 공개한 내용과 새로 추가한 부분을 원고 안에서 밝히고, 서로 겹치는 실험은 같은 실험임을 명시한다.
- 학위논문·저널의 공개 및 재사용에 관한 구체 정책·권리 문제는 제출 시 해당 기관·학술지의 실제 규칙을 확인해야 한다. 이 초안은 그런 허용을 보증하지 않는다.

## 7. 평가 결과에 종속되지 않는 진행 조건

SVI의 양성 확률이 높아야 한다거나, 특정 학습기가 반드시 1등이어야 한다거나, B40에서 반드시 유의해야 한다는 조건을 두지 않는다. 개선의 방향은 정의 근거·정보 비교·검증 절차를 강화하는 것이며, 성능 방향은 결과로 남긴다. 다만 실행상 결함·혼합 표본·누수 때문에 비교가 성립하지 않는 문제는 ‘음성 결과’로 포장하지 않고 수정한다.

두 목표의 라벨·코호트가 달라지면 CoG AUC와 새 SVI AUC의 차이를 곧바로 개선 효과라고 부르지 않는다. 원 CoG의 제한과 설계는 존중하고, 재구성·변경의 범위와 이유를 설명한다. [S1, S3]

# 사용자 조건 정정: 21만 경기 전체 패치 분할

2026-09-15 사용자 재확인. 이 문서가 기존 야간 명세의 소규모 분할 재사용 지시보다 우선한다.

## 요구와 실제 실행의 차이

요구: 21만 경기 코퍼스를 대상으로 15.14 TRAIN,15.15 VALIDATION,15.16 TEST, 최신 경기 데이터 별도 TEST. 최신 TEST로 보정/선택/재학습하지 않는다. VALIDATION 내부 보정·선택 분리는 허용되는 구현 방식일 수 있지만 TRAIN/TEST 패치 경계를 침범해서는 안 된다.

기존 전체 캐시 조사 outputs/postkill_objective_delay_full/results.json의 수: 15.14=74,673경기,15.15=74,748경기,15.16=60,579경기, 합210,000경기. 이 수는 과거 전체 조사에서 확인된 캐시 경기 수이며 지금 원시파일 전부를 재스캔한 수가 아니다. 실제 한타 학습행은 고정 engagement 정의의 적격 사례만 생성하며, 검출 없음/부적격/결측 제외는 전수 집계해야 한다.

실제 야간 P1/P2는 기존 50k 실험에서 추출한 V용14,993경기의 기존 분할을 유지했다. 이 V분할은 전체 패치 분할 연구의 대체가 아니다. P3/P4는9,198경기/26,693교전만 사용했다. P4 q는 패치 순서를 지켰으나 train3,218경기,validation3,325경기,test2,655경기로 전체 코퍼스가 아니었다. 최신 데이터의 신 V/q 테스트는 하지 않았다. 따라서 이번 결과를 전체 조건 충족/최종 성능으로 보고하면 안 된다. Codex가 작성한 명세에서 범위를 잘못 고정한 책임이며 Opus가 데이터를 임의로 축소한 문제가 아니다.

## 유지할 것과 다시 해야 할 것

- 기존 P1–P4는 구현·누수 방지·경계·설명 방식 점검용 파일럿으로 보존한다. 숫자를 지우거나 전체 결과로 바꾸지 않는다.
- 기존 검출 정의와 상태 스키마/종료 규칙은 유지하되 전체210,000경기의 경기 ID/패치 매니페스트를 먼저 검증한다. 모든 적격 교전 및 제외 이유를 패치별로 집계한다.
- V와 q 모두 외부 패치 경계를 존중해야 한다. V가15.16 최종결과로 학습된 채 그 패치의 q 라벨을 만드는 구조는 금지한다. 기존 파일럿 V모델을 그대로 전체본의 라벨러로 사용하지 않는다.
- 전체 TRAIN을 활용하면서 같은 경기 결과를 본 V로 TRAIN 라벨을 만드는 문제는 경기단위 out-of-fold 가치예측 등으로 설계해야 한다. cross-fitting 분할/보정/선택 경로를 사전 명세하고 검증한 뒤 실행한다. OOF만으로 모델 기반 라벨의 의미 타당성이 증명되지는 않는다.
- 15.15는 검증/보정/선택용,15.16 및 최신 데이터는 동결 모델의 평가용이다. 원래 검증/테스트의 역할을 바꾸거나 최신 테스트에 맞춰 적응 보정을 주결과에 섞지 않는다.
- '최신 데이터'의 실제 캐시/패치/기간/과거 접근 이력을 확인한다. 과거 확인한26.13이면 별도 미래시점 테스트일 수는 있어도 미사용 테스트라고 부르지 않는다. 존재가 확인되지 않은 새 패치 데이터를 가정하지 않는다.
- 전체본의 재학습·라벨 재생성·q 학습·패치별/최신 평가·SHAP가 끝나기 전 완료라 보고하지 않는다.

현재 상태: 범위 오류 확인과 계획 정정. 전체본 실행은 아직 시작하지 않았다. 다음 명세는 이 조건을 기준으로 작성해야 한다.

# 통합 검증: 실행 전 동결 기록

2026-09-14. 사용자 승인: 문헌 기반 다음 단계 전체 실행 및 전후 기록. 현재 15.16 결과를 이미 보았으므로 본 명세는 전향적 사전등록이 아닌 추가 분석 실행 전 기록이다.

## 변경 전

- 기존 모집단, B+90 라벨, 고정 V 유지. 60/120은 민감도.
- q 비위치 AUC .55807 / Brier .254335 / log loss .703702; 위치 .56119 / .253549 / .702036. 학습 비율 상수 .5 / .250009 / .693165.
- 위치 차이의 95% CI는 0 포함. 위치 무용성 또는 동등성은 입증되지 않았다.
- V는 별도 fit/calibrate/select/test 분할에서 학습·선택 완료. expanded_sigmoid 고정. 가치 모델을 자동 교체하지 않는다.
- q 보정, 사전 확률만의 학습 기준선, 새 라벨의 SHAP, 독립 의미 검토, 미사용 미래 패치 검증은 미완료.

## 이번 실행

1. 저장 V의 독립 test 경기: 동일 1경기 1시점 원래 표본 지표 재현, 보정 절편/기울기/곡선, 전체 시점 시간대 및 오브젝트 획득 이력별 지표. 최종 승패가 정답. 기존 시험표본이며 새 외부 자료가 아니다.
2. q: 15.14 학습/15.15 보정·선택/15.16 탐색 평가. 상수, p_pre 로지스틱, p_pre spline 로지스틱, 경제·전광판 LightGBM, 전체 비위치/위치 기존 모델, 정규화한 단순 비위치 모델을 비교한다. 후보 선택은 15.15 Brier 최소, 동률 log loss. 테스트로 선택하지 않는다.
3. 기존 q 및 새 경제 모델에 raw/sigmoid/isotonic 비교. sigmoid/isotonic은 15.15에서만 맞춘다. 보정 학습 자료에서의 지표는 낙관적일 수 있으므로 선택 진단으로만 사용한다. 선택된 결과의 15.16 평가는 여전히 탐색이다.
4. 경기별 총가중치 동일. 주요 q 지표 차이는 평가 경기 bootstrap 500회, 고정 모델 조건. 보정도 평가 자료에서 재학습하지 않는다.
5. B90 종료 상태에서 대안 Maymin V 라벨과 기존 V의 일치율, 작은 |ΔV| 및 기간별 진단. 60/90/120 기존 자료 재사용. 성능을 높이기 위한 라벨/임계값 변경 없음.
6. 기존 비위치 LightGBM의 TreeSHAP을 계산하고 합계와 raw margin 재현, seed/패치별 특징군 순위 안정성을 확인한다. 보정 후 q의 SHAP이라고 오표기하지 않는다. 가능하면 선택 단순 모델도 해당 척도로 설명한다.
7. 독립 검토용 층화 사례 패키지와 가려진 평가 양식을 생성한다. 사람 평가가 없는 상태에서 전문가 타당성 검증 완료라고 쓰지 않는다. 미사용 후속 패치 존재 여부를 조사하고 없으면 준비 상태와 필요한 자료를 기록한다.

## 실행 중 방법 수정: 보정과 선택 분리
첫 실행의 isotonic 보정 학습과 후보 선택이 같은 개발 표본을 사용해 유연한 보정기에 유리할 수 있음을 확인했다. 해당 결과는 pilot_shared_development로 보존한다. 최종 추가 분석은 15.15 경기를 SHA256('calibration17:'+match)의 앞 8자리 정수 mod 2로 분리해 0에서 보정, 1에서 후보 선택한다. 정규화 로지스틱에도 sigmoid/isotonic 후보를 추가한다. 15.16을 이미 관찰한 뒤의 방법 수정이므로 엄격한 미사용 시험이라고 주장하지 않는다. 이후 후속 시즌 평가 전에 모델을 동결한다.

## 후속 시즌 이전 평가 표본 동결
기존 replay_goldset_2026_26_13의 사전 선정 100경기를 사용한다. 원래 2026-07-15 시간층화 추출 표본이며 detector 기술 점검에 사용됐다. 이번 q/V 성능으로 재선정하지 않는다. 원본 detail/timeline 해시를 대조하고 현재 v3.3 모집단 탐지기로 다시 추출한다(기존 2026 검토의 10초 시작/소규모 pick 등 정의를 재사용하지 않음). 동결 V와 q, 15.15에서만 학습한 보정기를 무수정 적용한다. 큰 시즌 차이와 100경기 표본 한계를 명시한다. 외부 자료에서 추가 보정이나 모델 선택을 하지 않는다.

## 외부 평가 확대: 결과 확인 전 규칙
100경기 예비 이전 평가 후, 수집 DB에서 complete/16.13/queue420/map11 전수를 고정하고 예비 100경기를 제외한다. 생성 시간순 앞 30%를 제한적 적응 자료, 뒤 70%를 평가 자료로 사용한다. 선택 q(ridge_sigmoid)와 V는 동결하며, 무수정과 적응 자료에서만 추가 sigmoid 보정한 결과를 동일 후기 경기에서 비교한다. q의 Y는 원래 고정 V에서 산출하고, V 보정 결과를 다시 라벨에 반영하지 않는다. 모델 선택이나 특징 변경은 하지 않는다. 예비 표본을 본 뒤의 확장이라는 이력을 공개한다.

## SHAP 보조 진단
선택 로지스틱 모델에서 동일 C와 분할/보정 규칙으로 직접 오브젝트 이력, 사전 승률, 경제·경험치, 킬·생존 특징군을 각각 제거한다. 주모델 재선택에 사용하지 않는다. 직접 오브젝트 제거에도 p_pre 등 간접 정보는 남으므로 오브젝트의 총영향 제거로 해석하지 않는다. 결과를 본 뒤 설계한 탐색적 설명 검증으로 표시한다.

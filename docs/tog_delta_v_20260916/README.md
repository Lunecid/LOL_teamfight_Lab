## 2. 범위와 금지 사항

- 대상은 **모델이 정의한 결과**다. `Y = 1[ΔV_h90 > 0]`, 즉 동결된 승률 가치 모형 `V`의 추정 승률이 교전 구간 전후로
  상승했는지의 방향이다. 한타 승패의 정답이 아니고, 최종 경기 승률도, 변화량도, 인과효과도, 교전 발생 예측도 아니다.
- 사후적으로 식별한 kill-conditioned engagement만 다룬다. 킬 없는 전투·존잉·시야 통제는 **정의상 제외**된다.
- 저자·소속·감사의 글·윤리 승인·익명 저장소 링크는 **의도적으로 비워 두었다**(날조 금지). 투고 단계의 미완 항목이다.
- 구간이 0을 포함하면 "동등성"이 아니라 **미결(inconclusive)** 로만 쓴다. 동등성 검정은 어디에서도 수행하지 않았으므로
  "동률(tie)", "통계적으로 구별되지 않음", "학습기 선택은 무의미" 같은 표현은 초안 전체에서 금지한다.
- 라벨 계보는 **세 갈래로 분리**한다: ① 출판된 CoG 308 수동 교환 점수(가중 합, α=exp(2p)/Σexp(2p), 특수 이벤트 규칙),
  ② 옛 코드베이스의 중간 `market_event` 실험(이번에 구현을 재확인하지 않았으므로 ①과 동일시하지 않는다),
  ③ 현재 `ΔV` 표적. 옛 수치·방법·모델 순위는 현재 표적과 섞지 않고 계보 설명에만 둔다.

## 3. 이번 통합에서 바로잡은 것 (요약)

전체 목록은 [claim_evidence_ledger.md §3](claim_evidence_ledger.md) 참조. **부모 findings의 수치는 바꾸지 않았고
해석만 좁혔다. 상충하는 과거 문장은 역사 기록으로 그대로 보존한다.**

1. **포지션 가정.** StateV2 슬롯은 `(team_id, participant_id)` 순서다. 슬롯 쌍 특징은 "**위치 대리 가정 하의
   슬롯 인덱스 쌍**"이며 검증된 라인/역할 매치업이 아니다. 주 코퍼스에서 캐시 role_slots 순서와 참가자 순서의
   불일치는 1.69%(3,548/210,000)이고, 나머지 98.3%의 일치는 슬롯별 역할 정확성을 증명하지 않는다.
2. **챔피언 클래스 결론.** "개선하지 않는다 / 학습할 것도 없다 / 그래프로도 나올 것이 없다"는
   **"이 설정에서 이득이 검출되지 않았다"** 로 축소했다. Track B 그래프, 세부 클래스, 다른 학습기는 시험하지
   않았으므로 배제되지 않는다. draft-only AUC≈0.50도 "정보 없음"의 증명이 아니다(고정 `C`, 제한된 예산).
3. **정의 민감도.** "TEST 패치 포함 우려가 닫힌다"를 **"결과의 크기를 한정하지만 이력을 제거하지는 않는다"** 로
   바꿨다. `D=4,285 u`는 pooled 95% 구간 [4,256.0475, 4,273.9677] **밖**이고, 재적합−동결 −0.00007
   [−0.00023, +0.00010]은 동등성이 아니며, N과 KR 16.13 T는 오히려 나빠졌다. "2% 변경" 대신
   **경기 3.3–4.4% 변경, 노출 행 제거 1.85–2.4% / 추가 1.15–1.5%** 를 분리 보고한다.
4. **MLP 해석.** "즉시 과적합한다"는 고정 예산(lr 1e-3·batch 512·patience 10)에서의 **정황**이지 증명이 아니다.
   "신경망이 LightGBM을 넘지 못했다"는 5개 표 형식 family·family당 6설정·3시드 범위로 한정한다.
5. **균형 상태 SHAP.** B40에서 오브젝트·경제의 **상대 비중** 증가는 주로 `p_pre` 절대 기여 감소(0.097→0.022)의
   결과이며, 셀 정의상 일부는 당연하다. 그룹 |φ|는 ΔV 총량의 몫도, 교환 가격도, 인과 기여도 아니다.
6. **B40 일반화 금지.** T B40에서 LightGBM−PT는 미결이지만 같은 셀의 logistic−PT는 logistic 우세다. 따라서
   "균형 상태에서 전체 입력 모델은 도움이 안 된다"로 요약하지 않는다.
7. **수치 재현 주의.** base LightGBM은 부모와 정확히 일치(차 0)하지만 logistic raw는 6e-7~3.4e-5, N isotonic은
   최대 0.0118까지 차이가 난다. 같은 실행 안의 비교라고 해서 수치 불확실성에서 자동으로 자유롭지 않다.
8. **인용 한계.** Kim은 보정 동기(손실 미구현), Hodge는 라이브 Dota2 선례(LoL 재현 아님), Maymin은 상태 조건부
   가치평가 선례(정확한 재현·인과 식별 아님), Halfaker는 세션 분리 유비(동일 알고리즘 아님),
   Schubert는 encounter 분석 선례(우리 상수의 증명 아님), Lundberg&Lee는 귀속 원리(인과 설명 아님)로만 쓴다.

### 3.1 2차(교정) 패스에서 추가로 바로잡은 것

독립 과학 리뷰([independent_scientific_review.md](../../outputs/manuscript_integration_20260916/independent_scientific_review.md))와
[revision_request.md](../../outputs/manuscript_integration_20260916/revision_request.md)가 1차 초안 자체의 오류를
지적했다. 전체 대조표는 [claim_evidence_ledger.md §3.1](claim_evidence_ledger.md)(X-21~X-34)에 있다.

9. **"세 family 동률"·"학습기 선택은 무의미" 삭제.** 0을 포함하는 구간은 미결일 뿐이며 residual MLP는 실제로 더
   나쁘다. 지정한 개별 대조만 서술한다.
10. **"h60/90/120에서 순위 불변" 삭제.** 개별 비교 패턴은 유지되지만 정확한 순위는 바뀐다(h60에서 plain MLP의 T
    점추정치가 최저). h60의 낮은 Brier는 **표적이 다르므로** "더 쉬운 과제"의 근거가 아니며, h90을 TEST 순위로
    정당화하지 않는다.
11. **"봉인 지표 0.0002 이내" 일반화 삭제.** 주 TEST T 동결 LightGBM의 Brier는 0.228391 → 0.22837이고, dev 재적합−동결 T는
    −0.00007 [−0.00023, +0.00010] (미결)이지만 N은 +0.00023, 외부 KR 16.13 T는 +0.00052로 **악화**한다. 외부 동결
    Brier 변화는 약 0.0007까지 간다. 주 TEST에서도 AUC 변화는 약 0.00075까지 관측되어 모든 지표에 같은 상한을
    적용할 수 없다. 정의의 TEST 의존 이력은 한정될 뿐 제거되지 않는다.
12. **프레임 진단 두 가지 구분.** "마지막 킬 이후 새 프레임 없음"(전체 유효 행 35.145%, T 35.27%)과 "pre/post가
    같은 프레임"(T 2,224/32,981 = 6.74%)은 다른 모집단이다. 후자만 프레임 기반 변화가 사라지고, 그 층에서도
    경과시간·×time 항은 변하므로 "사건 열만으로 라벨이 결정된다"고 쓰지 않는다.
13. **기여도≠계수.** 0.110/0.102는 열별 평균 |기여|이고 실제 계수는 blue −1.0564 / red +0.9901로 부호가 반대다.
    작은 |ΔV| 층의 구조물 19.3%는 **전체 T 9.6%**(또는 >2pp 층 7.9%)와 비교해야 한다. 챔피언 블록은 기록된
    **1,382열**(변환 1,733열 = 수치 351 + 1,382)이며 1,372가 아니다. 검증 오차는 실측 3.042e-14 / 6.231e-12.
14. **B40 해석 한정.** 미결인 것은 LightGBM−PT이며 같은 셀의 logistic−PT는 0을 제외한다(탐색적·다중비교 미보정).
    "균형 상태의 잔여 신호는 해소 불가"로 쓰지 않는다. N 이득의 원인(국지 상태 대 전체 판세) 설명도 미검증이므로
    제거했다.
15. **"pre-registered" 표현 제거.** 외부 사전등록 기록은 확인되지 않았으므로 "이 탐색적 후속 프로토콜에서
    사전 선언(predeclared)"으로 쓰고, 선행 TEST 노출 사실을 함께 유지한다.
16. **구간 종류 구분.** 고정 모형의 **경기 부트스트랩** 지표 구간, SHAP 256행 **행 부트스트랩** 서술 구간,
    경계상수(G/D) 추정 부트스트랩, 인용 문헌의 구간은 서로 다른 대상이다.
17. **리뷰 매트릭스 출처 교정.** 리뷰어가 제시한 6개 참고문헌 중 [1] Schubert2016은 검증·인용되었고 나머지
    **5개**만 미검증이다. 새 이슈 ID는 옛 매트릭스와 다른 **새 통합 ID**이며 crosswalk를 넣었다. family당 6개 후보
    구성과 3시드 평균(확률적 LightGBM·MLP만)을 구분했고, CE-5는 우리 쪽 **제안 확장**, CE-6는 우리 쪽 결과로
    다시 표기했다.

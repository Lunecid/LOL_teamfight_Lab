# 불필요한 부속 코드 정리 결과

사용자가 요청한 아키텍처 정리에 따라 연구 실행과 분리된 저장소 내부 에이전트 설치 도구 묶음을 폐기했다. 개발자가 별도로 수동 실행할 수 있던 부속 기능을 의도적으로 제거한 결정이며, 외부 프로젝트 전체가 죽은 코드라는 주장은 아니다.

- 삭제: `master_ver/tooling/`의 추적 파일 47개. 설치기, vendored 설정·프로필·도우미 코드, 벤치마크, 도구 그림과 중복 안내를 포함한다.
- 보존: 라이선스 전문 2개, 원본 설치 provenance manifest, 폐기·복구 설명을 [보존 문서](../../retired-agent-tooling/README.md) 4개로 옮겼다. 원본 3개는 RAW SHA256와 전체 내용이 보존됐다.
- 지침: Master AGENTS의 선택적 도구 라우팅 문장 한 줄만 현재 공통 작업 지침으로 연결했다. 연구 요구사항·분할·날짜·기존 template는 그대로다.
- 원래 파일 바이트 1,610,649 삭제, 보존 문서 27,090 추가, 지침 수정 +10바이트로 순 파일 바이트 1,583,549가 줄었다. 파일 시스템 할당량이나 무시된 로컬 로그를 포함한 디스크 절약량은 아니다.

원본은 Git 커밋 `4bdc77953f3bfbaa852f954f1846f907384383a3`의 같은 경로로 복구할 수 있다. `_compat`, 실제 학습·평가 코드, 과거 연구 스크립트·잠금 결과, 데이터·가중치·보호된 분할은 삭제하지 않았다. 전역 사용자 에이전트 설치나 설정도 변경하지 않았다. 단순한 참조 검색 0건만으로 동적·수동 사용이 절대 없다고 주장하지 않는다.

구현자는 정확한 47개 추적 경로, 보존 해시, 현재 문서 링크, 남은 entrypoint와 설치기 참조를 제한 검사했고 마지막 CPU1 검사는 0.374초였다. 독립 검토는 [별도 검토 문서](2026-10-25-junk-retirement-review.md)를 따른다. 과학 실험을 다시 실행한 결과가 아니며 학습 속도 향상을 측정한 변경도 아니다.

GPU 측정 실행 커밋 `f867a51e582bd5f4011e6cc52b6f3476deb1b75a`과 그 깨끗한 실행 checkout에는 이 삭제를 적용하지 않았다. 실행 중인 모델·입력·이전 S CPU 결과를 바꾸지 않기 위해 정리는 별도 개발 트리에서 수행했다. 동시 개발 활동은 제어 폴더 developer-activity.json에 기록한다.

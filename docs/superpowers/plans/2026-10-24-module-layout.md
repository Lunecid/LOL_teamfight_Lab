# 모듈별 코드 배치 작업 계약

2026-10-24 저자는 코드가 난잡하므로 모듈별로 실제 묶으라고 요청했다. 이전 세 프로젝트 모듈화·독립 검토·Gemini 보조·GitHub 게시 승인은 계속 적용한다. 기준 구현은 d9d7ac8이고 공개 기준은 9385740이다.

## 범위

- 역할별 하위 패키지로 구현을 이동하고 기존 import/CLI는 작은 호환 진입점으로 유지한다. 단순 문서 인덱스만 추가해 완료라고 하지 않는다.
- EPT는 data, preprocessing, domain, valuation, models로 나눈다. ept/runtime 패키지는 유지하고 위치 의존 설정·고정 pins·실행 진입점과 보호된 cohort 코드는 이동하지 않는다.
- CoG/Master는 좁힌 후보의 경로·직렬화·하위 프로세스 의존을 확인한 뒤 실제 묶을 수 있는 코드만 옮긴다. 과거 날짜별 연구/결과는 새 정의로 합치지 않는다.
- common_training_r1은 입력·모델·보고·학습의 경계를 유지하며 탐색하기 쉬운 배치를 만든다.
- 두 언어 README 및 탐색 안내는 최종 물리 배치와 일치시킨다.

## 보존할 계약

- 기존 이름과 새 이름이 같은 모듈 객체를 가리키도록 하여 monkeypatch와 전역 상태를 보존한다. 실험 수치·데이터·분할·라벨·난수·체크포인트 스키마는 바꾸지 않는다.
- 원본 Master와 실행 중인 S4 체크아웃, D:\LOL_Data의 실행·입력·가중치를 변경하지 않는다. 보호된 cohort/holdout/split 모듈 본문은 열거나 재작성하지 않는다.
- 원고·잠금 문서의 기존 수치는 수정하지 않는다. 기존 사용자 변경을 되돌리지 않는다.
- 실제 학습/벤치마크 없이 AST 동등성, import identity, 합성 오류 경로, 제한한 기존 단위 검사로 확인한다. CPU 1스레드, GPU 사용 안 함.

## 역할과 수용

구현 작업자의 자체 시험과 별도 독립 검토를 분리한다. 리드는 설계·통합·Git 게시를 맡고 Gemini는 작은 설명·주석 초안을 보조한다. Strata는 계속 끈다. 수정과 리뷰는 동일 파일을 동시에 덮어쓰지 않는다.

물리 이동 목록, 의도적 호환 파일, 남겨 둔 연구 경로, 실제 통과/실패/미실행을 보고한다. 새 정의나 과거 hash-bound 실행의 재개 승인을 뜻하지 않는다. 게시 시 기존 공개 소스 스냅샷을 부모로 하고 코드·문서만 정상 fast-forward한다. 실험·입력·비공개 과거 이력은 게시하지 않는다.

# 마지막 Codex 설계와 현재 Claude 작업의 차이

확인일: 2026-09-14. 읽기 기반 대조이며 재실험·원고 수정은 하지 않았다.
기준: Codex `ece1168`의 temporal v2 설계 및 `CLAUDE_NEXT_STAGE_HANDOFF.md`.
현재 확인: worktree `15751e8`, 원본 원고 브랜치 `f0cbe00` 및 작성 중 파일.
Claude 작업이 진행 중이므로 이 문서는 해당 시점의 설계 비교 기록이다.

## 1. 전체 판단

Claude는 Δ승률 예측을 생략한 것이 아니다. v2 검증에서 발견한 오류를 v3에서 개선하고,
Δ 부호 분류·크기 회귀·|Δ| 가중 학습을 실제 수행한 다음 결과와 가치를 두 축으로 나눴다.
따라서 단순한 설계 이탈이 아니라 실험에 따른 재설계와 CoG 리뷰 대응으로의 범위 확대다.
문서에는 9월 10일 D1~D4 결정과 같은 날 수정 합의가 기록돼 있다. 현재 대화에 그 결정 과정
전체가 없다는 이유로 승인 없는 변경이라고 단정하지 않는다.

가장 큰 잔여 차이는 사용자에게 제공하는 출력의 시점이다. 현재 두 축 출력은
사전의 물질적 교전 승자 확률과 사후의 관측 Δ승률을 함께 보여 준다.
사후 Δ를 붙였다는 사실만으로 교전 전에 Δ의 방향·크기를 예측하는 시스템이 완성되지는 않는다.

## 2. 항목별 대조

|---|---|---|---|

## 3. 출력 재설계의 실제 근거

`docs/CLAUDE_V3_PREDICTOR_REPORT.md`와 `outputs/engagement_predictor_v3/results.json`:

- 전체 26,712행의 비가중 sign Δ 모델 AUC 0.62426.
- market_event가 결정된 공통 25,177행에서 sign Δ 모델은 자기 표적 AUC 약0.6344,
  market_event 모델은 자기 표적 AUC 0.66489.
- |Δ|를 추가로 학습 가중한 모델은 공통행 sign Δ AUC 약0.5885로 내려감.
  반면 |Δ| 가중 평가 AUC는 올라가므로, 단순히 가중이 항상 해롭다고 일반화하면 안 된다.
- |Δ| 회귀 Spearman 약0.458/R² 약0.192. 사전 headroom 한 변수 모형의 Spearman 약0.462.
- 부호 있는 Δ 회귀는 약한 성능. downstream 별도 실험에서 X만으로 end Δ R²=0.023716.
- 실제 market_event 결과만 주면 R²=0.549710, X와 실제 결과를 함께 주면 0.656513.
  실제 결과를 쓰는 행은 사후 설명력이며 사전 예측 성능이 아니다.

판단: Δ 예측이 쉬운 주 표적이 아니라는 실험 근거는 생겼다. 그러나 서로 다른 정답에 대한
AUC 0.665와 0.634의 차이는 그 자체로 더 타당한 결과 정의를 선택하는 증거가 아니다.
market_event가 물질적 교환을, Δ가 관측 경기 가치 변화를 잰다는 의미 차이를 먼저 설명해야 한다.
약한 결과 역시 현재 입력·모형·표본에서 얻은 결과이지 Δ 예측 불가능성의 증명이 아니다.

## 4. v2의 한계 중 해결된 것과 남은 것

v2에서 snapshot_age_s 단독 외삽 오류를 없앤 것은 첫 수정이었다. Claude A/B/C는 그 이후에도
장로 입력 반응이 획득팀 기준 2/52건만 올바른 방향이고 후반 표본이 희소함을 발견했다.
v3은 30분 이후 fit 표본을 211→2,517행으로 늘렸고 같은 검사에서 장로 52/52,
전체 오브젝트 411/412건의 기대 방향을 보였다. 이는 입력 반응 검사이지 인과 가치 검증이 아니다.
C도 0.01→0.001로 재선택됐으므로 표집 변화만의 독립 효과라고 단정할 수 없다.

경계 민감도는 남았다. v3에서도 end→+60초로 옮기면 약20.4%의 방향이 달라진다.
마지막 킬을 채택했어도 실제 전투 종료를 관측하게 된 것은 아니다. 한타 뒤 오브젝트를 취득하는
시간 구간을 연구 범위로 어디까지 볼 것인지라는 의미론적 선택은 계속 남는다.

## 5. 입력 개선은 유력하지만 이전 파일럿과 구분해야 함

기존 hold 입력에 event-based evidence block 306개 열을 추가했다. 과거 50k 파일럿은
위치 오차 곡선을 평가 경기에서 추정하는 문제가 발견되어 새 평가로 대체됐다.
최신 원고 `docs/tog_manuscript/sec_limit.tex`는 이 문제를 명시하고, 평가 패치와 분리한
보정 자료로 곡선을 다시 추정한 전체 코퍼스 결과를 사용한다.

15.14 학습 / 15.15 검증 / 15.16 시험, 시험 153,816교전에서:

| 입력 | AUC |
|---|---:|
| X | 0.666484 |
| X + 같은 형식의 hold 열 | 0.668163 |
| X + evidence 열 | 0.673239 |

Evidence−X +0.006755 [0.005700,0.007757], Evidence−Hold +0.005076 [0.004083,0.006042].
주장 가능한 범위는 '관측 상태의 개선이 이 설정에서 도움이 된다'다.
아직 끝나지 않은 경쟁 학습기 비교 전에 '병목은 모델이 아니라 정보다'로 확대할 수 없다.
최신 원고는 제목에서 이 단정을 뺐다.

## 6. 과거 보고서와 최신 원고의 갭도 있음

- 과거 요약의 '같은 AUC 0.665인 합성 예측기만 스태킹을 개선'은 서로 다른 표적을 혼동했다.
  최신 원고는 비교 표적을 맞추고 정보 출처와 예측 정확도를 분리해 입증하지 못했다고 제한한다.
- 실제 market_event 예측기를 넣은 수정 실험 AUC 0.812522 대 상태만 0.812387,
  차이 CI [-0.00099465,0.00129165]. 여전히 개선의 확실한 증거는 없다.
  이는 교전이 경기 결과에 중요하지 않다는 결론이 아니다.
- '중요한 교전일수록 예측 불가능'은 실현 |Δ|로 층화한 선택 효과 문제로 정정됐다.
  `CLAUDE_V3_PREDICTOR_REPORT.md`의 후반부에는 과거 강한 문구가 남지만
  `CLAUDE_FULL_PIPELINE_SUMMARY.md`는 그 결론을 철회한다.
- '원소 드래곤은 즉시 골드를 주지 않아 0'이라는 과거 요약 설명은 최신 원고와 다르다.
  최신 `sec_label.tex`는 회귀 추정치에 CS 계수를 더해도 음수라 0으로 자르는 구현과
  규칙 가격 해석·민감도를 별도로 설명한다. fitted zero를 게임 규칙상 zero와 동일시하면 안 된다.
- `downstream_winprob.json`의 시간대별 paired CI에는 타깃/예측 행 정렬 오류가 있다.
  최신 `sec_limit.tex` 상단은 이를 이미 알고 해당 CI를 인용에서 제외한다.
  새 발견으로 중복 보고하거나 그 CI를 결과로 다시 사용하지 않는다.

## 7. 이론 해석에서 추가로 구분할 것

최신 원고는 martingale 관점으로 사전 예상 변화가 작고 승리/패배 시의 폭이 비대칭일 수 있다고
설명한다. 이는 마지막 Codex 설계에 없던 중요한 이론적 보강이다.
단, 확률 bin 보정(ECE가 작음)만으로 martingale 성질이 성립하지는 않는다.
중첩된 정보집합에 대한 정확한 조건부 기대값이라는 가정과 시점 선택 조건이 필요하다.
현재 사전 cutoff는 미래 킬로 선택되고, 입력은 전체 이력이 아닌 제한된 상태 표현이다.
원고도 미래 기반 시점 선택을 제한으로 적지만, 편차가 반드시 작다는 보장은 별개다.

또한 E[Δ|정보]=0이어도 P(Δ>0|정보)=0.5이거나 방향 분류가 불가능한 것은 아니다.
예를 들어 80% 확률의 +5%p와 20% 확률의 -20%p는 기대 변화0이면서 방향은 불균형이다.
평균 변화 회귀의 어려움, 부호 분류 가능성, 조건부 이득/손실의 폭을 서로 바꾸어 말하지 않는다.

## 8. 갭을 반영한 현재 이해

현재 프로젝트는 '교전 전후 승률 변화를 계산하는 모델'에서
'데이터 기반 교전 정의 → 물질적 결과 예측 → 독립 가치 모델로 사후 영향 해석 →
정보·관측·학습기의 한계 검증'으로 발전했다.

보존할 것: 정의 산출, 독립 가치 모델, 오브젝트 사건 반영, 시점 안전성,
경기 분할, 입력 재구성, 반증 후 주장 축소.
다음 설계 판단의 핵심: 논문의 최종 사용자 출력이 사전 결과 확률 + 사후 Δ로 충분한가,
아니면 사전 결과 확률과 함께 '이길 때/질 때의 예상 가치 폭'을 요구하는가.
후자는 현재 retrospective two_axis_test.csv와 별개의 사전 추정·검증 계약이 필요하다.
이 기록에서는 어느 쪽도 새로 확정하거나 Claude에 변경 지시하지 않았다.

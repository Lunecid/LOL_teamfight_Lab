# ΔV 라벨 생성과 사전 예측 학습: 설명용 예시

2026-09-15. 아래 시각·확률·교환은 **설명용 가상 값**이며 실측 결과가 아니다. 현재 주 기준 h90과 사건 기반 종료를 사용한다. 과거 20260914 예시의 후보 상태와 구분한다.

## 1. 서로 다른 두 학습 목표

V_theta(S_t) = P(최종 Blue 경기 승리 W=1 | 시점 t까지의 관측 상태).

V는 교전 여부와 무관한 적격 경기 상태와 실제 최종 승패 W로 학습한다. 시점마다 같은 모델에 다른 상태를 넣으므로 확률이 달라진다. 각 시점의 경기 승률 정답을 직접 관측하는 것은 아니며 W를 정답으로 확률 모델을 적합·검증한다.

각 engagement i에서 동일 V로 p_pre=V(S_pre), p_post=V(S_e)를 구하고 ΔV=p_post-p_pre, Y=1[ΔV>0]를 만든다. TRAIN에서는 해당 경기를 학습하지 않은 OOF V를 사용한다. q는 교전 이전 X_pre를 입력으로 Y를 학습한다.

q_phi(X_pre) = P(Y=1 | X_pre) = P(생성된 ΔV가 양수 | 사전 입력).

현재 q는 ΔV 크기의 회귀 모델이 아니다. ΔV는 연속값으로 저장하지만 q의 주 학습 표적은 그 부호의 이진값이다. 경기 승패 W를 바로 q 정답으로 사용하는 것도 아니다.

## 2. 정확한 타임라인

| 시각 | 사건 / 사용 |
|---|---|
| 19:44.999 | q 입력 cutoff; 이 시각 이하 최신 분 프레임+사건만 사용. 가상 p_pre=.35 |
| 19:45 | 사후 정의한 engagement 시작 s |
| 20:00 | 현재 engagement 첫 킬 K, s=K-15초 |
| 20:20 | 현재 engagement 마지막 킬 L |
| 20:50 | Blue 바론 획득; 정의된 구간 안이므로 가치 모델의 종료 상태에 반영 |
| 21:15 | 다음 적격 engagement 시작 S_next |
| 21:30 | 다음 engagement 첫 킬 J; 이전 engagement의 L 이후 첫 킬이라고 가정 |
| 21:50 | L+90초 상한 |

경기 종료가 위 시각보다 늦고 더 빠른 다른 종료 후보가 없다고 가정한다. 그러면 e=min(21:50,21:29.999,21:14.999,game_end-1ms)=21:14.999. 바론은 포함하고 다음 교전은 제외한다. 다음 교전 시작도 사후 계산된 값이다.

이 종료 상태의 가상 p_post=.47이면 ΔV=.47-.35=.12, 즉 **+12%p**, Y=1이다. Blue는 여전히 최종 승률 50% 미만이지만, 시작보다 Blue 쪽으로 개선됐으므로 양성 라벨이다. +12%가 아니라 +12 percentage points이다. 이 +12%p 전체를 바론 하나의 고정 가치 또는 교전의 인과효과로 귀속하지 않는다.

## 3. 우세, 변화 방향, 변화 크기의 구분

| 가상 사례 | p_pre | p_post | ΔV | Y | 의미 |
|---|---:|---:|---:|---:|---|
| A | .35 | .47 | +.12 | 1 | 아직 열세지만 Blue 쪽으로 개선 |
| B | .65 | .59 | -.06 | 0 | 아직 우세하지만 Blue 쪽에서 악화 |
| C | .49 | .50 | +.01 | 1 | 작은 Blue 개선 |
| D | .49 | .69 | +.20 | 1 | 큰 Blue 개선; C와 같은 이진 라벨 |
| E | .50 | .50 | 0 | 0 | 현 규칙상 Blue 비개선. 엄밀한 Red 개선과 다르므로 tie count 별도 기록 |

한 팀의 경기 승률을 p라고 할 때 상대는 1-p이므로, 모델상 양수/음수 변화는 반대 팀 방향의 감소/증가다. 단 정확한 0을 0클래스로 넣는 현재 규약 때문에 0클래스 전체를 엄밀한 Red 개선으로 정의하지 않는다. 기존 유효 저장 라벨에서는 정확한 0이 없었지만 규약은 명시한다.

## 4. 학습되는 한 행과 손실

가상 A에서 q 학습 행은 (X_19:44.999, Y=1)이다. X에는 현재 허용된 사전 상태와 p_pre가 포함되고, e/p_post/ΔV/후속 바론/최종 경기 결과는 포함되지 않는다. 모든 사건을 본 뒤 라벨을 붙이는 것은 지도학습의 결과 관측 단계이고, 그 결과를 사전 입력에 넣는 것과 다르다.

q가 이 행에 .62를 출력했다면 라벨에 부여한 확률은 .62다. q=.62의 뜻은 '유사한 사전 입력에서 Blue 개선 라벨일 추정 확률 62%'이며 최종 경기 승률 62%도, 승률 +62%p도 아니다.

확률 분류의 기본 학습 예시는 경기 가중 binary cross-entropy다:

L = -sum_i w_i [Y_i log q_i + (1-Y_i) log(1-q_i)] / sum_i w_i.

logistic/residual neural 모델은 이에 각 모델의 규제를 적용하고, tree는 대응 binary objective를 사용한다. 모델 선정 주 지표는 별도의 Q_SELECT Brier다. w_i는 경기별 총 가중치 균등화를 위한 것으로 |ΔV_i|가 아니다. 따라서 C와 D가 같은 q와 같은 w라면 주 이진 손실 기여도는 같다. 변화 크기를 회귀하거나 |Δ|로 가중하는 것은 별도 연구 변경이며 현재 시행하지 않았다.

## 5. 나중에 최종 경기에서 패배한 경우

A 이후 Blue가 실제 경기에서 패배해도 A의 Y=1을 0으로 고치지 않는다. A는 정해진 구간 전후의 추정 승률 변화이고, 이후 전체 경기 승패는 다른 결과다. V의 학습에는 실제 W가 필요하지만, 해당 TRAIN 사례의 가치를 계산하는 V는 그 경기를 제외하고 학습한다. 보류된 경기의 W는 V 평가 정답으로 사용한다.

이 설계가 개별 라벨의 의미 타당성·인과 귀속을 보장하지는 않는다. 경계 산출의 기존 TEST 사용, 관측 공백, V의 오차 및 작은 Δ의 민감도는 별도 한계다. q는 현재 교전 발생 여부를 실시간 탐지하는 모델도 아니다.

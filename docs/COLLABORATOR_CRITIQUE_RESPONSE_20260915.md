# 협업 명세서 검토 의견에 대한 대조 감사와 후속 우선순위

2026-09-15. 기존 명세서 작성 이후 받은 검토 의견에 대한 후속 기록이다. 기존 Word·Markdown·모델·라벨은 보존한다. 아래 새 수치는 저장 예측값을 이용한 사후 감사이며, 새 모델 학습이나 미접촉 데이터 확인 실험이 아니다.

## 1. 판정

검토 의견의 중심 문제 제기는 타당하다. 구현 검증과 연구 주장 검증은 구분해야 하며, 한타 T의 추가 예측력·실제 평가 시점의 V·라벨의 작동 원리·외부 이전이 우선이다. 다만 최신 프레임으로 학습하고 오래된 프레임으로 라벨을 만든다는 가설은 실제 저장 자료에서 방향이 반대였다. 검토 의견을 모두 확인된 오류로 취급해서도, 기존 문서가 한계를 공개했다는 이유로 해결된 문제로 취급해서도 안 된다.

이번에 수행한 것은 다음이다.

- 기존 주 TEST와 네 외부 세트의 유효 h90 218,238행 전체를 재집계했다. T 44,103행, N 174,135행이다.
- 동결 A specialist와 각 코호트에서 학습한 p_pre spline을 동일 행에서 비교했다. B40·B45도 기존 예측값에 적용했다.
- 실제 V 학습 질의 424,160개의 snapshot age와 TEST/external grid·교전 pre/post의 age를 비교했다.
- 저장된 최종 승패 W에 대한 pre/post V 지표, 확률 구간별 보정 집계, age별 V/q 지표를 계산했다. 모든 평가 행에서 W 연결이 가능했다.
- 모델 재학습·재보정·재선택·라벨 변경은 하지 않았다. 강화된 p_pre+시간 기준모형, 전체 CoG 재학습, 새 V는 아직 실행하지 않았다.

전체 수치와 원천 해시는 [감사 결과](../outputs/collaborator_critique_audit_20260915/results.json), 사람이 읽는 표는 [결과 보고서](../outputs/collaborator_critique_audit_20260915/REPORT.md), 재현 코드는 [감사 스크립트](../scripts/audit_collaborator_critique_20260915.py)에 있다. 첫 실행의 외부 파일명 오류와 수정 후 성공 기록도 같은 폴더에 보존했다. 기존 평가자료를 이미 본 사후 분석이라는 지위는 바뀌지 않는다.

## 2. 초기 승률 이상의 기여

기존 T 전체에서 specialist AUC 0.670188과 spline 0.664191의 차이는 약 0.006이다. Brier 개선은 -0.001615이며, 상수 대비 개선량 중 spline 비율은 약 92.6%다. 이는 정보량이나 분산을 분해한 비율이 아니다. 그렇다고 q가 미래 관측 변화 없이 라벨을 산술적으로 복사하는 것은 아니다. q의 입력은 pre 상태이고 라벨은 post 상태도 사용하므로, 문제는 순환성 자체의 확정이 아니라 추가 예측력의 크기와 일반화다.

이번 동결 모델 재집계는 다음과 같다. ΔBrier는 specialist−spline이며 음수가 개선이다. 구간은 경기 단위 paired bootstrap 1,000회, seed 20260915, 95% percentile 구간이다. AUC 차이의 구간은 계산하지 않았다.

N에서는 다른 양상이 나타난다. 주 TEST 전체 N의 ΔBrier는 -.003662 [-.004091, -.003224], B40 N은 -.003402 [-.004069, -.002679]다. KR 16.13과 NA 전체 N에서도 Brier 이득이 관측되지만 일부 log loss 구간은 0을 포함한다. N 결과로 주 연구 대상 T의 약한 일반화를 대체하지 않는다. 작은 외부 하위집단과 다중 비교는 탐색적으로 해석한다.

후속 핵심 비교에는 기존 spline 외에 p_pre와 게임 시간 및 상호작용의 유연한 기준모형이 필요하다. 새 모델의 full/B40 성능 차이를 같은 기준으로 평가해야 하며, balanced에서 성능이 좋아지도록 임계값·보정법을 사후 선택하지 않는다.

TRAIN 질의의 약 99.996%는 age가 30초 이상이었다. 따라서 학습 질의가 실제 프레임과 정렬되어 최신 상태를 쓴다는 가정은 기각해야 한다. 정수 분 grid와 실제 frame timestamp의 관계는 원시/cache provenance로 추가 확인해야 하며, 다음 미래 frame을 가져오는 방식으로 이 문제를 해결하면 안 된다.

위 결과는 실제 endpoint V가 전체적으로 무너졌다는 증거도 아니다. 다만 grid·T·N의 시간과 사례 구성은 다르고, post에는 더 늦은 정보가 있으므로 endpoint의 높은 AUC를 관측 지연에 문제가 없다는 증거로 해석하지 않는다. 같은 경기·시간대에 맞춘 비교와 보정 진단을 우선한다. 특히 최종 W에 대한 양 끝 확률의 성능만으로 그 차분 부호가 실제 교전 승리와 일치함을 보장할 수 없다. 전후 오차의 상관과 작은 Δ에서의 부호 안정성은 별도 문제다.

현재 저장 자료로 해결된 것은 age 분포와 실제 pre/post의 기본 성능 확인이다. 시간대 통제, 보정 기울기 추정, TRAIN에서의 불규칙 질의 민감도, age 입력을 가진 대체 V는 아직 남는다. 거의 한 종류의 age만 본 모델에 age 열을 추가하는 것만으로 다른 age 범위에서의 학습 근거가 생기는 것은 아니다.

## 4. 선형점수 차분과 라벨 해석

현재 V는 전처리 후 로지스틱 모델이며 선택된 보정은 identity다. 한 행 i의 pre와 post에 같은 모델·전처리를 적용한다. TRAIN에서는 행의 OOF fold에 따라 계수가 다르므로 아래 β_i는 해당 행의 어댑터를 뜻한다.

$$V_i(S)=\sigma\{\beta_{0,i}+\beta_i^T z_i(S)\}.$$

$$Y_i=1[V_i(S_{post})-V_i(S_{pre})>0]=1[\beta_i^T\{z_i(S_{post})-z_i(S_{pre})\}>0].$$

이 등식은 수학적으로 엄격 단조인 sigmoid에서 성립한다. 유한 정밀도 포화나 보정 clipping의 동률은 구현에서 별도 확인한다. 현재 raw adapter에는 추가 확률 clipping이 없으며, 기존 유효 라벨에는 정확한 Δ=0이 없었다. 일반적인 로지스틱 수식은 [scikit-learn 공식 문서](https://scikit-learn.org/stable/modules/linear_model.html#logistic-regression), 현재 경로는 fc20260915_fit_v.py와 fc20260915_common.py의 FullCorpusWinProbV2에 근거한다.

이는 기존 수동 계수를 학습 계수로 바꾼 단순 가치 함수라는 해석과 부합한다. 다만 z에는 시간 상호작용 등 비선형으로 구성한 특징도 있으므로 원시 게임 변수 전체에 대해 단순 선형이라고 말하지 않는다. 미래 z_post가 필요하다는 사실도 변하지 않는다.

변하지 않는 챔피언 one-hot의 직접 항은 부호 차분에서 상쇄된다. 챔피언이 ΔV 크기, p_pre, 실제 이후 상태 변화에 영향을 줄 수 있다는 점과 구분한다. q에 직접 champion ID 열이 없어도 p_pre_V를 통해 챔피언 정보가 간접 전달된다. 엄격 단조 보정은 부호를 바꾸지 않으므로 확률 보정과 라벨 의미 타당성을 같은 성과로 세지 않는다.

다음 기전 감사는 각 transformed column의 β_j Δz_j를 원래 명명된 특징에 연결하고 합이 decision_function(post)−decision_function(pre)와 일치하는지 확인한다. 주 V의 학습된 식을 설명하는 정확한 산술 분해이며 인과분해가 아니다. 시간 관련 특징과 오브젝트 관련 특징은 중첩되므로 두 분류의 기여를 합해 총합이라고 쓰지 않는다. 유일한 총합 분해에는 각 열이 한 그룹에만 속해야 한다. c×t 상호작용의 변화는, 예를 들어 Δ(ct)=평균(t)Δc+평균(c)Δt로 배분할 수 있지만 이 대칭 배분 자체는 분석 규칙이지 자연적인 인과 구분이 아니다.

## 5. 종료 규칙과 정의 독립성

cap 민감도와 종료 사건의 타당성은 다른 검증이다. 기존 next-kill 비율은 129,036/163,576, 약 78.9%이므로 h60/90/120의 낮은 반전율만으로 현재 종료를 정당화할 수 없다.

다음의 고정 V 분해를 우선한다.

$$\Delta V=\{V(S(L))-V(S(t_{pre}))\}+\{V(S(e))-V(S(L))\}.$$

S(L)은 같은 timestamp의 허용 사건을 모두 포함하는 기존 at(L) 규칙을 사용하고, 사건들의 가짜 내부 순서를 만들지 않는다. 전투 중 변화와 후속 변화의 부호 조합, 역전 비율, 객관적 획득 사건 및 age를 함께 기록한다. 아직 V(S(L))를 전체 행에서 평가하거나 이 분해를 완료하지 않았다.

공간 관련 next-kill 등 대안 종료는 별도 명세 이후 민감도로 다룬다. 원래 군집을 유지한 입력 offset 변경은 모집단을 바꾸지 않는 민감도로, development-only G/D에 의한 재탐지는 모집단까지 달라지는 민감도로 구분한다. 정의 변경 후의 전체 모집단 지표와 공통/변경 사례의 구성 변화를 모두 제시해야 하며 AUC 차이를 정의 변경의 순수 효과로 부르면 안 된다.

현재 pooled G/D에는 TEST patch가 포함되어 있다. q의 직접 입력 누수와 구별되지만 end-to-end 독립성의 한계가 해소된 것은 아니다. TRAIN 15.14만으로 추정·고정한 정의를 우선적인 독립 민감도로 권한다. VALIDATION은 뒤의 V/q 보정·선택에 기존 역할대로 유지한다. TEST 미사용 원칙은 [scikit-learn의 누수 설명](https://scikit-learn.org/stable/common_pitfalls.html#data-leakage)과 일치하지만, 정확한 LoL 정의 추정 절차와 수치는 우리 연구의 선택이다.

## 6. 모델 선택 이력

기본 A와 표현 비교 C는 서로 다른 후보 집합을 가진 실험이다. C의 더 높은 N TEST AUC를 보고 A 주 모델을 사후 교체한 것으로 해석하지 않는다.

| 단계 | 후보 범위와 지위 | T Q_SELECT 선택 | N Q_SELECT 선택 |
|---|---|---|---|
| 동결 pooled E | 전체 E의 기존 후보와 보정 | 공통 ridge_isotonic | 같은 모델 |
| A specialization | 상수, p_pre logistic/spline, 전체 수치 ridge, economic LightGBM 및 각 허용 보정 | ridge_raw, Brier .229194 | ridge_isotonic, Brier .242560 |
| C representation | participant 전체입력, draft, role 표현의 ridge/LightGBM 및 보정 | role_lgbm_raw, Brier .228032 | role_lgbm_sigmoid, Brier .238537 |
| 새 공정 비교 | 공통 352열 logistic/LightGBM/plain MLP/residual MLP 및 CoG 표현 adapter | 아직 미선택 | 아직 미선택 |

후속 원고는 하나의 선택 이력 표를 유지해야 한다. T/N은 사후 확정 규모에 따른 조건부 평가이며, 라이브 라우팅 검증 없이 운영 이득으로 확대하지 않는다.

### 입력 사전과 SHAP에서 확인된 문서 보완 사항

정규화 식은 전달한 JSON에는 빠져 있지만 현재 추적한 pipeline_cache.py 소스에는 존재한다. 표의 clipping은 고정 범위이고 분모는 고정 상수다. 소스만 보면 경기 전체 최댓값이나 TEST 평균을 이용하는 식이 아니다. 다만 과거에 생성한 모든 실제 캐시가 이 코드와 일치한다는 원시/cache 재계산을 이번에 수행한 것은 아니다. 소스 해시와 실제 캐시 provenance를 구분해야 한다.

| 특징 | 현재 소스의 원본 필드와 식 | 소스 근거 |
|---|---|---|
| totalGold_norm | clip(totalGold / 25000, 0, 5) | pipeline_cache.py:282,354 |
| curGold_norm | clip(currentGold / 4000, 0, 5) | pipeline_cache.py:281,353 |
| xp_norm | clip(xp / 20000, 0, 5) | pipeline_cache.py:280,352 |
| laneCS_norm | clip(minionsKilled / 400, 0, 5) | pipeline_cache.py:284,356 |
| jgCS_norm | clip(jungleMinionsKilled / 250, 0, 5) | pipeline_cache.py:285,357 |
| level_norm | clip(level / 18, 0, 2) | pipeline_cache.py:279,351 |
| alive | 1[championStats.health > 0], 마지막 과거 프레임 값 | pipeline_cache.py:328–334 |

원본 수치가 없으면 소스는 기본값 0과 safe_float를 거친다. health가 없을 때도 alive=0이 될 수 있으므로 missing과 실제 사망을 동일 의미로 설명하면 안 된다. hp/mp 분모와 결측 처리까지 포함한 전체 사전 보완은 별도 버전으로 만들어야 한다. V/q 안의 TRAIN-only imputer·scaler와 그 이전 cache 정규화는 다른 전처리 단계다.

alive는 과거 frame에서 복사하지만 kills/deaths·최근 사망 특징은 query까지의 사건을 반영한다. state_value.py:62–85,127–136에서 확인된다. 따라서 alive=1과 최근 사망 사건의 공존이 가능하며, 이 소스 경로에서는 사건으로 alive를 강제 덮어쓰지 않는다. 실제 빈도는 아직 집계하지 않았다.

inhibitor 네 열의 combat 분류는 의도적인 게임 해석을 확인한 것이 아니다. fc20260915_common.py:501–515에서 `kills` 검사에 먼저 걸리는 이름 기반 분류 순서로 설명된다. 구조물로 옮기는 새 설명 스키마를 만들 경우 combat 68→64, structures 24→28이 되고 총 352열은 그대로다. q 예측 자체는 바뀌지 않지만 group SHAP은 달라질 수 있으므로 기존 SHAP를 고친 이름만 붙여 재사용하지 않는다.

현재 fc20260915_shap.py:43–60,181–203은 이미 계산된 열을 TRAIN background 열과 교체한다. p_pre_V를 원천 상태에서 다시 계산하지 않는다. 시간 상호작용도 원천/시간 관계가 자동 복원되지 않는다. cr20260915_shap.py:85–91에는 이러한 파생 관계가 깨진다는 제한이 실제로 적혀 있다. 따라서 지금 설명하는 것은 **동결된 입력열 공간에서 q의 반응**이지, 가능한 게임 상태를 생성해 가치까지 재계산한 결과가 아니다. 재계산하는 다른 설명은 원래 352열 q에서 빠진 champion ID 등 전체 V 입력까지 필요하므로 단순한 SHAP 옵션 변경으로 취급하지 않는다.

역할 모델은 별도 461열 표현이다. cr20260915_common.py:330–402에 16개 참가자 필드, 역할 가중 합, Blue−Red 차이, 3개 자원 차이×게임 시간, 불확실성 14열 및 일곱 SHAP 그룹이 있다. 이 역할 상호작용은 실제 minutes를 곱하며, 기본 StateV2 일부 `_x_time`의 minutes/30과 혼동하지 않는다. 192 global 및 p_pre 열 + 160 팀/역할 열 + 80 역할 차이 + 15 시간 상호작용 + 14 불확실성 = 461이다. 소스와 저장 모델 featurizer에 정의가 있지만 전달한 기본 q 사전에 포함되지 않은 것은 문서의 누락이다. role_models_manifest.json·role_supervision_provenance.json과 각 arm의 모델이 별도 근거다. 약한 역할 라벨의 원시 정답 확인까지 끝났다는 뜻은 아니다.

## 7. 후속 실행 순서와 중단 조건

1. **관측 시계 감사 마무리와 강화 기준선.** 현재 age와 endpoint 집계에 시간대 통제를 추가한다. p_pre와 시간의 marginal spline 및 tensor-product 상호작용을 갖는 규제 로지스틱 기준선을 명세한다. knots·전처리는 TRAIN만 사용하고, C 후보와 보정 선택은 기존 validation 분리 규칙을 유지한다. 새 결과를 보기 전에 표현·후보·지표를 고정한다.
2. **주 V의 작동 원리.** Δlogit 열별 합산, 시간 관련 항, 정적 항 상쇄, L 전후 분해를 전체 유효 집단에서 계산한다. 소수 사례 그림은 집계의 대체가 아니라 설명 자료다. 임의로 실제 사례를 골라 좋은 예만 제시하지 않는다.
3. **독립 정의와 가치 함수 민감도.** TRAIN-only G/D, 동일 입력의 다른 V 함수형태, 관측시계에 맞춘 V 질의 민감도를 각각 분리해 진행한다. 기존 주 V를 TEST 성능에 맞춰 교체하지 않는다. 이런 대체 V를 q TRAIN 라벨에 쓸 때에도 자기 경기 제외 OOF가 필요하다.
4. **공통 입력과 전체 CoG 비교.** 기존 사용자 요구대로 완주하되, 각 표현이 허용하는 사전 정보와 모델 선택 기록을 먼저 닫는다. 역할 정보가 추가된 C를 동일 352열 알고리즘 비교에 섞지 않는다.
5. **SHAP 및 문서 보완.** 원천/파생 입력의 masking 의미를 확정한 뒤 그룹 정의를 고친 설명을 새 버전으로 생성한다. 정규화·역할 사전, 실제 익명 사례, 학습/평가 정보 경계 그림, reviewer-response 표를 갱신한다.

지표가 낮거나 paired 구간이 0을 포함한다는 이유로 데이터를 제외하거나 정의를 수정하지 않는다. 독립 정의·외부 T·강화 기준선에서 추가 가치가 작거나 불안정하면 그 범위를 논문의 결과로 보고한다. 사람 평가와 실시간 배포를 강제로 새 목표에 추가하지 않는다. 현재 사용자가 정한 model-defined outcome에 대한 교전 분석 연구의 범위를 유지한다.

## 8. 문서의 지위

기존 20쪽 패키지는 이전 준비 시점의 기록으로 남긴다. 이번 문서는 그 이후 수행한 감사와 후속 우선순위이며, 기존 패키지의 “balanced 미실행”은 새 모델의 공정 비교에서는 여전히 맞지만 동결 모델에 대한 사후 집계는 이번에 일부 완료됐다. 과거 문서의 제한을 공개한 것만으로 해결했다고 주장하지 않는다. 새 강화 기준모형·분해·독립 정의 실험은 이 문서 작성 시점에 아직 실행되지 않았다.

# 시점 안전 위치 추정: 실행 전 실험 명세

목표는 미래 프레임 없는 위치 추정 방법 비교다. 교전 예측 성능 개선을 입증하는 실험과 구분한다. 기존 A3 seeded20k 인덱스의 고정 경기 목록을 사용한다. 마지막 두 관측으로부터 다음 프레임 위치를 예측한다. target>=3분, 직전 두 관측 간격과 예측 지평이 각각45–75초인 쌍만 주 분석한다. 말기 짧은 프레임과 초반 초기 위치의 별도 영향을 피하기 위한 사전 운영 선택이다.10명 전원 사용하며 관측 좌표가 없거나 비유한 행은 제외 수를 기록한다.

비교: 마지막 위치 유지(LOCF), 과거 두 점 평균 속도의 등속 외삽(CV), 감쇠 외삽 tau=5/15/30/60초, 칼만 등속 모델 q=0.01/1/100(u²/s³). KF 위치 관측 잡음 R=100²u², 초기 속도0·공분산diag(R,100²). Q=q[[dt³/3,dt²/2],[dt²/2,dt]]인 연속 백색 가속도 모델. 두 좌표 독립,10명 동일 covariance 구조. 이는 비교를 위한 가정이며 위치 센서오차100u의 실측 주장 아님. 칼만 근거는 Kalman1960(doi10.1115/1.3662552), 감쇠식·후보값은 연구자 선택이다.

출력은 모두 예측 당시 관측만으로 생성한다. KF는 target 위치 업데이트 전에 오차를 측정한다. 예측을 지도 경계로 강제 clipping하지 않는다. 이동/귀환/사망 등 불연속을 결과에서 유리하게 제외하지 않는다. 위치 불연속 사건 초기화는 이번 최소 구현에 넣지 않는다.

주 지표: 경기별 평균 Euclidean error의 동일 경기 가중 평균(MAE,u). 보조: 경기별 제곱오차 평균의 전체 평균에서 계산한RMSE, 오차≤1600u 비율. 15.14는 개발 진단,15.15에서 감쇠tau/KFq 선택,15.16에서 선택된 방법을 비교한다.15.16은 앞선 연구에서 사용한 패치이므로 새 외부시험이 아닌 시간순 탐색 비교다. 테스트 결과를 보고 후보를 재선택하지 않는다.

선택된 방법과 LOCF의 경기별MAE 차이 bootstrap500회(seed7)를 보고한다. 정답 프레임을 숨긴 next-frame 예측이며 실제 예측 cutoff의0–60초 위치오차를 직접 검증하지 못한다. 그 검증에는 고빈도 독립 리플레이 정답이 필요하다. q/SHAP은 이번 결과에 포함하지 않는다.

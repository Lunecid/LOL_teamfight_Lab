## 2. 연구 목적

본 학위논문은 서로 다른 시간 해상도로 기록되는 공개 게임 자료를 이용하여, 교전 사례의 구성, 경기 승패 기반 결과 가치의 정의, 교전 전 정보에 의한 예측, 예측의 의미와 적용 범위 검증을 일관된 연구 절차로 연결하는 것을 목적으로 한다. 중심 응용 문제는 CoG의 교전 이후 이득 예측이며, 데이터베이스 구축·알고리즘 목록·모델 순위 중 하나를 새로운 목적처럼 앞세우지 않는다. [S1]

저널 분기와 주 자료·라벨·예측 증거를 공유하되, 학위논문은 왜 특정 분석 단위·관측 시점·가치모형·정보 표현·평가 절차를 택했는지와 대안 선택이 결과에 미치는 영향을 단계별로 설명한다. 연구의 깊이는 모델 수가 아니라 설계 근거, 대안 비교, 결과 해석, 재현 가능성의 연결에서 확보하도록 설계한다.

## 4. 개선 흐름에서 도출한 네 연구질문

### M-RQ1. 교전 사례 구성 — I1

> 서로 다른 시간 해상도의 공개 상태·사건 기록에서 킬 조건부 교전 사례를 어떤 근거로 구성할 수 있으며, 경계와 규모 기준의 선택은 사례 구성에 어떤 변화를 만드는가?

연구 내용:

1. 원자료의 단위, timestamp, 동기화, 결측·불완전 기록의 처리, 사후 사례 식별과 사전 입력의 분리.
2. 시간·공간 상수의 데이터 근거와 운영 선택의 구분.
3. T/N 정의, onset/cutoff, 중복·중첩 제외, 사례 키의 재현.
4. 기준 정의와 명시한 대안 정의의 사례 수·공통/추가/제거·구간 분포 비교.

필수 산출물: 데이터 흐름·특징 계보, 사례 정의서, 포함/제외 표, 정의 민감도 표.

해석 제한: 사람의 독립 경계 주석이 없으면 ‘실제 한타 탐지 정확도’를 주장하지 않는다. 규모·경계 변경이 새 코호트를 만드는 경우 절대 성능 차이를 순수한 정의 효과라고 부르지 않는다.

### M-RQ2. 결과 가치 구성 — I2

> 최종 경기 승패와 연결한 가치모형을 이용하여 교전 전후 전략적 가치 개선을 어떻게 정의할 수 있으며, 이 측정은 관측된 결과와 얼마나 대응하고 모형·구간 선택에 얼마나 의존하는가?

**번호 매핑 (2026-09-20):** 현재 \(\widehat{V}\) 재설계·시간대 성능·연속성 작업은 저널 **J-RQ1**의 중심과 대응하며, 석사에서는 **M-RQ2**로 인용한다. 양쪽에서 ‘RQ1’로 부르지 않는다.  
저널 J-RQ1 문구·범위 고정 장부: [J_RQ1_SCOPE_LOCK_20260920.md](J_RQ1_SCOPE_LOCK_20260920.md). 질문 고정 ≠ M-RQ2 검증 완료.

연구 내용:

1. 지원 모형 V̂의 상태 표현·적합·검증과 실제 최종 승패 W에 대한 품질.
2. pre/endpoint에서 같은 V̂를 적용하는 ΔV̂와 이진 SVI의 구성.
3. 원 CoG의 운영적 교환 점수와 새 측정의 개념적 차이. 같은 사례에서 재계산한 직접 비교가 없으면 서로 다른 코퍼스의 수치를 개선 효과로 제시하지 않는다.
4. V̂ 사양·endpoint·관측 갱신 조건에 따른 라벨 안정성, 물질적 결과 대응 및 불일치.

필수 산출물: V̂와 q 구분표, 라벨 정의서, 시간대별 V̂ 평가, 민감도·대응 표, 대표 사례의 수치 추적.

해석 제한: V̂가 실제 경기 승패를 잘 예측하는 것과 SVI가 한타 승리의 독립 정답인 것은 별개다. ΔV̂ 자체가 인과적 기여가 되는 것은 아니다.

### M-RQ3. 사전 정보와 학습기 — I3

> 이렇게 정의한 SVI는 교전 전 공개정보로 어느 정도 예측할 수 있으며, 관측 정보의 구성과 학습기의 선택은 각각 예측 성능과 확률 품질에 어떻게 반영되는가?

연구 내용:

1. 공통 352개 입력에서 학습기 비교. 공통 주 모델·선정 이력을 저널과 공유한다.
2. 프레임 기반 상태와 사건 기반 특징이 전체 상태 요약 이상의 예측에 어떻게 활용되는지 단계적으로 점검한다.
3. 결과 해석에 필요한 경우 q의 특징군 귀속과 오류·불확실 사례를 설명한다. SHAP를 정보 유무의 독립 검정이나 인과적 승리 조건으로 사용하지 않는다.

필수 산출물: 동일 정보 모델표, 단계별 정보집합 비교표, 학습·보정·선정 기록, 필요 범위의 모델 설명.

해석 제한: 동일 성능 또는 미결 대비가 해당 정보의 부재를 증명하지 않는다. 같은 정보·예산에서 수행한 결과를 모든 신경망·그래프·시계열 모델로 일반화하지 않는다.

### M-RQ4. 예측의 의미와 적용 범위 — I4

> 구성한 교전 결과 예측은 초기 경기 우세에 얼마나 의존하며, 균형 상태·경기 시간·관측 조건·패치와 지역이 달라질 때 어떤 범위까지 유지되는가?

연구 내용:

1. 같은 평가 행의 q−PT와 확률 품질.
2. 전체 T/B40, B45·시간대·관측 갱신 조건의 보조 진단.
3. 외부 평가에서 고정 V̂와 q를 각각 검증하고, 기준모형도 함께 동결한다.
4. 무킬 참고 구간의 대응 조건과 의미, 알려진 선택 편향·라벨 의존·미관측 정보 제한.

필수 산출물: 주 검증표, 층별 효과크기·불확실성, 전이표, 한계와 적용 범위 진술.

해석 제한: B40는 사전 정보가 없는 집단도, 본질적으로 어려운 정답 집단도 아니다. 한 셀의 유의/비유의만으로 상태별 차이를 확정하지 않는다.

## 5. 석사 분기의 대표 심화 모듈: 사전 정보군 구성

### 5.1 지위와 목적

아래는 **이번 계획에서 새로 제안하는 석사 심화 모듈**이다. 실행 완료가 아니며 공통 주 모델을 다시 선정하는 절차도 아니다. 최소 핵심의 적합성·자원 범위를 확인한 뒤 실행 계약에 등록한다. 저널의 집필 시작을 이 모듈 완료에 종속시키지 않는다.

질문은 ‘모델을 더 크게 하면 좋은가’가 아니라 ‘초기 상태 요약을 공통으로 제공한 뒤 어떤 관측 특징군을 직접 추가할 때 예측이 달라지는가’다.

### 5.2 네 정보집합

동일한 LGBM 계열, 동일한 사례·라벨·평가 역할, 동일한 후보 예산·선정·보정 절차로 네 arm을 적합한다.

| arm | 입력 | 질문 |
|---|---|---|
| M-F0 | C: p_pre와 현재 시간 관련 기본 열 | 이 학습기에서 초기 상태 요약만 사용할 때의 수준 |
| M-F1 | C + F: 프레임 기반 자원·성장·체력 등의 특징군 | 프레임 특징을 직접 제공하는 추가 가치 |
| M-F2 | C + E: 사전 사건·이력 기반 특징군 | 사건 특징을 직접 제공하는 추가 가치 |
| M-F3 | 기존 전체 X: C + F + E + 필요한 혼합 파생열 | 원래의 결합 정보 수준 |

PT는 기존 주 검증 기준으로 그대로 유지한다. M-F0는 ‘C-only LGBM’이며 PT와 동일한 모델이라고 부르지 않는다. F0–F3 사이의 비교에서 학습기를 고정하고, PT와의 주 비교와는 다른 목적임을 밝힌다.

### 5.3 해석과 구현 계약

- p_pre는 F/E 정보를 이미 압축했을 수 있다. 따라서 이 설계는 **관측원 정보를 완전히 제거한 실험이 아니라, 초기 승률 요약에 조건부인 특징 추가 효용**을 평가한다.
- 특징사전에서 각 열의 실제 원천을 먼저 확인한다. time×resource는 자원 블록과 함께 관리한다. 둘 이상의 원천을 결합한 열은 혼합으로 표시하고 전체 arm에만 남기는 등 사전 규칙을 정한다.
- 제거한 열을 이용해 만든 파생열을 남겨 놓고 해당 정보가 제거됐다고 주장하지 않는다. p_pre 경로는 의도적으로 유지한 공통 정보임을 표시한다.
- 각 정보집합의 q는 TRAIN에서 다시 적합한다. V̂·Y·B40 기준·사례 마스크는 바꾸지 않는다.
- 주 코호트의 동일한 평가 키와 가중치를 사용한다. TEST·B40에서 더 유리한 하이퍼파라미터를 골라 넣지 않는다.
- 전체 입력 arm을 기존 동결 결과와 비교할 때 전처리·규칙 차이를 확인한다. 새 진단 실행의 재현 차이가 있으면 별도로 기록한다.
- 공통 주 352열 실험과 부분집합 실험을 같은 ‘동일 입력’ 순위표에 섞지 않는다.
- 보조 Logistic 교차점검이나 p_pre를 제거한 엄격한 원천 제한 실험은 확장 선택지이며 둘 다 자동 실행 조건은 아니다.

이 모듈은 학위논문에서 정보 표현을 선택한 근거를 풍부하게 만드는 방법이다. 긍정적인 추가 이득을 보장하거나 새 아키텍처 발명을 요구하지 않는다.

## 6. 별도 새 대규모 실험 없이 확보할 설명 깊이

### 6.1 사례 추적

제한된 수의 사례를 동일한 식별자와 시점으로 추적한다. 원자료 timestamp → 교전 경계 → 사용 가능 X → V̂ 두 시점 → SVI → q 예측 → 결과 대응을 연결한다. 사례 선택 규칙을 명시하고 대표성이나 일반적 빈도의 증거로 과대해석하지 않는다.

### 6.2 대안 설계의 비교

변경된 탐지 상수, 종료 구간, 입력·보정 선택의 배경과 결과를 비교한다. ‘왜 선택했는가’와 ‘그 선택을 바꾸면 무엇이 달라지는가’를 구분해 설명한다. 이미 존재하는 민감도 산출물은 먼저 재사용하고 학위논문이라는 이유만으로 전체 실험을 반복하지 않는다.

### 6.3 재현과 기여의 추적

수집·정리·전처리·특징·모델·평가의 버전 연결, 오류 및 수정 이력, 본인이 수행한 설계·구현·해석과 기존 논문·공동연구의 기여를 구분한다. 코드 목록 전체를 본문에 붙이는 대신 핵심 결정과 증거를 연결한다.

| 7 | 검증과 적용 범위 | PT/B40/시간·관측 조건, Quiet, 외부 전이 | M4 |
| 8 | 통합 논의와 결론 | I1–I4가 어떻게 연결되는지, 한계·기여·향후 과제 | 전체 |
| 부록 | 재현 자료 | 데이터·특징사전, 프로토콜·추가표, 오류·변경 장부 | 전체 |

이는 내용 구조안이다. 쪽수나 장별 분량, 제출 언어·양식은 임의로 지정하지 않는다.

## 8. 필수 범위와 범위 밖

### 이 계획의 최소 핵심

원 CoG와 후속 연구의 관계, I1 사례와 시간 계약, I2 V̂/SVI 및 핵심 민감도, I3 공통 예측·정보/학습기 구분, I4 PT/B40와 제한에 대한 근거를 연결한다. 기존 외부 결과가 있다면 그 노출 이력을 포함하여 재사용한다. 특정 유의확률이나 AUC 목표를 학위논문 완료 조건으로 정하지 않는다.

### 우선 심화

§5의 네 정보집합 모듈과 §6의 사례 추적을 우선 후보로 둔다. 원시 데이터 재수집·모든 모델 재학습을 선행조건으로 만들지 않는다.

### 자동 확장하지 않는 것

PUBG 등 다른 게임과의 통합, 모든 그래프·시계열 구조 재실험, 실시간 교전 발생 탐지, 인과적 최적 행동 추천, 새 수작업 주석 연구, 연속형 ΔV̂로의 주 목표 교체는 포함하지 않는다. 별도 요구·자료·프로토콜이 생기면 독립 후속 연구로 다룬다.

## 9. 계획서용 요약문

본 학위논문은 비동기 공개 게임 텔레메트리에서 국소 교전을 구성하고, 그 전후의 전략적 가치 개선을 정의하여 교전 전 정보로 예측하는 일련의 연구 절차를 다룬다. League of Legends를 실증 대상으로 하며, 선행 CoG 연구의 교전 이후 이득 예측 목적을 유지한다. 교전 단위의 근거를 보강하고, 고정 교환 가치 대신 경기 승패와의 관계를 학습한 상태 가치 변화로 결과를 구성한다. 이후 동일 입력의 학습기 비교와 단계적 정보집합 분석을 통해 예측 성능의 출처를 살펴보고, 초기 우세 기준모형, 균형 상태, 가치·구간 민감도와 외부 평가를 통해 해석 범위를 검토한다. 학위논문은 각 단계의 설계 선택과 대안, 구현·측정의 한계, 재현 가능한 근거를 연결하여 공개자료 기반 교전 예측의 가능성과 제약을 설명한다. 결과는 모델 정의 SVI에 관한 것으로 독립적인 한타 승리 판정이나 인과적 행동 추천을 주장하지 않는다.

## 자료 근거

[S1–S5] 공통 문서의 자료 목록과 사용자 합의를 따른다. M-RQ1–4, 목차, 네 정보집합 모듈, 사례 추적 방식은 이번 학위논문 분기를 위한 **제안**이다. 실행 여부와 학위 요건의 충족은 이 문서만으로 확인되지 않는다.

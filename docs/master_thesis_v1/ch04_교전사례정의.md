## 4.2 쓸 내용 (골격)

1. 검출 파이프라인: G(킬 간격) → D(공간 분할) → R,B,M(존재 게이트).
2. 상수표: 값 + source class(data-derived / rule / convention / engineering) — Methods 표 전사.
3. 규모: pick ≤1 / skirmish 2–3 / teamfight ≥4 (convention).  
   - **T:** cohort==1 (n_min≥4).  
   - **S:** cohort==0 & fine==1 (2≤n_min≤3); **pick 제외**.
4. SVI endpoint h90 vs CoG 골드 라벨 윈도우 H=35s 구분.
5. 패치별 G·D 재추정과 pooled 정의 채택 근거.
6. 해석 제한: 탐지 ‘정확도’ 미주장; **규모 기울기·어느 쪽이 더 예측가능 금지(F6)**.

## 4.3 핵심 문단 (초안)

교전은 킬을 앵커로 한 시공간 군집이다. 시간 간격 G와 공간 지름 D는 자료에서 추정한 뒤 운영 상수로 고정했고, 존재 반경 R과 리드 B는 규칙 앵커, 팀당 최소 인원 M은 관례다. 본 논문의 주 분석은 한타(T)와 소규모 교전(S) 두 코호트이며, 각 코호트에서 동일한 측정·예측 절차를 반복한다. 두 코호트의 절대 성능을 규모 효과로 해석하지 않는다.

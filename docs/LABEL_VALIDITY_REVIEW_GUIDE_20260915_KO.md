# Δ승률 라벨 사례 검토 지침

목적은 계산된 라벨을 맞히는 것이 아니라, 공개 텔레메트리로 정의한 평가 구간이 사람이 해석할 수 있는 단기 교환과 전략적 이점을 얼마나 포착하는지 확인하는 것이다. 이 검토는 아직 수행되지 않았다. 모델이 작성한 평가를 전문가 평가로 채우지 않는다.

## 검토자에게 제공할 정보

- 익명 사례 번호, 양 팀 챔피언, 교전과 후속 구간의 시간 경계.
- 관측된 킬·오브젝트·건물 사건의 시간순 기록.
- 구간 전후 자원 상태와 각각의 실제 관측 시각. 평가 시각과 상태 관측 시각이 다르면 명시한다.
- 관측되지 않은 포지셔닝·스킬 적중·쿨다운 등은 없다고 분명히 표시한다.

모델 V/q 점수, Δ와 생성 라벨, 최종 경기 승자, 사례 선택 이유는 가린다. 어느 팀이 실제 경기를 이겼는지로 판단하지 않는다.

## 독립적으로 기록할 문항

1. **관측된 단기 교환:** Blue 유리 / Red 유리 / 중립 / 정보 부족.
2. **해당 구간에서의 전략적 이점 변화:** Blue 쪽 개선 / Red 쪽 개선 / 중립 / 정보 부족. 단순히 현재 더 강한 팀과 구분한다.
3. **종료 경계:** 진행 중인 전투를 잘랐다고 보임 / 새 전투 전에서 끊었다고 보임 / 판단 어려움. 정밀 위치가 없으면 추측을 강요하지 않는다.
4. **판단에 부족한 관측:** 자유 기록. 새 프레임 부재, 오브젝트 소유 불명확, 동시 다른 지역 사건 등을 기록한다.
5. **판단 확신:** 1(매우 낮음)~5(매우 높음). 2번의 응답과 별도로 기록한다.

검토자는 다른 검토자의 응답을 보기 전에 독립적으로 작성한다. 합의 과정은 최초 응답을 보존한 뒤 별도로 기록한다. 검토자가 없거나 미응답이면 빈칸을 유지한다.

## 분석 규칙

- 단기 킬·골드 교환과 전략적 결과는 서로 다를 수 있다. 둘을 하나의 정답으로 합치지 않는다.
- 중립과 정보 부족은 Red 승리로 변환하지 않는다. 모델의 Y=0에는 정확한 Δ=0도 들어간다는 차이를 공개한다.
- 사례는 작은 Δ·대체 V 불일치 등을 찾기 위한 층화 표본이다. 전체 모집단 정확도로 단순 평균하지 않는다.
- 우선 각 층의 분모·응답 수·정보 부족 비율·검토자 간 불일치와 예시를 보고한다. 검토자 간 일치는 진실의 증명이 아니다.
- 유효 비교에서 사람 판단과 라벨이 다른 비율을 보고하되, 그 원인을 V 오차/경계/관측 공백/다른 가치 판단 중 하나로 자동 확정하지 않는다.
- 이 자료로 사람의 게임 실력이나 한타의 인과적 경기 승리 효과를 평가하지 않는다.

## 현재 상태

이 문서는 검토 설계이며 결과가 아니다. 자동 사건·자원 비교, 대체 V 민감도, 사람의 독립 판단을 세 종류의 증거로 분리한다. 실제 사례 묶음 생성·검증은 별도 실행 명세에 따른다.

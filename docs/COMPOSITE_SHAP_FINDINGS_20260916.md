# 합성 시스템 설명과 모형군 의존도 범위 — 결과와 해석

2026-09-16. 설계·구현·실행·검증: Claude(Codex 라인 계승). 새 학습 없음. 명세 `CLAUDE_COMPOSITE_SHAP_20260916.md`, 실행 `outputs/composite_shap_20260916/`, 사후검증 31/31(2차; 1차는 이 세션이 실행 중 추가한 문서 2건이 docs 목록 검사에 걸린 것, 영수증 `audit_followup/`). 2026-09-16 문헌 검토(Chen·Lundberg·Lee 2022, Aas 등 2021, Fisher·Rudin·Dominici 2019)에 대한 실행이며, 균형 SHAP(③)의 두 한계 — 마스킹 시 p_pre·×time 파생열 미재계산, 성능 동급 모형 간 귀속 차이 — 에 답한다. 기존 TEST 노출 후의 탐색적 실행이고, 귀속은 적합된 모형의 서술이지 인과 기여가 아니다.

**판단.** (A) 마스킹한 원 상태에서 파생열과 p_pre = V(S)를 다시 계산하는 합성 함수 F(S) = q(h(S), V(S))의 7그룹 정확 Shapley에서는, 입력 공간 설명이 p_pre 한 열에 몰아 주던 기여(전체 셀 61.7 %)가 경제·경험치 32.6 %, 오브젝트 22.8 %, 전투·생존 16.7 %, 구조물 11.2 %로 흘러가고, **q가 쓰지 않는 챔피언 정체성이 V 경로를 통해 8.2 %(균형 셀 13.7 %)** 로 나타난다. (B) 검증 Brier가 최적 +0.0005 안인 후보 22개(T)는 p_pre에 대한 순열 의존도가 0.0015에서 0.0304까지 20배 차이 나면서도 같은 성능을 낸다 — "q가 어느 그룹에 의존하는가"는 성능으로 식별되지 않으며, 모든 동급 모형에서 공통인 것은 시간·체력 그룹의 의존도가 0에 가깝고 경제·전투·오브젝트가 항상 양이라는 사실뿐이다.

- 두 설명은 다른 대상에 대한 것이다(q의 입력 vs 원 상태 전체). "수정본"이 아니며 인과 분해도 아니다. 마스킹은 여전히 주변 배경(개입적)이라 상관 특징의 비현실 조합은 남고, 파생열·p_pre의 일관성만 확보됐다.
- 균형 셀에서 합성 Σ|φ|가 입력 공간보다 크다(0.113 vs 0.078): p_pre를 고정하면 사라지던 상태 변화가 V 경로로 되살아나기 때문이다.
- 챔피언 정체성: 라벨에서는 정확히 상쇄되지만(④), q의 예측에는 V의 가산 챔피언 항을 통해 들어온다. LightGBM q가 p_pre에 크게 의존하므로 그 경로가 크고(8.2 → 13.7 %), plain MLP는 p_pre 의존이 작아 2–3 %에 그친다. 이는 예측 경로의 서술이지 "챔피언이 한타 결과를 바꾼다"는 뜻이 아니다.

## 3. 원고에 쓸 문장

> q의 입력 공간 귀속(p_pre 61.7 %)과 원 상태에 대한 합성 시스템 귀속(경제 32.6 / 오브젝트 22.8 / 전투 16.7 / 구조물 11.2 / 챔피언 정체성 8.2 %)은 같은 모형에 대한 서로 다른 질문의 답이며, 챔피언 정체성은 라벨에서 상쇄되지만 V 경로로 예측에 들어온다. 검증 Brier가 최적 +0.0005 안인 22개 후보는 p_pre 의존도가 0.0015–0.0304로 갈리면서 같은 성능을 내므로, 어느 그룹에 의존하는지는 성능으로 식별되지 않는다; 동급 모형에서 공통인 것은 시간·체력 그룹의 무의존과 경제·전투·오브젝트의 양의 의존이다. 귀속은 적합된 모형의 서술이지 인과 기여가 아니다.

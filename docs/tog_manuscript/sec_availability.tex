\section{Code and Data Availability}\label{sec:availability}

Every number in this article depends on choices that a reader cannot see in the text alone: the
detector constants, the label rule, the feature extraction and the settings of each learner.
The code and the derived data are therefore released, so that each result can be checked and the
definition can be applied to new matches.

The complete pipeline is released under the MIT License: the engagement detector, the procedure
that estimates the kill-gap and cluster-diameter thresholds from data, the label construction,
feature extraction, every learner in the comparison, and the evaluation and audit scripts. The
release also contains the definition specifications as JavaScript Object Notation (JSON) files, one
per patch and one pooled over the three patches, together with the fitted event-price table, the
static map anchors and a configuration preset that sets every constant of this article at once.

The derived data behind every reported number are released as well: the per-engagement feature
matrix of the corpus (566,452 engagements with 7,106 columns each); five outcome labels with draws
marked; the out-of-fold (OOF) predictions of the headline model for the 532,547 engagements with a
non-draw label; the predictions of every learner in the comparison for the 153,816 engagements of
the test patch; and the identifiers of the 210,000 matches from which the corpus was built, among
them the 191,940 matches that contain a labelled engagement. The files of the feature matrix also
hold the label with which their rows were built, which is the headline label with each draw resolved
by a deterministic seeded coin. No result in this article uses that label.

The terms of the Riot Games application programming interface (API) count copies, extracts and
derivatives of the returned data among Riot's materials, and they license the use of the data for
applications that show it to users or for purposes that Riot sets out \cite{riot2013apiterms}. The
terms do not mention research use or datasets, so they neither expressly authorise nor expressly
forbid sharing derived research tables such as these. Riot's developer policies separately forbid
products that de-anonymise players who cannot reasonably be identified from visible information
\cite{riot2025devpolicies}. The authors limit the release to tables without player identifiers,
intended for non-commercial research. The licence of the data files, and whether Riot's written
confirmation is sought before they are released, are still open
\pending{data-licence}{licence of the released data files; decision on asking Riot for written
confirmation that the per-engagement tables may be shared for research}.

The raw Match-V5 match and timeline responses are not released. A match record lists the Riot
identifiers of its players \cite{riotapi2024matchv5}. The API terms permit the returned data to
be used only as authorised and require a developer to delete it when the licence ends, and Riot
forwards players' deletion requests to developers, which a public copy could not honour
\cite{riot2013apiterms}.

The raw responses are also no longer held. The corpus was built from a per-match cache of the
210,000 matches, which is now the only copy of the data. The cache is not released either, because
it is an event-level extract of the timelines rather than a per-engagement table.

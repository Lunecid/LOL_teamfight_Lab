## How to read this file

- **Rows.** One row per distinct reviewer request. A request whose parts have different states is split into
  a/b/c rows. Rows `X-1` to `X-4` record problems the revision found that no reviewer raised.

  summary in `repo:docs/CLAUDE_TOG_PAPER_PLAN.md` sections 7-8. The one quoted fragment (R3-1) was quoted by the
  first compilation and cannot be checked against a stored review. Before the response letter is drafted, replace
  each fragment with a verbatim one under 15 words from the review e-mail.

  `sec_limitations.tex` subsections have no labels and are named by their `\subsubsection` titles.
  `sec_learners.tex` is untracked and partial; every other section file named here is committed. Line numbers
  refer to fa166ec, which is also the section-file state at b930f82 (b930f82 changed no section file), and for
  the untracked `sec_learners.tex` to its 11:33 working copy. Between 19:58 and 20:00 other revision items
  started uncommitted edits to `sec_definition.tex`, `sec_intro.tex` and `sec_prediction.tex` whose diffs touch
  the `\pending{gxd\_sweep}` markers (calc: `git status` and `git diff` at 20:00); the line numbers and marker
  lists here describe the committed files, so re-grep once those edits are committed.
- **Path prefixes.**
  `repo:` = `C:/Users/todtj/PycharmProjects/LOL_teamfight/`;
  `wt:` = `C:/Users/todtj/문서/LOL_Teamfight/worktrees/engagement-state-value/`;

- **Numbers.** Each number is followed by its source, written `(src: file -> key)`. A derived number shows its
  arithmetic, written `(calc: ...)`. A result that does not exist yet is `\pending{key}{what}`, never a number.
  `grep -n "pending{" reviewer_response_matrix.md` lists every open item.
- **Status.** A row's status is the first thing it still waits on, in this order:
  - `pending decision`: an author has to decide something before work can go on, including whether to create a
    run that the committed text asks for but that no script, queue job or revision item provides.
  - `running`: a run it needs is queued or executing on either queue (`rev:queue_wave5.json`,
    `rev:queue_c34.json`), or is being prepared by an assigned revision item whose script is committed and which
    has so far written only smoke or preflight output.
  - `writing`: the evidence exists, or no experiment is needed, but manuscript text is missing, partial,
    uncommitted or still carries a `\pending` for a finished run.
  - `done`: answered in committed text, the artefacts exist, and nothing more is planned.
  A `\pending` counts against the row whose request it answers, not against every row that names the same
  section (for example, the effect column of `tab:constants` belongs to R1-5, not R1-4).

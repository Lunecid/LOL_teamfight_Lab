# 교전 예측 프레임워크: 정의·입력·표적 계약

사건 기반 B+90초 후보의 정확한 종료 수식, 포함 관계 및 논문용 타임라인은 [라벨 종료 규칙 및 예시](LABEL_ENDPOINT_RULE_AND_EXAMPLES_20260914.md)를 참조한다. 해당 문서 저장만으로 기존120초 계약이 대체되지는 않는다.

후속 결정: 사용자가 120초를 운영 기준으로 두고 다음 실험을 진행하도록 승인했다. 따라서 후속 실험에서는 h=120초를 고정한다. 데이터가 입증한 최적값이라는 주장은 하지 않는다. [고정120초 사건 실험](FIXED120_EVENT_RESULTS_20260914.md)을 참조한다. 아래의 '후보/미확정'은 이 결정 이전 설계 상태이며, 최적성·외부 타당성은 계속 검증 대상이다.

2026-09-14. 기존 구현과 대화에서 합의한 연구 목표를 연결한 설계 명세다. 새 입력 전체 및 새 라벨의 구현 완료 선언이 아니다. h=120초는 기본 실험 후보이며 최종 확정값이 아니다. 아래 최소 입력 명세는 새 표적 실험의 제안이며 기존 7,106열을 모두 승인한 목록이 아니다.

## 목적

기존 규칙으로 사후 식별된 kill-conditioned localized engagement에 대해, 예측 시점까지의 관측 가능한 전반적 경기 상태로 이후 경기 승리확률의 개선 여부를 예측하고 SHAP으로 예측 근거를 설명한다. 교전 발생 자체를 예측하는 모델은 아니다. 관측 상태의 가치 변화는 인과적으로 식별된 교전 효과가 아니다.

## 정의와 근거 종류

| 항목 | 정의 | 근거/상태 |
|---|---|---|
| 시간 묶음 | 연속 킬 간격 ≤13.7초를 연결 | 시간 간격 분포에서 추정. 세션 경계/KDE 관련 문헌은 방법의 선례이지 13.7초의 출처가 아님 |
| 공간 분할 | 묶음 내 모든 킬 쌍의 거리 ≤4,264u가 되도록 기존 순차 분할 | 챔피언 공유율 기반 내부 추정. 공유율 0.5 기준은 운영 선택 |
| 참여 판정 | 기존 시작 시점의 첫 킬 중심 1,600u 범위에서 팀별 최소 2명 조건 및 기존 탐지 게이트 | 반경은 게임 규칙 기반, 인원 기준은 운영 정의. 사후 식별용 위치 복원과 예측 입력은 분리 |
| 예측 시점 s | 첫 킬 시각 K에서 15초 이전 | s=K−15초. 게임 규칙/구현 선례 기반 운영 정의. 실시간에 미래 K를 알 수 있다는 뜻이 아님 |
| 교전 종료 L | 해당 교전 묶음의 마지막 킬 | 탐지된 전투 구간의 종료 |
| 결과 관찰 유예 h | L 이후 최대 120초 | 데이터 검토 후 제안한 실험 후보. 60/90/120/180초 민감도 필요 |
| 관찰 종료 e | min(L+h, 다음 탐지 교전 시작 직전, 경기 종료 직전) | 새 계약 제안. 전장 전체 기준 다음 교전 제한을 계승. 다음 시작≤L인 중첩 사례는 별도 표시하고 일반 라벨에서 제외/처리 비율 보고 |

실제 탐지의 시작 관측 길이, 시작 오프셋, 위치 복원, 후처리 등의 나머지 게이트는 v3.3 구현을 계승한다. 이 표의 상수만으로 탐지기가 완전히 재현된다고 주장하지 않는다. 규모 구분은 부가 분석이며 주 모집단을 새로 선택하지 않는다.

e에서 종료 이벤트 또는 다음 교전의 이벤트를 섞지 않도록 컷오프 포함 관계를 구현에서 고정한다. 종료에 의해 짧아진 관찰 구간은 사유와 길이를 보관한다. 학습 표적은 따라서 가변 종료 구간에서의 개선 확률이다. 고정 120초 결과와 동일하다고 부르지 않는다. 터미널 상태를 0/1 승패로 강제 치환하지 않으며, 종료 전 마지막 관측 상태를 평가한다.

## 시간 정보 계약

F(t)는 timestamp뿐 아니라 실제 이용 가능 시각까지 t 이하인 정보다. 입력 상태 S(t)는 이를 통해서만 만든다. 공개 데이터의 실제 전송 지연을 모르면 기록상 시점 안전성을 주장하고 운영 실시간 지연 검증과 구분한다.

- 분 단위 프레임은 해당 시점까지의 마지막 관측만 사용한다. 미래 프레임을 이용한 양방향 보간은 금지한다.
- 이벤트로 확실히 갱신 가능한 상태만 갱신한다. 분 프레임의 골드/체력을 정확한 실시간 값이라고 부르지 않는다.
- 관측 시각, frame_age, 결측 여부를 저장한다. 자료가 없다는 것을 0 또는 효과 없음으로 바꾸지 않는다.
- 예측 특징을 고를 때 미래 첫 킬 중심·미래 실제 참여자를 사용하지 않는다. 기본 입력은 두 팀 전체 10명의 고정 역할 슬롯이다.

## 모델 A: 보조 상태 가치 모델 V

학습 단위: (경기 m, 관측 시점 t). 교전 여부와 독립적으로 사전 고정한 시점 추출 규칙을 적용하고 경기별 표본 수 차이를 관리한다.

학습 정답 W_m: 블루 팀 최종 경기 승리=1, 패배=0.

출력 p_B(t)=V_theta(S(t)): 당시 상태에 조건부인 블루 최종 승리확률 추정. p_R(t)=1−p_B(t)로 정의해 팀별 평가를 일관되게 한다.

첫 실험은 정규화된 로지스틱 계열과 시간 상호작용을 출발점으로 삼고 확률 보정을 검증한다. 최종 승패 W는 다른 경기에서 V를 학습하는 정답이지 해당 교전 모델의 입력이 아니다.

### V의 최소 의미 입력 목록: 제안

양 팀별 수치를 보존하고 차이는 명시적으로 파생한다. 희소 종류 변수는 범주 인코딩하며 모델/인코더 버전을 저장한다.

| 그룹 | 입력 |
|---|---|
| 시간/관측 | 경과 초, 프레임 경과 시간, 결측 마스크 |
| 경제/성장 | 팀 총골드, 팀 경험치 또는 레벨 요약, 팀 CS, 생존 인원 |
| 구조물 | 양 팀의 파괴한 타워 수 및 관측 가능한 라인/등급, 현재 억제기 상태 |
| 드래곤 | 팀별 원소 종류별 획득 수, 총 스택, 영혼 보유 여부·종류 |
| 바론/장로 | 팀별 획득 수·최근 획득 시각, 관측/규칙으로 복원 가능한 현재 버프 보유 상태 |
| 전령 | 획득 및 사용 상태를 구분. 사용 정보가 없으면 결측으로 표시 |
| 유충 | 팀별 개별 획득 수·누적 상태 |
| 아타칸 | 팀별 획득 여부/수, 데이터에 존재하는 종류 및 효과 상태 |
| 규칙/가용성 | 패치별 해당 오브젝트 존재 여부, 스키마/규칙 버전. 존재하지 않음과 누락을 구분 |

현재 버프는 획득 시각만으로 확정하지 않는다. 죽음에 따른 상실 등 복원에 필요한 정보가 없으면 '최근 획득 이력'으로 명명하고 정확한 활성 상태와 구분한다. 원소·스택과 시간의 상호작용을 통해 가치 차이를 학습하도록 하며 효과를 사전 고정 WPA 가중치로 넣지 않는다. 이 입력이 전부 실제 캐시에 완전하게 존재하는지는 구현 전 필드별 검증 대상이다.

## 라벨 생성

동일한 고정 V로 p_pre=V(S(s)), p_post=V(S(e)), Δp=p_post−p_pre를 계산한다. s와 e 사이에서 모델 버전이나 보정함수를 바꾸지 않는다.

주 이진 라벨의 제안 계약: Y_gain=1[Δp>0]. 1은 블루의 평가 승률 개선, 0은 비개선(감소 또는 정확한 동률)이다. 따라서 Y=0을 항상 레드 승리라고 표기하지 않는다.

감사/표시용 direction=blue_gain if Δp>0, red_gain if Δp<0, unchanged if Δp=0을 함께 보관한다. 정확한 동률의 빈도를 보고한다. 근소 변화의 임계값 ε나 confidence 필터는 주 정의에 임의로 추가하지 않으며, 필요하면 개발 자료에서 정한 별도 민감도로 비교한다. V 수치 오차와 낮은 신뢰도는 라벨 안정성 검증 대상이다.

기존 market_event 금전 결과와 킬 우위는 비교 라벨이다. 임의 가중합으로 주 Δp 라벨에 더하지 않는다. 골드의 단위는 게임 내 공통 통화이지만 패치와 상태에 따른 전략적 가치는 불변이라고 주장하지 않는다.

Δp에는 해당 관찰 구간 전체 상태의 변화가 반영된다. 공간 필터로 특정 오브젝트를 연결했다고 해서 V의 전장 전체 변화에서 원거리 성장·행동 효과가 제거되는 것은 아니다. 따라서 이름은 '교전 연관 구간의 승리확률 개선'이며 순수 교전 기여가 아니다.

## 모델 B: 주 교전 예측 모델 f

학습 단위: (경기 m, 교전 i), 블루 기준 한 행.

기본 입력 X_i는 S(s)에 다음의 시점 안전한 사전 특징을 추가한 것이다.

- 고정 TOP/JUNGLE/MID/BOTTOM/UTILITY 슬롯별 챔피언, 레벨·경험치, 총골드·보유 아이템, CS, 누적 K/D/A, 마지막 관측 체력/자원·생존 상태.
- 시작 전에 알려진 조합 정보: 챔피언·소환사 주문·룬. 실제 남은 스킬 쿨다운이나 스킬 정확도를 안다고 가정하지 않는다.
- 기본 직전 30초의 관측 이력/증분을 후보로 둔다. 원시 시간 해상도를 넘는 갱신을 만들어내지 않고 실제 관측 수와 관측 나이를 함께 기록한다. 시간창 선택은 기존 실험과 새 표적 민감도로 확정한다.
- p_pre를 요약 특징으로 추가한다. 이는 원본 상태에서 유도한 값이며 독립적인 추가 관측이 아니다. p_pre만 쓰는 기준모델 및 포함/제외 비교를 둔다.

좌표의 사후 복원은 교전 탐지에 사용할 수 있지만 이 기본 예측 계약의 입력에는 넣지 않는다. 미래 참여자, 첫 킬 좌표, 킬 수·길이, L/e, 사후 획득, p_post/Δp/Y, 최종 W, 경기 총길이는 f의 입력 또는 입력 선택 기준이 아니다.

학습 정답: Y_gain. 출력 q_i=f_psi(X_i,p_pre) ≈ P(Y_gain=1 | F(s), 사후 교전 선정 규칙).

q는 최종 경기 승률도, 예상 승률 증가량도 아니다. 실시간 예측 표시는 p_pre와 q, 해당 q의 SHAP 설명이다. p_post·실현 Δp·정답은 평가 구간 종료 후에만 표시한다. q≥0.5의 이진 결정을 사용할 경우 그것도 결정 규칙으로 명시하며 q 자체를 주 확률 출력으로 유지한다.

## 설명/저장/검증

SHAP은 주로 f의 q 예측을 설명한다. V의 SHAP은 별도 보조 결과다. 로그오즈 설명을 확률 %p로 표시하지 않는다. 역할/상태별 중요도와 패치/seed 안정성을 검증하며 인과 원인으로 해석하지 않는다.

각 행에 match_id, engagement_id, patch, K/s/L/e, 실현 관찰 길이·중단 사유, input_asof, 원시 프레임 시각, detector/feature/value/label 버전, split, p_pre/p_post/Δp/Y/direction, 비교 라벨을 저장한다. 모델 입력과 감사용 메타데이터를 구분한다.

V 학습·보정은 해당 라벨을 만드는 경기의 최종 W를 보지 않아야 한다. 우선 별도 V 학습 경기 집합으로 V를 고정하고 나머지 교전 행을 라벨링하는 명료한 설계를 사용한다. 교차적합을 쓰면 양 끝점을 같은 fold 모델로 평가한다. q는 시간순 패치로 학습/검증/시험하며 한 경기의 행을 여러 split으로 나누지 않는다.

이미 전체 패치의 G/D와 지연 통계를 열람했으므로 이를 바탕으로 규칙을 고른 뒤 같은 패치를 완전 미사용 시험이라고 부르지 않는다. 새로운 미래 패치 평가 또는 탐색적 평가 범위 명시가 필요하다.

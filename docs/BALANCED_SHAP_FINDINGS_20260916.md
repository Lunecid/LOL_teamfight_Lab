# 균형 상태 설명(RQ3): 최종 선정 q의 7그룹 정확 Shapley, 전체 T 대 B40 T — 결과와 ToG 해석

2026-09-16. 설계·구현·실행·검증: Claude(Codex 라인 계승). 새 학습 없음. 설명 대상은 동결된 h90 모델의 최종 보정 확률: (a) 공통 352입력의 최종 선정 q = iq LightGBM 승자(Track A 동결이 5-family Q_SELECT 1위로 기록), (b) 동률이었던 plain MLP 승자. 7그룹(p_pre 1, 시간 2, 경제·경험치 60, 전투·생존 68, 오브젝트 176, 구조물 24, 체력·마나·기타 21) 128연합 정확 Shapley(Lundberg & Lee 2017), 배경 = 코호트 TRAIN 128행(hash), 사례 = 셀마다 256행(키 hash, 모델 무관). 사후검증 36/36 통과. 기존 TEST 노출 후의 탐색적 설명이며, 기여도는 모델 서술이지 인과적 승리 요인이 아니다.

**판단:** 한타 T에서 최종 선정 q(LightGBM)는 전체 셀에서 교전 전 승률 p_pre 한 열이 |φ| 합의 **61.7 %**를 차지하지만, 균형 상태 B40(p_pre ∈ [.40,.60])에서는 그 비중이 **27.7 %**로 떨어지고(평균 |φ| 0.097 → 0.022) 경제·경험치(12.0 → 24.4 %), 오브젝트(9.6 → 17.3 %), 전투·생존(8.1 → 13.9 %)의 상대 비중이 커진다. 즉 균형 상태에서 모델이 쓰는 정보는 "누가 앞서 있는가"에서 "현재 상태의 자원·오브젝트·전투 지표"로 옮겨 간다. 이것이 협업 메일이 물은 "균형 상태에서 초기 승률 이상의 정보가 남는가"에 대한 설명 쪽의 답이며, 예측력 쪽의 답(iq: B40 T에서 전체 입력 모델 − PT의 Brier 구간이 0을 포함)과 함께 읽어야 한다.

## 1. MAIN TEST 15.16 (T 주, 256사례/셀, 배경 128)

최종 선정 q (LightGBM, T), 평균 |φ| [행 부트스트랩 95 %] 및 |φ| 합 대비 비중:

| 경제·경험치 | 0.0189 [0.017, 0.021] | 12.0 % | 0.0190 [0.017, 0.021] | 24.4 % |

전체 셀 평균 p_pre 0.518, B40 0.503; 두 셀 겹침 2행. 비-p_pre 그룹의 절대 기여는 두 셀에서 거의 같고(경제 0.0189 vs 0.0190), 달라지는 것은 p_pre의 절대 기여(0.097 → 0.022)다 — 균형 상태에서 다른 정보가 "더 커지는" 것이 아니라 p_pre가 "작아져" 상대 비중이 바뀐다.

plain MLP (T): 전체 셀에서 오브젝트 21.0 %, 전투·생존 20.7 %, 구조물 20.0 %, 경제 17.2 %, p_pre 14.8 %; B40에서 p_pre 4.1 %. 같은 Brier의 두 모델이 기여를 다르게 배분한다(트리는 p_pre 한 열에 집중, MLP는 상관된 그룹에 분산). 개입적 치환은 그룹 간 상관을 무시하므로 모델 간 크기를 순위로 비교하지 않는다.

N(보조): LightGBM 전체 셀 p_pre 27.7 % → B40 6.5 %, 경제·경험치 21.8 → 31.4 %, 전투·생존 19.4 → 22.3 %, 체력·마나·기타 14.9 → 20.3 %. 같은 방향.

## 2. 해석과 한계

- p_pre는 V의 출력이므로 "p_pre 기여"는 상태 요약 하나에 압축된 정보의 기여다. 균형 셀은 p_pre 값으로 정의되었기 때문에 그 안에서 p_pre의 분산이 작고 기여가 줄어드는 것은 구성상 당연하며, 실질적 관찰은 **다른 그룹의 절대 기여가 유지된다**는 점이다.
- 시간 그룹(2열)의 기여가 0인 것은 LightGBM 승자가 시간 열을 거의 분할에 쓰지 않았다는 뜻이며, 시간 정보가 없다는 뜻이 아니다(다른 열의 ×시간 상호작용은 각 그룹에 속한다).
- 전체 대 B40은 서로 다른 행의 서술적 비교이고 짝지은 구간이 없다. 부트스트랩 구간은 256행의 표본 변동만 반영한다. 파생 관계를 깨는 인위적 혼합 상태의 한계, 인과 해석 금지는 프로토콜 §6 그대로다.
- Kim et al. (CoG 2020)의 불확실성 손실은 구현하지 않았다.

## 4. 논문에서 사용할 문장

> 최종 선정 q(LightGBM)의 7그룹 정확 Shapley에서 교전 전 승률 p_pre는 한타 전체 사례의 절대 기여 합 중 61.7 %를 차지했으나, p_pre가 0.40–0.60인 균형 사례에서는 27.7 %로 줄었고, 경제·경험치, 오브젝트, 전투·생존 그룹의 절대 기여는 두 집단에서 유지되어 상대 비중이 커졌다(각 256사례, 배경 128행, 128연합). 이 기여도는 적합된 모델의 서술이며 인과적 승리 요인이 아니다.

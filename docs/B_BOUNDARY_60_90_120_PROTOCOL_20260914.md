# B 종료 규칙의 최대 상한60/90/120초 직접 비교

사용자의 세 상한 비교 요청에 따라 같은 B=min(다음 추가 킬,다음 적격 교전,경기 종료) 규칙을 고정한다. 기존 공통 유효26,693교전에서60/90/120초의 실제 endpoint와 고정 expanded 모델 확률을 재계산한다. 기존90/120초 산출물은 덮어쓰지 않는다.

각 상한의 공간 첫 획득 CIF, 실제 후속 길이, 상한 도달률, 양성률을 비교한다. 모든 쌍60–90/90–120/60–120에서 전체 라벨 반전과 endpoint가 달라진 하위집합의 반전을 함께 공개한다. 경기 bootstrap500회(seed7)로 라벨 반전과 첫 획득 증가의 불확실성을 평가한다. 90초와120초가 실제로 동일 endpoint인 행의 안정성을 독립 근거로 삼지 않는다.

범위는 기존 독립 engagement 파티션9,198경기이며 전체210,000경기 재학습이나 새 외부 시험이 아니다. 첫 획득 CIF는 앵커 불명117행을 제외한26,576행이다. V의 전체 상태 라벨에는 공간 앵커가 필요 없어26,693행을 유지한다. 최적 h의 확정이나 q 예측 성능 비교는 이번 실험에 포함되지 않는다.

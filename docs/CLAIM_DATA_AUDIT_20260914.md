# 주장과 데이터의 부합성 감사

2026-09-14. 코퍼스 32 shard의 메타데이터 전체, 첫 shard의 X, 가치평가 NPZ, two_axis CSV, 관련 생성 코드를 직접 확인했다. 원본 경기 전체를 재추출하거나 모든 7,106개 입력의 시간 안전성을 검증한 감사는 아니다. 재현 코드는 동명 ipynb에 있다.

## 판정

현재 데이터는 **킬을 기준으로 사후 식별한 교전에서 사전 관측값으로 금전적 결과를 예측하고, 별도 상태 가치 모델로 전후 변화를 기술한다**는 제한된 주장을 뒷받침한다.

그러나 **모든 교전을 실시간으로 예측한다**, **교전 후 오브젝트까지 포함한 전략적 승리를 예측한다**, **교전이 승률을 얼마나 인과적으로 올렸는지 측정한다**, **완전히 새로운 데이터에서 전체 방법론의 일반화를 확인했다**는 주장까지 입증하지는 않는다.

## 직접 수행한 구조·수치 확인

| 검사 | 결과 |

| 전체 shard | 32개, 메타데이터 스키마 동일 |

| 판정 가능한 표본 | 532,547교전, 191,940경기 |

| (경기, cutoff) 중복 키 | 0 |
| 여러 패치에 등장한 동일 경기 | 0 |
| X 검사 범위 | 첫 shard 17,546행×7,106열; NaN/Inf 0 |
| 가치 모델 5개 분할의 경기 교집합 | 모든 쌍 0 |
| 교전 예측 학습·시험 경기 교집합 | 0 |

코퍼스의 기본 `y`는 무승부를 random 처리하지만, `y_market_event`는 무승부를 -1로 저장한다. 판정 가능한 행에서는 두 열 불일치가 0이었다. 기존 주 결과의 표본 수는 무승부를 제외한 수와 일치한다. 다만 새 실험에서 기본 `y`를 사용하면 다른 연구 문제가 되므로 명시적 y-key와 유효행 마스크가 필요하다.

## 중요한 부합성 문제

### 1. 전략적 가치와 주 예측 라벨은 동일하지 않다 — 높음, 코드·데이터로 확인

`gameplay/labels.py::_compute_label_market_event`는 킬 bounty와 shutdownBounty, 추정 킬/어시스트 가격, 비킬 사건 가격을 합산한다. 300g dead zone 안에서는 킬·생존·구조물 순으로 판정한다. 이는 무작위 가중합보다 명시적이고 검증 가능한 규칙이지만, 전략적 가치의 정답 자체는 아니다.

`config/game_rules/event_prices.json`의 pooled 가격은 dragon=0, elder_dragon=1390, baron_nashor=1555다. 드래곤의 전략적 영향이 0이라는 뜻은 아니며, 이 라벨에서 골드 상당액 추정값이 0이라는 뜻이다. 후속 상태 가치 모델에는 드래곤 종류·영혼·바론·장로 이력 및 시간 상호작용이 들어가므로 프로젝트 전체에서 오브젝트가 누락됐다는 주장도 부정확하다.

직접 비교한 공통 시험 25,177교전 중 1,941건(7.71%)은 실제 market_event 승자와 ΔV_end 부호가 달랐다. 서로 다른 정의를 측정한다는 실증적 증거다. 이 차이를 모델 오분류로 읽으면 안 된다.

**조치:** 주 출력 이름을 금전적 교전 결과로 유지하고 ΔV 가치 축을 구분한다. 전략적 승자 예측을 주장하려면 그 의미에 맞는 표적·검증이 추가로 필요하다.

### 2. 마지막 킬 경계는 교전 후 이득 전체를 포함하지 않는다 — 높음, 직접 계산

`train/temporal_winprob.py::observed_queries`는 pre=cutoff−1ms, end=last_kill, 그리고 end+30초/60초를 계산한다. 주 가치 축은 마지막 킬이다. 그 뒤 획득한 오브젝트는 그 시점의 end 상태에 들어갈 수 없다.

직접 계산: end와 end+60초가 모두 유효한 25,350건 중 5,159건, **20.351%**에서 전후 변화의 부호가 바뀐다. 남은 1,362건은 비교에서 제외됐다. 방향 반전을 전부 오브젝트 탓으로 귀속할 수는 없다. 다른 사건·상태 갱신도 포함된다.

**조치:** 마지막 킬, +30초, +60초의 결과를 나란히 보고하고, 종료 후 오브젝트·새 교전·동시 원거리 사건을 분리해 귀속 범위를 점검한다. 단순히 +60초를 주 경계로 바꾸는 것으로 해결되지 않는다.

### 3. 교전 발생 시점은 사후 선택된다 — 높음, 코드로 확인

`gameplay/fights.py`는 첫 킬에서 15초를 뺀 시각을 cutoff로 만든다. 입력이 cutoff 이전이라는 것과 그 cutoff를 온라인에서 알 수 있다는 것은 별개다. 킬 없는 사건을 포괄하지 못하며, 발생하지 않을 교전의 음성 사례를 갖춘 발생 예측 평가도 아니다.

**조치:** 현재 연구를 사후 식별된 교전의 사전 결과 예측으로 표현한다. 실시간 발생/탐지 성능을 주장하려면 온라인 trigger와 비교전 음성 표본, 경보 지연·오탐 평가가 필요하다.

### 4. 완전한 독립 외부검증으로 표현하기 어렵다 — 높음, 설정으로 확인

`config/fight_boundary/spec_pooled.json`과 이벤트 가격 표는 15.14·15.15·15.16을 사용한다. 따라서 예측기 가중치의 패치 홀드아웃과 **정의 산출·가격 추정까지 포함한 전체 파이프라인의 홀드아웃**은 다르다. 이것을 곧바로 X에 시험 정답이 들어간 직접 누출이라고 부르는 것도 과장이다. 전체 방법론의 외부 일반화 주장에 필요한 분리가 부족한 것이다.

가치 모델 `protocol.json`도 `same 50k exploratory corpus; this is not a newly untouched external test`라고 명시한다. 경기 분리는 직접 확인됐으나 반복 개발에 사용한 시험 자료라는 제한은 남는다.

**조치:** 정의·가격·모형 선택을 개발 자료에서 고정한 후 새 패치로 한 번 평가하거나, 현재 결과를 탐색적/조건부 검증으로 명시한다.

### 5. ΔV는 모델 추정값이며 인과효과가 아니다 — 높음, 해석의 한계

상태 가치 모델은 기록된 게임 상태로 최종 승패를 학습한다. 이후 두 상태의 예측 확률을 빼도 교전이 없었을 때의 결과가 주어지지 않으므로 교전의 인과효과가 되지 않는다. ΔV에는 다른 장소의 사건과 시간 흐름, 관측값 갱신도 들어갈 수 있다.

기존 결과 파일의 독립 분 평가에서 expanded 모델 AUC≈0.84636, Brier≈0.15978, ECE≈0.02877이다. 이 수치는 본 감사에서 재학습하지 않았으며, 평균적인 보정이 개별 교전의 ΔV 진실성을 보증하지 않는다. 특히 드문 오브젝트 조건의 방향·크기 신뢰도는 별도다.

**조치:** 관측 상태에 따른 추정 승률 변화라고 표현하고 모델/시간 경계 민감도를 동반한다. 인과적 표현을 쓰려면 별도 식별 설계가 필요하다.

### 6. 모델 계열의 한계 주장은 아직 검증 중 — 중간~높음, 작업 상태에 따른 제한

입력 복원으로 성능이 개선된 것은 관측 개선의 유효성을 지지한다. 그러나 용량·튜닝을 맞춘 비교가 끝나지 않았고 과거 SAINT 결과에는 배치 누출 노출 문제가 있어, 정보가 유일한 병목이거나 더 나은 모델이 도움이 없다고 결론낼 수 없다. 이는 현재 원고도 축소하고 있는 주장이다.

## 우선순위

1. 연구의 정답을 명확히 표기: 금전적 결과와 전략적 가치 변화를 구분.
2. 교전 종료 후 오브젝트의 포함·제외와 경계 반전 사례 분석.
3. 정의·가격 추정까지 동결한 외부 패치 검증 범위 확립.
4. 남은 공정한 학습기 비교와 기존 입력 시간 안전성 감사 결과 확인.

현재 표본을 폐기할 근거는 발견하지 않았다. 다만 주장의 범위를 명확히 제한하거나 위 검증을 추가해야 한다. 모든 입력의 원본 재구성, 원시 이벤트 누락률, 모든 X의 비유한값, 오브젝트 후속 귀속, 외부 패치 일반화는 이번 직접 검사의 범위 밖이다.

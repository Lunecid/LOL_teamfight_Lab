# 저널 연구 설계 재정리: 교전 시점의 가치 개선 예측과 설명

2026-09-14. 사용자가 이 대화에서 확정한 목적을 기존 CoG 리뷰 대응, 원고, 데이터 감사와 연결한 설계 문서다. 구현 완료 보고서가 아니다. 원본 HEAD fa166ec 및 큐 wave5를 확인했다. 기존 실행·원고 파일은 변경하지 않았다.

원문 수령 후 정정: 118번은 regular 선행 버전(최종 reject, 리뷰 3건+메타리뷰), 308번은 후속 auxiliary 버전(accept, oral, 리뷰 3건)이다. 기존 118 대응표가 다른 버전을 참조한다는 이유로 잘못된 리뷰라고 판단하지 않는다. 두 버전의 원문 기준 통합 계획은 `REVIEW_LINEAGE_AND_BOUNDARY_PLAN_20260914.md`가 우선한다. 기존 완료율은 118 대응표의 과거 시점 상태이며 두 버전 전체의 대응률이 아니다.

## 1. 확정된 목적과 미확정 조건

### 확정된 목적

- 교전 발생 구간은 전체 경기 기록으로 사후 식별한다. 실시간 발생 탐지 자체가 연구 목표는 아니다.
- 그 교전의 예측 시점에서는 당시까지 이용 가능한 정보만 사용한다.
- 교전 직전의 전체 경기 승리확률을 기준점으로 삼아, 종료 후 그 확률이 높아질 가능성을 예측한다.
- 전략적 가치는 드래곤 종류·스택·영혼, 바론, 장로, 전령, 공허 유충, 아타칸을 포함한다. 도메인으로 사건과 상태를 정의하고 수치적 가치는 데이터에서 학습한다.
- SHAP은 누출 진단에 더해 e스포츠 분석을 위한 주요 설명 분석으로 포함한다.
- 상태 가치 모델은 이번 저널의 보조 도구이며, 정교한 가치평가 모델 자체를 별도 주요 기여로 확대하지 않는다.
- 주 모집단은 이미 정한 kill-conditioned localized engagement 정의를 그대로 사용한다. 교전 규모별 분류는 기존 정의에 따라 부가 분석하며 모집단을 다시 선택하지 않는다.
- 검증은 기존처럼 시간순 패치 분할을 사용한다. 패치 변화에 소규모 설정 수정으로 대응 가능한 프레임워크가 목표이며 모든 미관측 패치에서의 성능 보장은 아니다.
- 관측 가능한 경기의 전반적 상태로 예측한다. 순간 포지셔닝·스킬 정확도 등 관측되지 않는 실행 요소를 직접 설명하거나 예측했다고 주장하지 않는다.

### 아직 결정·검증할 조건

- 교전 종료와 후속 이득 경계: last-kill, +30초, +60초 및 다른 교전과의 중첩.
- 가치가 정확히 0인 표본, 추정이 불안정한 표본의 처리. 모델 confidence 구간을 걸러 결과를 좋게 만드는 선택을 피하고 전체 coverage를 보고한다.
- 가치 모델 버전과 경제·오브젝트 상태의 정확한 입력 계약.
- 새 외부 패치 또는 완전히 미사용 경기 확보 가능 여부. 없으면 탐색적 검증이라는 범위를 유지한다.
- SHAP의 설명 대상 출력(확률 또는 log-odds), 기준집단, 상관 특징 처리 방식.

## 2. 수학적 계약

교전 i의 탐지 결과를 (s_i,e_i)=D(전체 기록)라 하자. F_s는 s까지의 이용 가능 정보다.

1. p_i = V_theta(S_{s_i}): 예측 시점의 경기 승리확률.
2. Delta_i = V_theta(S_{e_i}) - V_theta(S_{s_i}): 고정된 가치 모델로 정의한 구간의 관측 가치 변화.
3. Y_i = 1[Delta_i > 0]: 가치 개선 방향 라벨. 정확한 0은 별도 규칙 필요.
4. q_i = f_psi(X_{s_i},p_i): 당시 입력으로 Y_i를 예측하는 확률.

q_i의 의미는 P(Delta_i>0 | F_{s_i}, 연구의 사후 교전 선정 규칙)이다. p_i와 q_i는 다르다. p_i는 경기 최종 승리 가능성, q_i는 이번 교전 후 그 가능성이 올라갈 확률이다.

최종 W는 다른 경기들에서 V를 학습하는 정답으로 사용할 수 있다. 평가 경기의 W, e_i, 미래 참가자, 미래 교전 중심은 q 입력이나 입력 선택에 사용하지 않는다. 사후 위치로 주변 사전 데이터를 선택하는 것도 별도 감사 대상이다.

이 Delta는 상태 가치 변화이며 교전의 인과효과가 아니다. Y는 학습된 평가함수로 만든 정답이다. q가 Y를 맞힌다는 것만으로 V나 Y의 현실적 타당성이 검증되지는 않는다.

## 3. 저널의 연구 질문

- RQ1 정의: 사후 교전 정의는 데이터·규칙에 근거하고 상수·표본·패치 변화에 얼마나 안정적인가?
- RQ2 가치 라벨: 경제·오브젝트를 포함한 단순 독립 V는 경기 승리확률로서 유효하고, Delta 라벨은 모델·경계 선택에 얼마나 안정적인가?
- RQ3 예측: 사전 정보가 초기 p만 사용하는 기준보다 가치 개선 방향을 잘 예측하는가? 입력과 모델의 개선은 각각 얼마나 기여하는가?
- RQ4 설명: 어떤 사전 특징이 q에 기여하며, 그 방향과 순위는 패치·seed·모델·라벨 변화에 얼마나 안정적인가?

최종 경기 승패 stacking은 보조 진단이다. 그것의 개선을 이 연구 성공의 필수조건으로 삼거나, 개선이 없다는 이유로 교전이 중요하지 않다고 결론내리지 않는다.

## 5. 필요한 데이터·평가 계약

### 정의와 시점

- 모든 row에 match_id, engagement_id, s, e, 정보 사용 종료시각, detector/label/value-model version, 분할, 오브젝트 사건 연결 기록을 둔다.
- 미래 참여자·사후 중심·규모를 이용한 사전 특징 선택을 검사한다.
- 전령 획득과 사용, 유충 개별/누적, 용 스택과 영혼 동시 갱신 등 의존 상태는 함께 관리한다.
- 종료 뒤 오브젝트가 포함되지 않는 사례, 두 교전이 같은 사건을 주장하는 사례, 동시 원거리 사건을 따로 계수한다. +60초 결과를 모두 한타 효과로 부르지 않는다.

### 가치 모델과 순환성

- V는 교전 승자 라벨이 아니라 경기 최종 승패로 학습한다. 단순 로지스틱 계열을 시작점으로 유지한다.
- V fit/calibration/selection과 q 학습·시험의 경기 분리를 유지한다. 개발된 V를 고정한 후 라벨을 만든다.
- G/D와 이벤트 가격까지 포함한 데이터 의존 선택을 개발 파티션에서 고정하고 외부 평가한다. 현재 pooled 15.14–15.16 결과와 구분한다.
- V의 AUC뿐 아니라 Brier/log loss/보정, 경기 시간·오브젝트 조건별 성능과 표본 수를 보고한다.
- 현재 바론/장로/용 사건 전후 응답 진단은 모델 반응 검사다. 추출한 평균을 오브젝트의 고정 승률 가중치로 사용하지 않는다.
- Y의 모델 간·경계 간 일치율 및 sign 반전율을 보고한다. 기존 직접 감사에서는 end→+60초 25,350건 중 5,159건(20.35%) 반전이다.

### 예측 비교

- 다수 클래스/상수확률 기준; p_pre만 사용하는 분류기; scoreboard 또는 경제 상태 기준; 전체 X; X+evidence를 비교한다.
- p_pre 및 headroom은 X에서 파생된 요약이라는 점을 명시한다. 추가 정보를 획득한 것으로 해석하지 않는다.
- LightGBM과 용량·튜닝 조건을 명시한 대표 신경망을 비교한다. 과거 SAINT 배치 누출, TabNet 부호 오류를 수정한 구현을 사용한다.
- 동일 target, 동일 rows, 동일 split로 paired 경기 bootstrap CI를 계산한다. 주요 metric은 AUC와 확률 품질(Brier/log loss/calibration), coverage와 불균형을 함께 보고한다.
- 주 분석은 방향 분류. |Delta| 가중 학습은 별도 목적의 보조 분석으로 둔다. 실현 |Delta| 계층의 예측 성능을 인과적 '중요한 한타의 어려움'으로 해석하지 않는다.
- 기대 Delta 회귀는 보조 분석일 수 있다. martingale 논리만으로 방향 분류가 불가능하다고 결론내리지 않는다.

## 6. SHAP: e스포츠 설명을 위한 주 분석

### 설명하는 대상

주 분석은 f_psi의 q다. 질문은 '이 교전에서 이 팀의 가치 개선을 높게/낮게 예측하게 한 사전 정보가 무엇인가?'다. 사후 실제로 획득한 오브젝트를 q의 설명 변수로 넣지 않는다.

V의 설명은 보조 분석이다. '왜 전체 경기 승률 또는 관측 Delta가 바뀌었다고 모델이 평가했는가?'라는 별도 질문이다. 두 모델의 SHAP 순위를 섞지 않는다.

### 출력과 집계

동일한 설명 함수 h, 기준집단, 척도에서 h(x)=phi_0+sum_j phi_j(x)를 검증한다.

- raw margin/log-odds를 설명했다면 %p로 표시하지 않는다. 보정된 확률을 설명하려면 해당 합성 예측함수에 맞는 설명 방법과 가산성 검사를 사용한다.
- 지역 설명: 개별 교전의 waterfall, 실제 시점과 상태, p_pre, q, 사후 라벨, 맞음/틀림을 함께 표시한다.
- 전체 설명: 경기 가중 평균 절대 SHAP과 부호가 있는 분포를 제시한다. 패치·시간·사전 p 구간별 안정성도 보고한다.
- 역할·정보 종류별로 사전에 그룹을 정의한다. 열을 역할 그룹으로 묶는 경우 psi_group=sum_j phi_j를 먼저 계산하고 그 후 절댓값을 평균한다. sum |phi_j|와는 다른 척도다.
- 열별 SHAP을 합친 그룹 attribution은 별도로 그룹을 player로 정의해 계산한 Shapley 값과 동일하다고 주장하지 않는다.
- p_pre와 이를 구성한 골드·오브젝트 입력은 중복·상관된다. p 포함/제외, 기준집단 및 그룹 정의에 따른 민감도를 확인한다.
- 기준집단은 개발 자료에서 정하고 시험 결과를 보고 변경하지 않는다. 특징의 비현실적인 조합을 만드는 masking과 상관 특징 사이의 기여 분배를 점검한다.

### 저널용 결과물과 검증

1. 의미 그룹별 전체 중요도와 경기 bootstrap 구간.
2. 주요 변수의 SHAP 의존성 및 사전 승률/시간과의 관계.
3. 역할별 분석(희소한 개별 챔피언 순위는 표본 확보 시에만).
4. 금전 승자와 가치 승자가 다른 사례, 맞힌 사례, 틀린 사례를 사전 선정 규칙으로 제시.
5. 패치·seed·background 변화에 대한 순위/방향 안정성.
6. 주요 그룹의 제거 후 재학습으로 예측 기여를 교차확인. 순열/제거 성능과 SHAP을 인과효과라고 부르지 않는다.

실무 도구 유용성 또는 코칭 효과를 주장하려면 별도 사용자/전문가 평가가 필요하다. 사례 설명만으로 그 효과까지 입증했다고 쓰지 않는다. 저널 핵심 범위는 우선 모델 설명과 안정성으로 둔다.

## 7. 리뷰 요구별 재정렬

이 절의 표는 118번 선행 리뷰 대응이다. 이후 118·308 원문을 모두 제공받아 계보와 추가 요구를 별도 문서에 정리했다. 이를 새로운 ToG 심사의 요구사항으로 주장하지 않는다.

| 요구 | 새 설계에서 필요한 대응 |
|---|---|
| R1 초록·기여 연결 | 정의→가치 라벨→사전 예측→e스포츠 설명의 흐름으로 다시 작성 |
| R1 상수 임의성·민감도 | 기존 정의 근거 계승, 새 표적에 대한 안정성은 별도 확인 |
| R1 비전문가 설명·한계 | p_pre와 q의 차이, 사후 탐지와 시점 안전 예측, 모델 기반 정답을 예제로 설명 |
| R2 라벨 가중치·대안 | 임의 가산 대신 V 차분. market_event/킬 우위를 비교 라벨로 유지. V·경계 민감도 추가 |
| R2 FT-Transformer/TabNet/SAINT 및 공정성 | 수정 구현, 동일 입력·분할·표적, 선언된 용량·탐색 예산으로 재평가 |
| R2 시간창·해상도 | 이전 코드와 대조 조건 계승, 새 표적의 결과 재산출 |
| R2 코드·자료 공개 | 버전 고정, 데이터 계약·익명화·라이선스·재현 명령·링크 준비 |
| R3 방법 근거·diagnostic MLP·Layered+Logit | 각 방법의 질문과 선택 근거를 명확히 하고 비교에서 제외하는 모델의 이유 설명 |
| R3 SHAP 근거 | 누출 감사 + 새 q의 맥락/역할 설명으로 동기 명시; 안정성과 제거 분석 포함 |
| R3 attention/CNN 대안 | 실제 비교 범위와 선택 이유를 답변. CNN 여부 및 시퀀스 누락 조건은 미결 |
| R4 kill-less·API 한계 | 기존 정량 결과 유지, kill-anchored 선정 범위와 관측 지연 명시 |

## 8. 실행 순서와 완료 조건

### P0: 연구 계약을 고정

확정된 기존 모집단과 시간순 패치 분할을 유지하고, s/e·주 label·무승부 처리·주 metric을 문서화한다. 마지막 킬 이후 오브젝트 획득 지연의 평균·분포·미획득 및 중첩 비율을 개발 자료에서 측정해 유예 경계를 검토한다. 최종 시험 결과를 보며 선택하지 않는다. 미정 항목을 확정된 것으로 구현하지 않는다.

### P1: 데이터와 V 검증

시점 선택 누출과 오브젝트 포함 범위를 점검하고, 단순 V의 경기 확률 보정·오브젝트 반응·라벨 안정성을 평가한다. 타당성이 부족하면 q 성능 경쟁 전에 이 단계를 수정한다.

### P2: 주 표적의 예측 및 비교

새 계약에 맞는 q를 학습하고 기존 market_event와 별도 결과표로 비교한다. 진행 중인 기존 큐는 승인 없이 중단하거나 결과를 새 목표의 결과로 치환하지 않는다.

### P3: SHAP 분석과 검증

확정한 주 예측기에 대해 전체·역할·상황·개별 교전 설명을 생성한다. 안정성/그룹 제거/실패 사례 검사를 마쳐야 기여에 포함한다.

### P4: 저널 통합

초록·기여·라벨·예측·SHAP 절을 새 목표에 맞춰 통일한다. 결론과 학습기 절을 마감하고 reviewer matrix를 갱신한다. CoG 대비 추가분과 수정/철회 결과를 구분한다. 대상 저널의 최신 제출/확장/공개 정책은 제출 준비 단계에서 공식 지침으로 확인한다. 최종 PDF, 참고문헌, 표 수치, 답변서, 공개 패키지를 검수한다.

## 9. 선행 근거와 적용 한계

- Decroos et al., 2019, *Actions Speak Louder Than Goals: Valuing Player Actions in Soccer*, https://arxiv.org/html/1802.07127 — 맥락에 따른 행동 전후 확률 가치. 축구의 득점/실점을 LoL의 최종 승리와 교전 라벨로 바꾸는 것은 우리 적용이다.
- Lundberg & Lee, 2017, *A Unified Approach to Interpreting Model Predictions*, https://arxiv.org/abs/1705.07874 — 가산적 특징 기여의 수학적 기반. 실제 승리 원인이나 코칭 효과의 보증은 아니다.
- Kumar et al., 2020, *Problems with Shapley-value-based explanations as feature importance measures*, https://arxiv.org/abs/2002.11097 — Shapley 설명의 수학적 성질만으로 사람이 원하는 설명이 보장되지 않음. 기준집단·상관·사용 목적 검증의 근거.

SHAP 분석을 주요 e스포츠 기여로 되돌리는 것은 이번 사용자 합의다. 기존 원고의 'SHAP은 누출 감사에만 사용' 결정은 이 새 계획에서 변경된다. SHAP 자체나 V 차분을 새 알고리즘 발명이라고 주장하지 않는다. 기여는 정의·시점 계약·가치 표적·예측·설명을 LoL 데이터에서 일관되게 검증한 데 둔다.

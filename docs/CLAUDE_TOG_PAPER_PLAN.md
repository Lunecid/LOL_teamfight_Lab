## 2. 절 구성과 확정 수치

### §1 Introduction

CoG 판은 한 숫자(0.675)였다. 확장의 질문은 두 개다 — (i) 그 숫자가 **정의의 산물인가 데이터의 성질인가**,
(ii) **무엇이 그 숫자를 묶고 있는가**. v2의 규모 분해 주장은 이 논문에서 **명시적으로 철회**한다
(누수 절제 실험을 근거로). 철회를 숨기지 않고 기여로 제시한다.

### §2 Engagement Definition (가장 강한 기여)

**데이터 산출**
- 시간 경계 **G = 13.72 s** (킬 간격 KDE 골짜기, 부트스트랩 CI [12.16, 15.67], 깊이 0.866,
  ARI ≥ 0.9 평원 10–18 s)
- 공간 경계 **D = 4,263.87 u** (같은 챔피언 공유율 50% 교차, CI [4,256.05, 4,273.97])
- 근거 규모: **208,141경기 · 10,417,458 킬 간격 · 창 내 쌍 5,460,008**
- 패치별 G 13.96 / 13.49 / 13.72, D 4,285 / 4,265 / 4,241 → drift 판정 **pooled**

**게임 규칙 앵커** (추정 불가임을 명시)
- **R = 1,600 u** (챔피언 사망 경험치 공유 반경), **B = 15 s** (킬/어시스트 크레딧 창), M = 2
- Data Dragon 사거리 커버리지 근거는 **강등**한다(돌진기의 range 필드가 자리표시자)

**규모 클래스**: pick n_min ≤ 1 / skirmish 2–3 / **teamfight ≥ 4**

한계로 명시: 킬 클러스터 기반이므로 **킬 없는 교전은 정의에 안 들어온다**.

### §3 Label

`market_event` — 킬 골드(bounty + shutdown + 20 + 45×어시) + **회귀 가격표**로 창의 골드 스윙을 만들고,
±300 g 데드존 밖이면 시장 판정, 안이면 클러스터 킬 → 생존자 → 구조물 순으로 보정. 무승부는 제외.

**정직하게 적어야 할 것**: 가격표는 규칙 지급액이 아니라 **프레임 골드 회귀 추정치**이고,
그래서 **원소 드래곤이 0 g**이다(즉시 골드를 안 주므로). 즉시 창 최대 범주가 1,060건인데 0으로 계산된다.
이것이 확률 자(ΔV)를 병기하는 근거다.

라벨 가족: market_event / @window / market_lex / @window / Eq.3 — 동일 행·동일 폴드에서 평가.

한타에서만 잘 통하고, 모델이 pick에서 리드 밖 신호를 찾아 격차를 메운다.** 규모 무관은 과제의
밋밋함이 아니라 모델이 하는 일의 결과다. (철회된 v2 기울기와 부호가 반대라는 점도 함께 적는다.)

### §6 Where the Limit Comes From (신규 기여, 이 논문의 심장)

**6.1 교전 결과는 직후 승률을 거의 결정한다.** 독립 승률 모델 V(교전 표본 미사용, 시험 AUC 0.846,
교전 시각 ECE 0.010–0.018)로 ΔV = V(end) − V(pre)를 만들면:

| 예측자 | ΔV의 R² | 부호 정확도 |
|---|---:|---:|
| 실현된 교전 결과 **단독(1변수)** | **0.550** | **0.924** |
| 교전 전 특징 7,106개 | 0.024 | 0.556 |
| 둘 다 | 0.657 | 0.921 |

시간대별(실현 결과 단독): 2–10분 **0.630** / 10–20 0.529 / 20–30 0.361 / 30+ 0.395.
지평선별: end 0.550 → +30 s 0.414 → +60 s 0.324.

**6.2 그런데 예측해도 이득이 없다.** 최종 승패 스태킹 A 0.812387 / B(+예측) 0.812514 /
C(+실현) 0.830781, **B−A CI [−0.00055, +0.00082]**.

**6.3 그 null은 게임에 대한 발견이 아니다.** 두 가지 이유를 분리해 보인다.
- **중첩 특징집합**: 예측값은 X의 함수다. 같은 AUC 0.665라도 X **밖**의 정보를 담은 합성 예측기는
  **+0.0018 [+0.0008, +0.0028]**을 준다. 우리 것은 +0.0001이다.
- **마팅게일**: 보정된 V는 `E[ΔV | cutoff에 아는 것] = 0`이어야 하고 실측 **+0.19 pp**.
  V_pre가 이미 다가올 교전을 값매김했다.

**6.4 그래서 예측 가능성은 스윙 비대칭으로 나타난다** (마팅게일의 필연적 귀결):

| V_pre | 이기면 M+ | 지면 M− | 스윙이 함의하는 교전승률 | 실제 |
|---|---:|---:|---:|---:|
| ≤0.14 | +6.30 | −2.23 | 0.261 | 0.296 |
| ≈0.50 | +14.13 | −12.92 | 0.478 | 0.526 |
| ≥0.87 | +2.19 | −5.25 | 0.705 | 0.701 |

예측기가 V가 미처 반영 못 한 것을 **조금** 갖고 있다: ΔV~p̂ 기울기 **+5.05 pp/단위
[+4.12, +6.06]**, 단 r = 0.05이고 +60 s에는 소멸.

**6.5 상금의 위치**: 부분 오라클 — 최상위 스테이크 분위만 맞히면 천장 전체(+0.0196)를 가져가고,
하위 분위는 완벽히 맞혀도 +0.0001.

**6.6 병목은 관측이다.** ms 이벤트로 상태를 복원하면(레벨은 LEVEL_UP, 아이템 능력치는 구매 이벤트 ×
Data Dragon 스탯표, 골드·XP는 직전 프레임 기울기 외삽, 위치는 나이 보정 융합) 예측이
**0.6649 → 0.6708** [+0.0022, +0.0069]로 오르고, **초반(2–10분)에서 가장 크다** [+0.0031, +0.0116].
상태 복원 정확도: 레벨 정확 일치 52% → **99.98%**, 생존 84% → 98.4%, 총골드 MAE 388 → 188,
위치 중앙 오차 3,975 → 3,184 u.

### §7 Discussion

세 문장으로 요약된다.
1. 정의를 데이터에서 산출하면 라벨이 예측 가능해진다(0.670). 그중 리드를 넘는 몫은 +0.043이다.
2. 그 0.67은 학습기의 한계가 아니다 — 선형부터 어텐션까지 8개가 0.62–0.67에 모이고, 용량 3배가 +0.003이다.
3. 교전 결과는 직후 승률의 55%를 단독으로 설명하지만, 그것을 사전에 맞히는 능력은
   분 단위 텔레메트리가 cutoff 시점에 담는 것에 묶여 있다.

**Limitations** (전부 측정된 것)
- 킬 없는 교전은 정의 밖.
- 가격표가 원소 드래곤을 0 g으로 친다.
- 30분 이후 구간은 가치 모델 학습이 얇다(5분 버킷 재표집 후에도 pre ECE 0.069로 최악 구간).
- 코퍼스는 한 지역·한 기간(15.14–15.16). **티어 구성은 측정값이 아니라 수집 제약**이다
  (원천 삭제, 캐시에 티어 없음) — Table 1의 해당 행을 "Sampling frame"으로 바꿨다.
- **플레이어 단위 분석 불가**: 캐시에 PUUID가 없다.

## 6. 절대 쓰면 안 되는 문장

- "규모에 따라 분해된다" / teamfight 0.78–0.81 / pick−tf −0.068 → **철회됨**
- "예측 가능성은 중요도와 반비례한다" / "0.493" → **충돌변수 인공물**. 사전 스테이크로는 0.615
- "결정적 교전은 본질적으로 예측 불가능" → 입력이 소진되지 않았다(+0.006)
- "우리 예측기가 가용 정보를 못 잡는다" → B−A≈0은 중첩 특징집합 정리
- "교전 예측이 승패 예측을 개선한다" → null
- "확률 라벨이 골드 라벨보다 잘 예측된다" → 0.6344 vs 0.6649로 반대
- "드래곤 가치를 확률 라벨이 드러낸다" → 두 라벨 불일치에 드래곤 안 몰림(4.3% vs 4.2%). 가설이다
- 티어·플레이어 단위 주장 → 측정 불가

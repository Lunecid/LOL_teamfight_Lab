## 새 설계는 확정된 구현과 분리

가치 모델 V, `ΔV=V(S_e)-V(S_s)`, 교전 시작 정보만으로 `P(ΔV>0)`를 예측하는 모델 q, 패치 순서 검증, SHAP 설명은 새 설계의 계약과 구현/실험 상태를 각각 기록해야 한다. 기존 정의 문헌 목록이 이 새 설계 전체에 대한 검증을 대신하지 않는다. 가치 관련 선행연구를 인용할 때에는 원문의 가치함수·학습 목표·평가 프로토콜과 우리 차이를 별도로 대조한다.

특히 다음을 분리한다.

1. G/D 등 탐지 정의를 추정하는 데이터.
2. V를 학습하고 보정하는 데이터.
3. h 및 라벨 규칙을 선택하는 개발 데이터.
4. 동결된 정의와 모델을 평가하는 미래 패치 데이터.

현재 원고는 G를 208,141경기의 pooled 분포에서 추정했다고 기록한다. 따라서 이번 지연 측정에서 15.16 원시 이벤트를 제외했다는 사실만으로 **전체 파이프라인이 테스트 패치로부터 독립적이라고 주장하면 안 된다.** 미래 패치 일반화를 주장하는 주 실험에서는 개발 패치만으로 추정한 경계를 사용하거나, 전체 데이터로 만든 기존 정의를 기술적 분석으로 구분하고 별도 전향 평가를 해야 한다. 이는 이미 정한 모집단 개념을 바꾸자는 의미가 아니다.

SHAP은 q의 예측에 기여한 관측 변수를 설명한다. V의 설명과 분리하고 출력 척도, 상관 변수, 집단별 안정성을 명시한다. SHAP 값 자체는 한타 승리의 인과적 원인을 증명하지 않는다.

## 평가 설계

1. 15.14에서 학습,15.15에서 검증·보정·선택을 마친 V/q 및 입력 파이프라인을 동결한다. 15.16과 모든 외부 세트에서는 재학습·보정·후보선택 금지.
2. 외부 세트는 지역×패치별로 따로 보고한다. 원시 경기수, 유효 상태수, 적격 교전수, 제외 이유, 미지원 이벤트/누락 특징을 구분한다. 합산 지표는 보조만 사용한다.
3. KR16.13 vs NA1 16.13은 같은 패치의 지역 차이 점검. KR16.13/16.14/16.15는 시간/패치 차이 점검. 지역과 패치가 다른 비교를 순수 지역효과라고 부르지 않는다.
4. 기존 KR16.13의 early adaptation 자료와 late evaluation 자료의 사용 이력을 표시한다. 이번 주평가는 동결모델로 전체 적격 자료를 평가할 수 있지만 과거 사용 사실은 삭제하지 않는다. 새로운 적응 보정을 추가하려면 별도 연구 명세/별도 시험세트가 필요하다.
5. 상태 스키마·이벤트 매핑이 달라지는 경우 목표 라벨을 보고 조정하지 않는다. 사전 호환성 규칙과 실패목록을 작성한다. 검출/종료 규칙은 고정하고 동일 기준으로 V/q 및 SHAP를 평가한다. 모델군 자체 비교는 기존 명세와 별개로 확장하지 않는다.
6. 외부 데이터의 게임조건(queue420/map11 등), 지역/patch, 경기 ID 중복, 원시해시, 실제 detail/timeline 매칭 및 접근 이력을 검증한 manifest를 동결한 뒤 실행한다. 수집상태 pending/excluded는 테스트 경기수에 넣지 않는다.

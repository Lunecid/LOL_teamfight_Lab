## 2. 고친 것

1. **time_norm 누수.** 캐시의 time_norm은 t / (T − 1), 즉 경기 총 프레임 수로 나눈 값이다.
   컷오프에서 경기 길이는 미래 정보이고, 일찍 끝나는 경기는 일방적인 경기라 승자와 상관된다.
   특징 경로에서 t / 45분으로 다시 쓰고, 단계 인코딩도 같은 상수로 분을 복원한다.
   `tests/test_time_norm_absolute.py`.
2. **앵커 누수.** `meta["anchors"]`는 경기 전체에서 플레이트가 깨졌거나 파괴된 타워의
   위치, 처치된 오브젝트의 위치를 담는다. "가장 가까운 타워까지 거리"가 컷오프 이후에
   무너질 타워를 알고 있었다. 정적 지도 좌표(`config/game_rules/map_anchors.json`, 2,000경기
   사건 위치의 중앙값: 타워 22, 억제기 6, 둥지 5)에서 τ 이전 BUILDING_KILL만 빼는
   "서 있는 타워"로 바꿨다. `gameplay/anchors.py`, `tests/test_causal_anchors.py`.
3. **공간 블록이 상대 좌표로 계산되던 문제.** 노드 좌표가 중심 상대이므로 싸움 중심은
   항상 원점이었고, 구역·타워·오브젝트 특징은 원점에서의 거리였다(zone_mid_lane = 1 고정,
   dist_tower = 원점에서 가장 가까운 파괴 타워 → 누수 2와 결합). 절대 좌표 시퀀스를 따로
   실어(`interpolate_abs_xy`, 같은 τ 캡·가드) 공간 블록에 넘긴다. 스모크(1,104행): zone
   river 66% / jungle 28% / bot 4%, near_obj_dragon 3%, in_tower_range 5%.
   `tests/test_spatial_abs_xy.py`.
4. **신선도.** frame_age_s = τ − 마지막 프레임(0~60 s). GRU-D의 관측 후 경과 시간.

보정: 프레임의 정글 CS는 에픽 몬스터도 1로 세므로 CS 회귀항이 몬스터당 23 g를
흡수한다. 몬스터 가격은 계수 + 23으로 두고 0에서 자른다(용 0). 첫 타워 보너스는 규칙으로
확인되지 않고 계수가 작고 음수라 제외한다. 패치 간 차이는 수 골드라 풀링 표를 쓴다.

**라벨 market_event (가격 부착판).** 창 [τ, max(마지막 킬, τ + 35)] 안의 사건에 대해
Δ = Σ 부호 × (킬: bounty + shutdown + 20 + 45 × 어시스트 수; 그 외: 위 표)이고,
|Δ| > 300이면 시장 판정, 아니면 클러스터 킬 → 마지막 킬 시점 생존자 → 구조물 부호 →
무승부 제외. 보간 없음. 스모크(1,104행)에서 market_lex와 일치 96.4%(무가격판 94.7%),
Eq.3와 91.5%.

  수정이 그대로 적용되지만, 공간 블록의 절대 좌표 전달은 탭 경로와 같은 `build_sequence_features`

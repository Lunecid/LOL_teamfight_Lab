# 단조 확률 보정과 Δ 부호 라벨

2026-09-15, 설계 감사 메모. 아래는 수학적 성질이며 새 실험 결과가 아니다.

같은 기본 가치 모델이 전후 확률 p_pre, p_post를 출력하고, 두 값에 동일한 엄격 증가 함수 g를 적용하면

```text
sign(g(p_post) − g(p_pre)) = sign(p_post − p_pre)
```

따라서 `Y=1[p_post>p_pre]`는 변하지 않는다. 현재 후보인 `g(p)=sigmoid(a+b*logit(p)), b>0`는 0<p<1에서 이 조건을 만족한다.

## 현재 연구에 주는 의미

- V의 보정은 최종 승리 확률 및 Δ의 크기를 해석하는 데 중요하지만, 동일 모델의 엄격 단조 보정만으로 부호 라벨의 의미 타당성을 검증할 수는 없다.
- abs(Δ)≤.01 등의 진단 구간은 보정 후 바뀔 수 있다. 부호 불일치와 작은 Δ 비율은 서로 다른 민감도다.
- 서로 다른 V를 비교하면 상태별 순위가 달라질 수 있으므로 부호가 바뀔 수 있다. 규제 강도·입력 표현 비교가 실제로 측정하려는 부분이다.
- 각 TRAIN fold의 보정 함수가 달라도 같은 행의 pre/post에 같은 함수가 적용되면 그 행 안에서 성질은 유지된다. 서로 다른 어댑터를 전후에 섞으면 성립하지 않는다.
- isotonic의 평탄 구간 또는 수치적 clipping은 서로 다른 확률을 같은 값으로 만들 수 있으므로 엄격 증가 가정이 깨진다. 방향 역전 없이도 양수 Δ가 0으로 바뀔 수 있다. 이 경우를 엄격 단조 보정과 구분한다.

현재의 0 기준 부호 라벨에 관한 성질이다. Δ의 크기 회귀, 고정 크기 임계값, 실제 게임 가치의 인과적 해석은 별도 문제다.

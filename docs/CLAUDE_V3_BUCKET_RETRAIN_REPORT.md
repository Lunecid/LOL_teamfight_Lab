# v3: 5분 버킷 표집으로 재학습한 결과 — 세 결함이 함께 해소됐다

실행일: 2026-09-10. 기준 커밋: `3578918`.
선행: [검증 A](CLAUDE_TEMPORAL_VALIDATION_REPORT.md) · [검증 B](CLAUDE_BOUNDARY_SENSITIVITY_REPORT.md) · [검증 C](CLAUDE_OBJECTIVE_PASSTHROUGH_REPORT.md).
스크립트: `scripts/run_temporal_winprob_v3_buckets.py`, `scripts/score_engagements_v3.py`.
산출물: `outputs/temporal_winprob_v3_buckets/`(학습 63.2초, 교전 채점 183.0초, 검증 A 69.4초 / B 27.2초 / C 44.7초).
**v2 산출물은 그대로 보존했다.** 새 디렉터리에만 썼다.

## 무엇을 바꿨나 — 단 하나

v2는 Maymin (2021) §3.2를 따라 **경기당 무작위 1분**을 뽑았다. 그 결과 학습 표본이 경기 길이 분포를
그대로 물려받아 30분 이후가 7,004행 중 **211행(3.01%)**밖에 없었다. 검증 A·B·C가 찾은 세 결함이
모두 이 희소성을 가리켰다.

v3은 Jalovaara (2024) §5.1을 따라 **경기당 5분 버킷마다 한 점씩** 뽑는다. 그 외에는 전부 동일하다 —
같은 분할, 같은 두 계열, 같은 입력(7 / 361), 같은 C 후보와 3-fold 그룹 CV, 같은 보정 변형과 선택 규칙.
**시험 표집은 바꾸지 않았다**(경기당 무작위 1분, 같은 시드). 따라서 시험 지표와 전체 그리드
시간대 지표는 v2와 직접 비교 가능하다. fit / calibrate / select만 버킷 표집으로 바뀐다.

| 역할 | 행 | 경기 | 행/경기 | 2–10분 | 10–20분 | 20–30분 | **30분+** |
|---|---:|---:|---:|---:|---:|---:|---:|
| fit | 40,228 | 7,004 | 5.74 | 13,988 | 13,904 | 9,819 | **2,517** |
| calibrate | 8,697 | 1,501 | 5.79 | 3,001 | 2,984 | 2,152 | 560 |
| select | 8,600 | 1,502 | 5.73 | 2,997 | 2,975 | 2,094 | 534 |
| test | 4,986 | 4,986 | 1.00 | 1,738 | 1,987 | 1,085 | 176 |

30분 이후 학습행이 **211 → 2,517개, 11.9배**가 됐다.

부수적으로 같은 선택 절차가 C를 `0.01 → 0.001`로 골랐다(정규화 강화). 표집만 바꿨는데 선택이 따라
움직인 것이라 개입하지 않고 기록한다.

## 결과 1: 장로 부호 역전이 완전히 해소됐다 (검증 C)

획득 팀 기준 부호 정확도, 확장형:

| 범주 | v2 | **v3** | 사건 시각 중앙 |
|---|---:|---:|---:|
| **elder** | **3.8%** (2/52) | **100.0%** (52/52) | 33.9분 |
| **soul** | 76.7% | **100.0%** | 28.1분 |
| baron | 98.3% | 100.0% | 27.2분 |
| atakhan / dragon / herald | 100% | 100% | 15.6–21.3분 |
| horde | 100% | 98.3% | 8.8분 |
| **전체** | **84.2%** | **99.8%** (411/412) | — |

크기도 상식적으로 바뀌었다. Blue가 장로를 획득할 때 모델 반응이 **−11.03 pp → +25.13 pp**,
Red가 획득할 때 **−2.08 pp → −21.44 pp**다. 부호만 맞은 게 아니라 장로가 후반 경기에 갖는
무게에 걸맞은 크기가 나온다.

C1 재현은 그대로다: 원천 이벤트에서 센 즉시 창이 Baron 225 / Dragon 1,060 / Elder 18 / Soul 63으로
v2와 동일하며, 교전 모집단(26,712행 / 9,198경기)과 경계 제외 0건도 같다. **모델만 바뀌었다.**

## 결과 2: 규모 상관 편향이 사라졌다 (검증 B)

이것이 즉시 경계를 라벨로 쓸 수 없게 만들던 결함이었다. 확장형 즉시 Δ:

| 규모 | v2 평균 | **v3 평균** | v2 Blue증가 | **v3 Blue증가** |
|---|---:|---:|---:|---:|
| pick (≤1) | −0.910 pp | **+0.172 pp** | 48.8% | **50.8%** |
| skirmish (2–3) | −1.795 pp | **+0.158 pp** | 46.3% | **51.0%** |
| teamfight (≥4) | **−3.017 pp** | **+0.326 pp** | 43.0% | **51.0%** |

**규모에 따른 기울기가 완전히 없어졌다.** 세 계급이 모두 +0.2 pp 부근이고 Blue 증가 비율이
51% 근처로 대칭이다. 분류 축(규모)과 상관된 편향을 라벨에 심을 위험이 사라졌다.

프레임 지연 대조도 같이 해소됐다 — 같은 프레임 −1.916 → **+0.382 pp**, 갱신됨 −1.816 → **−0.107 pp**.
검증 B가 지목한 "킬은 기록됐는데 경제는 아직 프레임에 없는" 상태를 v3 모델은 훨씬 덜 잘못 읽는다.

경계 민감도도 개선됐다(구조적 문제라 완전히 없어지지는 않는다):

| 경계 이동 | v2 전환율 | v3 전환율 | v2 중앙변화 | v3 중앙변화 |
|---|---:|---:|---:|---:|
| end → +30초 | 17.8% | **13.8%** | 4.36 pp | 3.22 pp |
| end → +60초 | 23.7% | **20.4%** | 6.09 pp | 5.13 pp |

모형 간 방향 일치도 85.6% → **88.9%**(즉시)로 올랐다.

## 결과 3: 후반 보정은 크게 나아졌으나 완전하지는 않다 (검증 A)

전체 그리드 시간대별, 확장형, 같은 4,986 시험경기:

| 구간 | v2 AUC | v3 AUC | v2 ECE | v3 ECE |
|---|---:|---:|---:|---:|
| 2–10분 | 0.6768 | **0.6794** | 0.0313 | **0.0099** |
| 10–20분 | 0.8525 | 0.8527 | **0.0090** | 0.0198 |
| 20–30분 | 0.9429 | **0.9449** | 0.0094 | **0.0081** |
| **30분+** | 0.9200 | **0.9336** | **0.0383** | **0.0101** |

교전 시각(pre)에서 게임 시간대별로 봐도 같은 패턴이다:

| 구간 | 행 | v2 AUC → v3 | v2 ECE → v3 |
|---|---:|---|---|
| 2–10분 | 11,224 | 0.6620 → **0.6664** | 0.0302 → **0.0091** |
| 10–20분 | 8,938 | 0.8373 → 0.8366 | 0.0136 → 0.0243 |
| 20–30분 | 5,473 | 0.9083 → **0.9123** | 0.0249 → **0.0119** |
| **30분+** | 1,077 | 0.8070 → **0.8443** | **0.0929 → 0.0690** |

30분+ ECE는 0.0929에서 0.0690으로 내려왔지만 **여전히 가장 나쁜 구간**이다. AUC는 0.807 → 0.844로
크게 올랐다. 희소성을 12배 줄였는데도 남는다는 것은, 후반 어려움이 표본 수만의 문제는 아니라는 뜻이다.

교전 시각 전체 지표는 모든 시점에서 개선됐다(확장형):

| 시점 | AUC v2 → v3 | Brier v2 → v3 | ECE v2 → v3 |
|---|---|---|---|
| pre | 0.8025 → **0.8050** | 0.1806 → **0.1798** | 0.0148 → 0.0182 |
| end | 0.8303 → **0.8335** | 0.1682 → **0.1663** | 0.0162 → **0.0103** |
| +30초 | 0.8298 → **0.8345** | 0.1684 → **0.1664** | 0.0149 → 0.0228 |
| +60초 | 0.8322 → **0.8348** | 0.1673 → **0.1666** | 0.0133 → 0.0249 |

## 대가 — 숨기지 않는다

1. **밀집 구간이 나빠졌다.** 10–20분 ECE가 0.0090 → 0.0198(그리드), 0.0136 → 0.0243(교전 pre).
   시간에 균등한 표집이 밀집 구간의 정확도를 희소 구간으로 재분배한 결과이며, 예상된 교환이다.
2. **풀링한 ECE는 나빠질 수 있다.** 경기당 1분 시험 모집단의 전체 ECE가 0.0121 → 0.0288이고,
   교전 pre·+30·+60의 풀링 ECE도 소폭 올랐다. 구간별로는 대부분 좋아졌는데 풀링이 나빠지는 것은,
   **v2에서는 구간별 편향이 서로 상쇄돼 풀링이 좋아 보였기 때문**이다. 검증 A가 처음에 "풀링 ECE는
   괜찮은데 30분+는 0.0929"를 발견한 것과 같은 현상의 뒷면이다. 풀링 지표만 보면 안 된다는 근거가 하나 더 늘었다.
3. **시험 AUC는 사실상 불변**이다(0.846790 → 0.846363). 이 재학습은 판별력을 올리는 작업이 아니라
   확률을 옳은 곳에 놓는 작업이었다.
4. **C가 0.01 → 0.001로 바뀌었다.** 표집 외 두 번째 변화이므로, 엄밀히는 "표집만 바꿨다"가 아니라
   "표집을 바꾸고 같은 절차로 정규화를 재선택했다"이다.
5. **포화 문제(검증 B5)는 그대로다.** 경기를 끝내는 한타가 작은 Δ를 받는 것은 모델 결함이 아니라
   ΔV의 의미론이므로 재학습으로 바뀌지 않는다.

## 무엇이 바뀌었나 — 라벨 결정에 대해

검증 A·B·C 시점에서 ΔV를 주 라벨로 쓸 수 없었던 이유는 세 가지였다. 그중 둘이 해소됐다.

| 결함 | 상태 |
|---|---|
| 규모 상관 편향(−0.9 / −1.8 / −3.0 pp) | **해소** (+0.17 / +0.16 / +0.33) |
| 장로 부호 역전(3.8%) | **해소** (100%) |
| 후반 과신(30분+ ECE 0.0929) | **크게 개선, 잔존** (0.0690) |
| 경계 민감도(부호 전환 23.7%) | 개선(20.4%), 구조적으로 잔존 |
| 결정적 한타의 포화(중앙 \|Δ\| 1.85 pp) | 변화 없음 — 의미론 |

**골드 자가 원소 드래곤을 0골드로 치는 문제**(`config/game_rules/event_prices.json`의 `"dragon": 0.0`,
즉시 창 최대 범주 1,060건)는 v3에서도 그대로다. 이건 골드 라벨의 성질이지 승률 모델의 문제가 아니며,
확률 자를 도입할 근거로 남는다. 확률 자는 v2에서도 v3에서도 드래곤 부호를 100% 맞힌다.

## 남은 결정

1. **ΔV를 주 라벨로 승격할지.** 승격을 막던 두 결함이 해소됐다. 남은 것은 30분+ 잔여 과신과
   포화 문제이며, 둘 다 "한계로 적고 진행"이 가능한 수준으로 보인다. 다만 채택은 설계자 결정이다.
2. **경계.** 즉시 경계의 편향이 사라졌으므로 검증 B의 "+60초 권고"가 약해졌다. 이제 즉시 경계도
   후보이며, 후속 창이 오브젝트를 2배 담는다는 검증 C의 지적을 피할 수 있다는 이점이 생긴다.
3. **v3를 고정 모형으로 승격할지.** 그렇다면 새 매니페스트와 해시 대장이 필요하고,
   `docs/CLAUDE_NEXT_STAGE_MANIFEST.json`이 가리키는 고정 입력이 v2에서 v3로 옮겨간다.
4. **환경 핀**(검증 A §0에서 보고한 scikit-learn 1.6.1 문제)은 여전히 미해결이다.

고정 모형의 `SimpleImputer`가 적재되지 않는다.

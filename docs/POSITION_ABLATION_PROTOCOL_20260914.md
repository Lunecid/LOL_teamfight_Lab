# 관측 위치 추가의 간단한 예측 비교: 실행 전 명세

주 실험 라벨은 이미 계산한 B+90초의 Y=1[Δp>0]. 기존 독립 engagement 파티션의 유효26,693교전에서15.14학습,15.15개발 확인,15.16탐색 평가를 사용한다. 별도 V 학습/보정/선택 경기와의 교집합0을 검사한다. 동일 경기의 행은 split을 넘지 않는다.

기준 입력: 기존 StateBuilder가 s−1ms 시점까지 구성한 경제·전력·이벤트 이력 특징과 고정 V의 p_pre. snapshot_age_s는 두 조건 모두 포함한다. 비교 입력: 기준+같은 마지막 프레임의10명 실제 관측 x/y좌표20열. 미래 첫 킬 중심·사후 참여자에 의한 위치 선택 없이 기존 고정 역할 슬롯으로 정렬한다. 좌표 외 거리·밀집도·보간값은 추가하지 않는다. 기존7116열 전체 모델의 재현이 아닌 단순 상태 특징 기준선의 위치 ablation이다. 역할 메타데이터의 사전 가용성 가정은 양 조건 공통이며 이번 실험만으로 보증되지 않는다.

LightGBM 고정250trees,15leaves,learning_rate=.04,min_child_samples=100,lambda=1,n_jobs=4. seed7/42/123. 튜닝/early stopping 없음. 두 조건 동일 하이퍼파라미터·라벨·행·split·경기 가중치. 챔피언ID는 범주 특징 처리한다. 경기별 학습 가중치 합이 같도록1/해당 경기 행 수 가중치를 사용한다.

지표: 경기 동일 가중 AUC/Brier/logloss,seed별 및3seed평균 확률.15.16에서 경기 bootstrap500회로 위치추가−기준 차이의95% CI. 양수AUC/음수Brier·logloss가 개선이다. 테스트를 보고 채택 기준을 재정의하지 않는다. 과거부터 활용한15.16이므로 새 외부 검증이 아니다. 유의한 향상 여부는 이 단순 모델 조건에서의 결론이며 위치의 보편적 유용성/무용성으로 확대하지 않는다.

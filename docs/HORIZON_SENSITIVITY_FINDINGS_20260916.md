# 종료 상한 민감도: h90 선정 학습기 5종의 h60·h120 재적합 — 결과와 ToG 해석

2026-09-16. 설계·구현·실행·검증: Claude(Codex 라인 계승). 사용자 결정: 현재 데이터 유지, 검증 계속. 구성(하이퍼파라미터)은 h90 승자로 고정하고 보정만 Q_SELECT에서 선택했다(DELTA_Q 프로토콜 §3-6). h90 열은 재적합하지 않고 iq·Track A의 동결 결과를 같은 행에 병기했다. 기존 TEST/외부 노출 후의 탐색적 후속 실험이며 미접촉 확증이 아니다.

**판단:** 학습기 순서는 종료 상한(60·90·120 s)에 무관하게 같다. 한타 T에서는 LightGBM ≈ 로지스틱 ≈ plain MLP(짝지은 구간 0 포함) > residual MLP(유의하게 열세) > PT 기준선(유의하게 열세); 비한타 N에서는 LightGBM > 두 MLP > 로지스틱 > PT가 전부 유의하다. 상한 간 Brier 수준 차이는 라벨(종료점) 차이를 포함하므로 학습기 비교로 읽지 않는다. 이로써 h90에서 관찰한 "정보가 같으면 학습기 차이는 0.0001 수준"이 상한 선택에 의존하지 않음을 확인했다.

## 1. 실행 전후와 고정 조건

- 새 적합 20건: 2상한 × 2코호트 × 5 family(PT, 전체 logistic, 전체 LightGBM, plain MLP, residual MLP). 각 family의 구성은 iq/Track A의 h90 승자(pt_C1; logit_C0.001 T / logit_C0.01 N; lgbm_L15_M100; mlp_W128_D0.3; resmlp_W128_D0.1)에서 복사해 프로토콜에 동결. LightGBM 반복 수와 MLP epoch 수는 상한 라벨에서 stop10 규칙으로 다시 정해졌다(적합 절차의 일부).
- 행 수는 상한별 유효 마스크가 코호트 manifest에서 동일해 h90과 같다(T 32,981 / N 130,595 TEST). 따라서 같은 행에서 라벨만 바뀐 비교다.
- 보정 선택 결과: T는 대부분 raw(LightGBM h60만 sigmoid), N은 LightGBM·MLP가 sigmoid, logistic h120이 isotonic. residual MLP는 T에서 상한과 무관하게 1 epoch 최적(즉시 과적합) — Track A와 같은 현상.
- 하나의 동결로 두 상한을 묶었고, TEST/외부/부모 참조 예측은 동결 이후에만 열렸다. 사후검증 91/91 통과.

## 3. 외부 세트

주 대비 LightGBM − PT는 KR 16.13 T/N, NA1 T/N에서 두 상한 모두 우세(구간 0 미포함), KR 16.15 N은 h60 우세·h120 0 포함, 소표본 세트는 0 포함. MLP − LightGBM은 외부에서 대부분 0 포함이나 **NA1 T에서는 두 MLP가 LightGBM보다 유의하게 나쁘다**(+0.003, 두 상한 모두) — Track A h90과 같다.

## 4. 해석

- 상한을 60·90·120 s로 바꿔도 (i) 전체 정보 학습기(LightGBM·로지스틱·plain MLP)가 강화 기준선 PT를 이기고, (ii) 그 셋 사이는 구간이 0을 포함하며, (iii) residual MLP가 뒤지고, (iv) N에서 트리가 앞서는 구조가 그대로다. 학습기 결론은 종료 상한의 선택에 의존하지 않는다.
- 상한 간 절대 Brier의 차이(T에서 h60이 가장 낮음)는 라벨이 달라진 결과이며, 60 s 라벨이 "더 예측하기 쉬운" 결과라는 뜻이지 모델이 좋아진 것이 아니다. 상한은 TEST로 고르지 않았고 주 분석은 h90 그대로다.
- 구성을 h90에서 고정했으므로 h60/h120에서의 최적 구성 비교는 아니다.

## 5. 검증과 기록

계약 테스트 10개 두 번 통과(run1, 최종 코드 run2), TRAIN-only smoke(h60) 통과, 사후검증 **91개 검사 통과(1차)**: 부모 무결성, 순서, 봉인 접근 시점, 동결 hash, 구성 = 부모 h90 승자, 선정·보정기·전처리·정지 기록·seed 평균·재로딩 독립 재현, 부모 참조열이 cohort_role 보고 지표를 <1e-12 재현, 저장 예측 지표 재계산 <1e-10, 부트스트랩 수용 게이트 60셀, 새 프로세스 재로딩 동일.

## 6. 논문에서 사용할 문장

> 종료 상한을 60, 90, 120 s로 바꾸어 h90에서 선정한 다섯 학습기를 같은 행에서 재적합해도 순서는 변하지 않았다: 한타에서는 LightGBM, 정규화 로지스틱, plain MLP가 0.0002 이내로 같고(짝지은 구간이 0을 포함), residual MLP와 p_pre×시간 기준선이 유의하게 뒤진다; 비한타에서는 LightGBM이 모든 상한에서 유의하게 앞선다. 상한 간 절대 Brier 차이는 라벨 종료점의 차이이며 학습기 비교로 해석하지 않는다.

# 윈도우 정당화 실험: 실행 전 명세

후보 h=0,30,60,90,120,180초를 비교한다. 0초는 마지막 킬 대조다. 결과로 최적값이 자동 도출된다고 가정하지 않는다.

1. 전체 210,000경기 탐지 산출물의 포함률, 다음 교전/경기 종료에 의한 관찰 단축률을 비교한다. 전장 전체와 4,264u 공간 제한의 첫 획득 연결 차이는 원거리 혼입의 대리 지표이며 인과적 오귀속률은 아니다.
2. 기존 temporal_winprob_v3_buckets의 engagement 파티션 전체를 대상으로 고정 expanded 및 maymin 두 모델로 윈도우별 Δp를 재평가한다. fit/calibrate/select 파티션과 경기 교집합 0을 검사한다. 기존에 관찰한 탐색 자료이며 새로운 외부 시험이 아니다.
3. s−1ms에서 p_pre를 만들고 각 endpoint=min(L+h,next_start−1,terminal−1)를 평가한다. 현재 상태 빌더의 마지막 관측 범위 이후 endpoint는 외삽하거나 0으로 채우지 않고 결측으로 남긴다. next_start≤L은 중첩으로 표시하고 제외한다.
4. 동일 교전 공통 유효 집합에서 Y=1[Δp>0]의 후보 간 반전율, 양성률, 정확한 동률, |Δp|, 모델 간 일치율을 보고한다. 모델 간 일치가 진실성을 입증하지 않는다. 일부 결측 제외가 결과를 바꿀 수 있어 각 비교의 n을 공개한다.
5. 예측 성능을 최대화하도록 h를 선택하지 않는다. 포함률과 라벨 안정성이 충분한 절충인지 판단하되 사전 합의된 수치 기준이 없으므로 이번 실험은 후보 탐색이다. 외부 패치 검증과 전문가 사건 귀속 검증을 대신하지 않는다.

출력: outputs/window_validation_20260914/{labels.csv,results.json}, 재현 코드 scripts/validate_windows.py. 원본 모델과 진행 중인 Claude 작업은 수정하지 않는다. 새 주 예측기 학습/SHAP은 입력 및 V 타당성 검증 후 별도 단계다.

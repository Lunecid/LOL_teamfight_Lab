기존 라벨을 대체하는 기본값으로 승격하지 않았다.

## 출력과 학습 절차

가치모형 `V(S)`는 관측 상태에서 Blue의 최종 경기 승리 확률을 추정한다.
`delta_value = V(S_post) - V(S_pre)`의 부호를 Blue/Red 라벨로 삼고 정확한
동률·유효하지 않은 상태는 mask 처리한다. 이번 시험에는 동률/무효 라벨이 없었다.
교전 모델은 기존 7,106개 cutoff 이전 입력으로 이 라벨의 확률을 예측한다.
사후 참여 규모는 집단 분석에만 사용한다.

가치 입력 362개에는 참가자 성장·생존·챔피언·역할과 바론/장로 획득 이력,
이후 사망, 종류별 드래곤, 명시적 영혼 이벤트, 구조물이 들어간다. 전략적
가중치를 수동으로 정해서 라벨에 더하지 않는다. 정확한 버프 보유/만료는
복원하지 못했으므로 획득 이력을 현재 버프 상태라고 주장하지 않는다.

파일럿 이후 고정한 절차대로 가치 학습 경기 내부 3-fold CV에서 log loss로
정규화 C를 선택했다. 후보 {0.0001, 0.001, 0.01, 0.1, 1} 중 C=0.001이
선택됐다. 가치 검증과 교전 시험 경기는 이 선택에 사용하지 않았다.
교전·경기 예측기는 고정 LightGBM 설정을 사용했다. 스태킹 학습 확률은
5-fold 경기별 OOF이며 최종 시험 성능에 맞춰 설정을 다시 고르지 않았다.

## 가치모형: 오브젝트를 포함한 상태 평가

| 가치 검증 모형 | AUC ↑ | Brier ↓ | Log loss ↓ |
|---|---:|---:|---:|
| 오브젝트 포함 | 0.847218 | 0.159241 | 0.475695 |
| 주요 오브젝트 변수 제거, 같은 C | 0.842091 | 0.161911 | 0.483084 |
| 가치 학습 경기의 승리 비율 상수 | 0.500000 | 0.249822 | 0.692791 |

오브젝트를 포함한 모형의 관측 지표가 더 낫다. 이 제거 실험은 동일 C의
진단이며, 각 오브젝트의 인과적 가치나 라벨의 독립적인 의미 타당성을 증명하지
않는다. 확률 10개 구간의 가치 검증 calibration도 원본 JSON에 저장했다.

다음은 **어느 팀이든 해당 이력이 관측된 서로 다른 경기 수**다. 두 팀의
수치를 합산한 값이나 반복된 상태 수가 아니다.

| 관측 이력 | 가치 학습 경기 | 가치 검증 경기 |
|---|---:|---:|
| 드래곤 | 9,908 | 4,931 |
| 바론 | 4,643 | 2,334 |
| 명시적 영혼 이벤트 | 1,517 | 811 |
| 장로 | 136 | 92 |

장로를 포함한 검증은 수행했지만 다른 오브젝트보다 여전히 희귀하다. 장로 관련
조건부 확률 품질이나 정확한 버프 소유 효과까지 검증 완료됐다고 보지 않는다.

## Engagement 예측

| 예측 대상/입력 | AUC ↑ | Brier ↓ | Log loss ↓ |
|---|---:|---:|---:|
| 전체 사전 입력, 학습 OOF | 0.621125 | 0.238154 | 0.668818 |
| 전체 사전 입력, 시험 | 0.622756 | 0.238059 | 0.668678 |
| 교전 직전 V(S) 하나만 사용, 시험 | 0.588878 | 0.242504 | 0.677856 |

가치 상승 방향의 예측 신호가 관측되며 초기 가치 하나만 사용하는 기준보다
관측 지표가 높다. 시험 교전 중 11.49%는 절대 가치 변화가 0.01 미만이고,
1.60%는 0.001 미만이다. 부호 라벨이 근사모형 오차에 민감할 수 있음을 남기며,
사후에 작은 변화 표본을 지우지 않았다.

사후 규모별 AUC는 pick 0.6024(4,851행), skirmish 0.6063(16,572행),
teamfight 0.6686(5,289행)이다. 서로 다른 집단이며 이 표만으로 규모의
인과적 효과나 보편적인 성능 순서를 주장하지 않는다.

기존 market_event와의 라벨 일치는 공통 25,177행에서 89.57%,
attention_value_win(Eq.3)과는 26,513행에서 86.86%였다. 높은 일치율도
새 정의의 타당성을 독립적으로 확증하지 않는다.

## 최종 경기 승패 예측에 대한 추가 기여

세 모델은 같은 경기·시점·시험 행에서 비교했다. A/B의 원래 입력과 학습기
설정은 동일하다. B의 추가 확률은 사전 입력의 함수이므로 개선이 있더라도
새로운 정보 획득보다는 중간 표현의 학습상 효용으로 해석해야 한다.

| 경기 승패 예측 | AUC ↑ | Brier ↓ | Log loss ↓ |
|---|---:|---:|---:|
| A: 사전 입력 | 0.812387 | 0.176098 | 0.520945 |
| B: 사전 입력 + OOF engagement 확률 | 0.812414 | 0.176061 | 0.520860 |
| C: 사전 입력 + 실현된 라벨, 사후 참고 | 0.833152 | 0.166493 | 0.496154 |

B−A AUC 차이는 **+0.000027**, 경기 단위 paired bootstrap 95% 구간은
**[-0.000838, +0.000855]**다. Brier 개선(A의 loss−B의 loss)은
**+0.000037**, 구간 **[-0.000288, +0.000375]**다. 300회 bootstrap은
현재 학습된 모형에 조건부이며 재학습·가치모형 추정의 불확실성은 포함하지 않는다.

추가 예측 기여는 확인되지 않았다. 사후 C의 높은 지표는 미래 결과 정보를
넣었을 때의 참고값이며 실현 가능한 사전 성능이나 인과효과가 아니다.
현재 근거로 논문에서 주장할 수 있는 것은 관측 상태 기반 가치 라벨을 통한
engagement 예측의 사례이고, 최종 승패 예측 향상은 입증된 기여로 쓸 수 없다.

## 감사와 산출물

`scripts/audit_state_value_artifacts.py`를 실제 50k 산출물에 실행해 통과했다.
선택·분할 경기 ID, 파일럿 무교집합, 가치 학습 CV와 engagement OOF 분리,
라벨/예측 행 정렬, 타임스탬프, delta 부호, 고정 모델과 소스 SHA-256을 확인했다.
저장된 확률에서 교전 및 A/B/C 지표를 재계산하여 원본 보고값과 일치함을 확인했다.
관련 단위/회귀 테스트 21개 통과 결과도 유지한다. 이는 현재 코드의 모든
도메인 상태 복원이나 실시간 운용을 완전히 보장한다는 의미는 아니다.

집계 결과와 감사 요약은 이 문서 옆 `experiments/state_value_50k_results.json`,
`experiments/state_value_50k_audit.json`에 보존한다. 모델·개별 라벨·분할 목록 등
대용량 산출물은 worktree의 `outputs/state_value_main_50k_eval`에 있다.

```powershell
python scripts/audit_state_value_artifacts.py --dataset outputs/state_value_main_50k --out-dir outputs/state_value_main_50k_eval --pilot-dataset outputs/state_value_pilot_full
```

새 입력/출력 계약과 학습 재현 명령은 `STATE_VALUE_EXPERIMENT.md`,
파일럿의 실패와 정규화 수정 기록은 `STATE_VALUE_PILOT_RESULTS_20260909.md`에 있다.
향후 출력 정의 확정에는 교전 직후와 후속 구간의 해석, 작은 delta의 안정성,
오브젝트 사례의 도메인 타당성 점검이 남아 있다. 이번 결과를 보고 가치모형을
계속 복잡하게 만들거나 시험 자료에 맞춰 라벨을 고르는 작업은 수행하지 않았다.
